# Topic: the reader binds a pronoun by counting backticks, and is wrong in both directions

**Date:** 2026-09-20
**Governing canon:** `ruling::half_up_denotes_ties_toward_positive_infinity`, and
`ruling::the_rounding_mode_vocabulary` for what the six names are.
**Where this came from:** finding 4 of the second review of pull request #150, which named two
false-negative classes in `half-up-is-not-a-magnitude-rule`. The lint runs at hard error on every gate.
Checking the two against the reader found a third class the review did not name and a false positive the
review reported as absent.

## What the reader does today

`mock/lints/half_up_is_not_a_magnitude_rule/reading.rs` carries a name from one clause to the next so that
"`half_up` is nearest. Its tie goes away from zero." fires. Two functions decide it. `antecedent` at :296
takes the last spelling of the mode in a clause and refuses to carry it when two or more backticks stand
after it, on the reasoning that a backticked span after the name is something else being named.
`clause_hit` at :262 consults the carried name only where the next clause opens with a pronoun, which
`opens_with_a_pronoun` at :309 reads off the first word.

## What was measured

Read with a copy of the shipped `reading.rs` driven from a probe. Each line is a passage and the verdict
is what `hits` returns for it.

Silent and should fire, because nothing that could be a rounding rule is named between the name and the
reading:

- "`half_up` pairs with `q/2`; it sends a tie away from zero." The backticked `q/2` is not a candidate
  antecedent for a pronoun standing for a mode, and it defeats the carry anyway.
- "`half_up` is a mode. Ties go away from zero under it." No backtick is involved at all. The second
  clause carries the reading and does not open with a pronoun, so it is never paired.
- "`half_up`: a tie goes away from zero." A colon introduces rather than separates, and the clause cut
  at it leaves the name behind.
- "`half_up` at a tie: away from zero."
- "`half_up`; a tie goes away from zero." The same at a semicolon, which the review did not name.
- "`half_up`? a tie goes away from zero." The same at a question mark.

Fires and should not, which the review reported as a class with no members:

- "`half_up` is not the HALF_UP of Java. That one goes away from zero."

That last one is the sentence of the control at `tests.rs:216` with the backticks taken off, and it is the
shape of the ruling's own note. The control passes only because the note happens to write `HALF_UP` in a
code span. The defeater is keyed on formatting rather than on what was named, so it is too wide where the
other name is backticked and too narrow where it is not. A false positive in a hard-error gate stops
correct work, which is the direction the review's severity argument assumed was empty.

## Where the review is wrong, and it is worth saying which part

Two of the four sentences the review lists as must-fire are correctly silent, and firing them would
contradict the repository's own controls.

- "`half_up` is not Java's `HALF_UP`. It sends a tie away from zero." differs from the passing control at
  `tests.rs:216` in the pronoun and the word order and in nothing that bears on the reading. `HALF_UP` is
  the name of the other operation, a pronoun after it points at it, and the sentence is true.
- "`half_up` resembles `ceil`. It sends a tie away from zero." `ceil` is one of the six names
  `ruling::the_rounding_mode_vocabulary` closed the set at, so it is a candidate antecedent for a mode
  under the review's own prescription two paragraphs later. The prescription and the sentence list
  disagree with each other; the prescription is the half that holds.

"`half_up` and `half_even` differ: the first sends a tie away from zero." stays silent too, for two
reasons that each suffice: `differ` is a negator bound to the name, and pairing "the first" with the
earlier of two names is ordinal anaphora, which nothing here models and which is not worth building into
a gate that refuses prose.

## The decisions

[between narrowing the backtick defeater as the review prescribes, and replacing what the carry is keyed
on] The carry is keyed on what was named. Counting backticks is a proxy for the question and the two
false directions above are what a proxy costs.

**A name is carried until another rounding rule is named after it.** `OTHER_NAMES` holds the five names of
the six-name vocabulary that are not this mode, the external constants this repository contrasts the mode
with, and MATLAB's method names. It is matched with case and bounded as a word, exactly as `SPELLINGS` is,
so `HALF_UP` defeats the carry whether or not it sits in a code span and `q/2` never does. Matching with
case is what keeps the lower-case English words apart from the identifiers: "`half_up` is nearest" does
not name MATLAB's `Nearest`.

**A clause that names no rounding rule is about whatever the clause before it left named.** That replaces
the leading-pronoun test, which was a proxy for the same question, and it is what pairs the name across a
colon, a semicolon, a question mark and a full stop without any of the four being special-cased.

**A clause that opens with a pronoun still refuses the doc block's item.** A pronoun points back
explicitly, so where the clause before it left nothing named the subject does not fill in. That is the
rule the existing control at `tests.rs:289` and the corpus pair about a tie at -2.5 both rest on, and it
is kept as it stands.

## What this costs, named rather than discovered later

`every_clause_boundary_separates_the_two` at `tests.rs:189` asserts that for each of eight cuts,
"`half_up` goes up{cut}and takes ties away from zero." stays silent. Under the decision above it fires,
and it should: the sentence says the mode takes ties away from zero. The test states a law that the colon
finding refutes, so it is narrowed to the boundary claims that are true, which are that a later clause
naming another rule is not paired with the earlier one and that a blank line starts afresh.

The clause cut is still observable and still mutated. What changes is that it is no longer observable
through this sentence, so the corpus carries pairs that separate the cut from the carry.
