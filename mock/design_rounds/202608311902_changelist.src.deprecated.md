# Src changelist: the three base primitive crates, and tests for the gate that certifies them

**Date:** 2026-08-31
**Round:** the base primitive design round, resumed after its canon-gate refusal
**Scope:** three new crates under `mock/crates/`, and test suites for five lints in `mock/lints/`
that today have none.

## What lands

### The three crates, from the locked doc changelist

`arvo-format`, `arvo-placement`, `arvo-strategy`, each implementing the design document locked in
`202608311902_changelist.doc.lock.md` and nothing beyond it.

Each carries its contracts, the shipped members of the inventories the design says are open or closed,
and tests asserting the laws that design names. The laws are asserted over the whole matrix of shapes
the contracts admit rather than over a chosen sample, because choosing which instantiations to include
is choosing what not to find out.

### Tests for five lints that gate this source

`no_std_enforcer`, `no_alloc_enforcer`, `no_dynamic_dispatch`, `no_runtime_grow` and
`arvo_bits_traits_only` have zero tests between them. Every canon-facing lint in the same directory
carries between eleven and twenty-three test markers, so the habit exists and these five were missed.

They are the five that read `mock/crates/`, which is to say they are the gate certifying every line
this changelist adds. Two have measured holes, established in
`mock/research/sketches/base-primitives-gate/p4_the_untested_enforcers_have_holes.rs`, which
transcribes both predicates verbatim and carries a control that fails if the transcription is wrong:

`no_std_enforcer` matches an import prefix, so a qualified path expression such as
`std::process::exit(0)` reaches the platform and passes. So do a renaming import, a brace-first
import, and an import behind a `cfg` attribute on the same line.

`no_alloc_enforcer` matches the literal `" String"` against the untrimmed line, so the same expression
is caught when indented and missed at column zero, and an identifier beginning with the word behind
whitespace is a false positive.

**The tests land in this round rather than a later one** because the alternative is writing the first
crate from this canon under a gate nobody has checked, and a green report from a gate with holes is a
fabricated claim of correctness about this changelist's own source.

**The tests are written first and are expected to fail.** A test that pins the intended behaviour and
fails is the specification; the lint is then fixed until it passes for the right reason. Where a hole
is real and the fix is larger than this round, the test stays red and marked, which is the honest
state and not a defect.

## Two derived calls in the source, marked as derived

**The type-level coordinates are primitive-typed, and they have to be.** The operating constraints say
public API positions use the stack's own primitives rather than bare `u8`..`u128` and friends. A const
generic parameter and an associated const are type-level coordinates, and the language requires them
to have a primitive type; there is no arvo type to reach for at the bottom of the stack, because this
is what defines it. So the constraint is read as binding value positions, and type-level coordinates
are outside it by construction rather than by exemption. **Flagged rather than assumed**: if a later
round decides otherwise, it is these three crates' signatures that change.

**The quantum law is affine in the magnitude**, carried as a base and a slope rather than as a
function. `proposal::membership_of_the_representable_set_is_one_affine_predicate` says affine, so the
two families differ in one coordinate: the slope is zero for the constant-quantum family and nonzero
for the magnitude-indexed one. This is what lets membership be a free `const fn` over a format's
associated items instead of a method the trait would have to make const, which would need a feature
nobody sanctioned. It is a reading of the ratified word rather than an invention, and it is the reading
that makes the contract expressible under `min_generic_const_args`.

## What is deliberately not here

**No arm.** An arm carries a predicate over a region and its own justification in words, and none has
a measurement behind it yet. The concepts arms are gated over are what lands; the arms are later work.

**No overflow mode bound to a preset.** `does_warm_wrap_or_clamp` is open in the registry and
`ruling::the_strategy_intents_are_not_clear_cut` forbids writing the per-strategy statements as
settled. The presets bind an objective and select an adaptation; which mode each names is not written.

**No chain, no strategy-object component count.** Both are out of the round's scope.

**No repair to `dimension::overflow_policy`**, which still lists `panic` among its values while the
ratified factoring requires an adaptation to be total. The dimension set is append-only, so the repair
is a note on that row and belongs to whoever next touches the axis.

## How this changelist expects to be checked

`cargo mock check` green at strict, and the laws each design names asserted over the full matrix. A
contract test that will not compile is kept as it stands and its compiler error recorded, because that
says the property has no expressible form against the implementation, which is a stronger result than
a wrong value and is not restructured away.
