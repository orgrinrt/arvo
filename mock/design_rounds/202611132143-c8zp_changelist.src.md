# Source changelist: the delegated operations get an oracle of their own

**Date:** 2026-11-13
**Round:** 202611132143-c8zp, branch `work/arvo-values`.
**Design:** `202611132143-c8zp_changelist.doc.lock.md`, and under it
`mock/crates/arvo-numeral/DESIGN.md.tmpl`.

## Current state

The tests of `div`, `convert`, the product at a non-zero exponent and the three `fits_` verdicts of
those compare the value with the function of `arvo-format` that the value calls. `take` at a capacity
of zero returns the slice it was given. The consumer test finds the build directory three levels above
the test binary, and its second test passes with the paths fixed at build time.

## Changes proposed

### `arvo-numeral`, source

`src/accumulator.rs`: `take` asserts in a const block that `CAP` is at least one. `ADMITTED` is
unchanged, so `empty`, `of` and `plus` keep a capacity of zero.

### `arvo-numeral`, tests

`tests/common/oracle.rs`, new: `rounded`, a quotient of two wide integers under a mode; `completed`,
an integer onto a signature's range by its policy; and `quotient`, `product` and `converted`, each the
slot of a result and whether the rounded result was a member. It reads the mode, the policy, the range
and the quantum's exponent from the signature and calls no function of `arvo-format` that computes.

`tests/common/mod.rs`: `check_product` reads `oracle::product` for the slot and for `fits_mul`.

`tests/the_quotient.rs`, `tests/the_conversion.rs`: the sweeps read `oracle::quotient` and
`oracle::converted`. The named cases are unchanged.

`tests/fixed_point_product.rs`: the control computes the slots' product completed with no scaling and
compares it with the value's product.

`tests/the_accumulator.rs`: `finish` is compared with `oracle::completed`.

`tests/a_consumer_crate.rs`: the scratch directory is `tmp` under the nearest ancestor of the test
binary that holds `CACHEDIR.TAG`. `the_crate_directory_is_read_when_the_test_runs` runs the binary
again with another `CARGO_MANIFEST_DIR` and reads back the directory it resolved. The earlier second
test is removed.

`tests/compile_fail.rs`, `tests/ui/`: the pair `take_at_a_capacity_of_zero_is_refused` and
`take_at_a_capacity_of_one_compiles`, with the diagnostic. Seven passing halves import only what they
use.

`tests/count/mod.rs`: one assertion that the plain target's own test repeats is removed.

`tests/band_*.rs`: the tests that also assert the difference and the negation say so in their names.
