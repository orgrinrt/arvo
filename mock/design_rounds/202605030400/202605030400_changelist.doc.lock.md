Section content:

- One-paragraph framing: `Ieee` is the IEEE float-width seal. Relocates this
  round (202605030400) to live alongside its supertraits `[const] Identity`
  and `[const] Bounded`, both already shipping from `arvo-strategy::arith`.
  The previous home at `arvo/src/float.rs` left the trait declaration one
  layer above its supertraits with no need for the higher-layer placement.

  ```rust
  pub const trait Ieee:
      sealed::Sealed + Copy + Default + PartialEq + PartialOrd
      + [const] Identity + [const] Bounded + 'static
  {
      const WIDTH: u16;
  }

  impl const Ieee for f32 { const WIDTH: u16 = 32; }
  impl const Ieee for f64 { const WIDTH: u16 = 64; }
  ```

- Companion trait note: `FromU8Ieee` rides along, same orphan-rule
  constraints, same logical family. Show its const-trait shape:

  ```rust
  pub const trait FromU8Ieee {
      fn from_u8_ieee(n: u8) -> Self;
  }

  impl const FromU8Ieee for f32 { fn from_u8_ieee(n: u8) -> Self { n as f32 } }
  impl const FromU8Ieee for f64 { fn from_u8_ieee(n: u8) -> Self { n as f64 } }
  ```

- Seal commitment paragraph: the seal admits `f32` and `f64` today. Future
  widenings (`f16` / `bf16` / `f128`) extend the seal in this file plus the
  existing `impl_bounded_identity_f!` macro invocation in
  `arvo-strategy::arith`. The seal lives in a private `sealed` module with
  marker impls for the admitted types only.

- WIDTH typing note: `WIDTH: u16` stays bare-primitive-typed for Round 2.
  Round 3 (#313) lifts it to `Width` once the broader bare-`u16` to typed
  `Width` substrate sweep cascades through the bridge family.

- Re-export note: arvo facade re-exports `Ieee` and `FromU8Ieee` from
  arvo-strategy so consumer imports through `arvo::Ieee` and
  `arvo::FromU8Ieee` keep working.
