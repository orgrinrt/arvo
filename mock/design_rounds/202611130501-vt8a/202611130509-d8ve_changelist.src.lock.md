## CHANGE: every crate's manifest names its readme

Files: `mock/crates/arvo-bits/Cargo.toml`, `mock/crates/arvo-format/Cargo.toml`,
`mock/crates/arvo-placement/Cargo.toml`, `mock/crates/arvo-strategy/Cargo.toml`,
`mock/crates/arvo-numeral/Cargo.toml`. Each gains `readme = "README.md.tmpl"`. In `arvo-numeral`'s, the
comment over the mutant features says the tests fail while one is on, rather than that they expect a
mismatch.

## CHANGE: the rung tests

File: `mock/crates/arvo-numeral/src/tests.rs`. `Wrong::check` asserts every rung agrees with the oracle,
with no reading of the mutant features. The per-width functions compute the 8-bit rung only where the
width fits it. A second macro expands widths 9 to 12, and two tests run every pair at those widths in
the 16, 32 and 64-bit rungs, signed and unsigned, under both policies.

## CHANGE: the bands

Files: `mock/crates/arvo-numeral/tests/common/mod.rs` and the four `band_*.rs`. `Tally::check` takes the
band's name only and asserts no `add` disagreed, naming how many did. The two verdict tests in
`band_1_to_8.rs` go, with their imports and the module documentation's sentence on them.

## CHANGE: the assertion tests

File: `mock/crates/arvo-numeral/tests/the_plain_markers_assert.rs`, new, compiled under
`debug_assertions` only. At `Int<4, _>`: `add`, `adapted` and `from_raw` each asserting under `Wrap` and
under `Saturate` with the site's message expected; each site's twin under `Wrapping` and `Saturating`;
and the plain markers quiet on what fits.

## CHANGE: the consumer crate

Directory: `mock/crates/arvo-numeral/tests/consumer/`, new: a `Cargo.toml` with an empty `[workspace]`,
path dependencies on `arvo-format` and `arvo-numeral` with no feature line, its `Cargo.lock`, and
`src/main.rs` reaching every public item and asserting what it reads.

File: `mock/crates/arvo-numeral/tests/a_consumer_crate.rs`, new: runs the consumer with the `cargo` that
runs the test, `--locked --offline`, into `CARGO_TARGET_TMPDIR`, and fails with its output when it does
not build and run.

File: `mock/crates/arvo-numeral/tests/compile_fail.rs` loses the consumer case, and
`tests/ui/a_consumer_with_no_feature_line_compiles.rs` is deleted.

## CHANGE: the red output of each mutant
