# Topic: the packed word's lane contract, tested over raw values

**Date:** 2026-11-20
**Scope:** `arvo-bits`, tests only

The third review of `work/arvo-packed-word` found the test `a_lane_agrees_with_cast_and_with_bit_zero` comparing `Lane` for `Bits<N>` and `Bool` against the expressions of its own impl bodies, and the masks in `Word::get` and `Word::with` unreached by any test, since every field value in the suite already masks in `from_low` and `low`.

## Decisions

1. The tautological test goes. The width matrix states the `Lane` contract for `Bits<N>` over raw values at every width from one to sixty-four: the low `N` bits kept, none above. A test states it for `Bool`: bit zero read, nothing above it written.
2. A consumer `Lane` four bits wide that keeps and hands back every bit is a field of a 64-bit layout in the law tests, and a test shows a write of it and a read of it reaching no bit outside the field. This is what the design's sentence on a leaking value promises.
3. No source and no design changes. The design already states both laws.
