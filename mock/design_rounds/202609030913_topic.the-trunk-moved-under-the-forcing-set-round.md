# The trunk moved under the forcing-set round, and five files were rewritten twice

## What is wrong

The round that closed at `202609022011` landed on `dev` while the same subject
was still open on `feat/the-primitives-a-consumer-names`. Both sides rewrote the
same paragraphs and the same tests, from the same finding, and neither is a
superset of the other. So the branch cannot merge: five files conflict and none
of them resolves by taking a side.

Four of the five are authored prose or authored tests. The fifth, `docs/FORMAT.md`,
is generated and is regenerated rather than resolved.

The phase gate refuses the merge commit, and it is right to. mockspace excuses a
merged file byte-identical to one parent, because nobody authored it, and
deliberately does not excuse a hand consolidation, because somebody did. A round
is what carries an authored change, so the consolidation is a round.

## What each side says, and what the consolidation keeps

`src/width.rs`, the module doc. Both sides say the type count is unsettled and
say it differently: `dev` adds that two separate derivations reached different
counts, the branch adds that a number written here would wear the door's
authority without having earned it. Neither clause is in the other. One sentence
carrying both.

`DESIGN.md.tmpl`, two hunks, and the branch's reading supersedes `dev`'s. `dev`
says the forcing sets are disjoint from the slot range's; the branch says a verb
belongs to as many sets as it has force sites, so `cancelling_slot` and
`has_additive_identity` each carry a second site on the adjacent line and the
sets overlap by construction. Disjointness is what the branch's own round set out
to refute, so keeping `dev`'s sentence would put the refuted claim back beside
its refutation. What `dev` carries that the branch does not is the clause saying
the open question is this tier's to settle, which the canon does not decide, and
that clause is folded in.

`src/tests/obligations.rs`. The two sides are the same three arms under different
fixture names, and the branch is the later one: it deduplicated the fixture to
`NoDenominator`, which is already declared with the other wrong constructions
above, where `dev` declared a second copy under a local name. `dev` alone carries
`a_coordinate_is_readable_off_the_impl_without_the_obligation_firing`, the
shortest of the three routes, which belongs and is rewritten over `NoDenominator`.
`dev` alone also carries the third assertion in the override arm, that the two
declarations differ only in the obligation, which transfers unchanged because
`NoDenominator` and `DisarmedObligation` differ only in `ADMITTED`. The lead
comment counts the arms, so its count moves with them.

`tests/compile_fail.rs`. The branch is a superset: same two cases as `dev`, plus
the `trybuild` case for a cancelling phase reaching the slot range. Nothing to
fold.

## Scope

`arvo-format` only, and no new claim about the design. Doc side: `DESIGN.md.tmpl`
and the regenerated `docs/FORMAT.md`. Source side: `src/width.rs` module docs,
`src/tests/obligations.rs`, `tests/compile_fail.rs`.
