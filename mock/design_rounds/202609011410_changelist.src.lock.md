# Src changelist: the other ratio constructor, and two sweeps that could not fail

**Date:** 2026-09-01
**Round:** the ratio fix stopped at the function a reviewer named
**Scope:** `mock/crates/arvo-format/src/apply.rs`, `mock/crates/arvo-format/src/format.rs`, `mock/crates/arvo-format/src/apply/tests.rs`, `mock/crates/arvo-format/src/tests/the_predicate.rs`

## CHANGE: `Fraction::of` FROM reading every non-positive denominator as `ZERO` TO normalising a negative one by sign
File: `mock/crates/arvo-format/src/apply.rs`
Verification: `Fraction::of(3, -7)` answers `(-3, 7)`, `Fraction::of(3, 0)` is `ZERO`, and
`Fraction::of(3, i64::MIN)` and `Fraction::of(i64::MIN, -7)` both answer a denominator of `1`.
Asserted in `a_fraction_never_carries_a_denominator_that_cannot_divide`.

The same three-way branch `Phase::of` now carries, with one difference the types justify: a zero
denominator names no position for a `Fraction`, so it stays `ZERO`, where a `Phase` keeps its
numerator over one. Everything else is identical because the two contracts are.

## CHANGE: the `Fraction` sweep FROM asserting the denominator's sign TO asserting the value
File: `mock/crates/arvo-format/src/apply/tests.rs`
Verification: reverting the constructor to `if den <= 0 { Self::ZERO }` fails the arm at
`Fraction::of(-5, -8)`. Run and recorded before the fix was kept.

The existing arm swept `-8`, `-3` and `-1` and asserted only `denominator() > 0`, which every input
satisfied while `of` was discarding all of them. It gains `i64::MIN` in the denominator row, the
value assertion on the pairs that normalise, the exactly representable `of(3, -7)`, a
zero-denominator control, and the two `i64::MIN` pairs pinned as whole-numbered.

## CHANGE: the two `i64::MIN` pins FROM asserting the denominator TO asserting the pair
File: `mock/crates/arvo-format/src/tests/the_predicate.rs`
Verification: both assertions name a tuple, and the values are `(3, 1)` and `(i64::MIN, 1)`.

Round `202609011250` added these and asserted `denominator() == 1` on each, which is the defect the
same test names twelve lines above: a sign assertion never asks about the value. Neither the sign nor
the magnitude survives those two pairs, and the assertion now says so rather than leaving a reader to
assume the sign is kept.

## CHANGE: the two constructor docs FROM implying the sign survives TO naming what is lost
File: `mock/crates/arvo-format/src/format.rs`, `mock/crates/arvo-format/src/apply.rs`
Verification: `grep -c 'Neither the sign nor the magnitude survives'` over the two files returns one
each.

Both paragraphs said the two `i64::MIN` pairs are read as whole-numbered, which is true and reads as
though only the denominator moved. They say the sign goes too, and `apply.rs` carries why the fix
reached it late.
