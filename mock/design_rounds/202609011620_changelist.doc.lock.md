# Doc changelist: the identity turns on a whole-multiple phase

Source topic: `202609011620_topic.the-identity-turns-on-a-whole-multiple-phase.md`.

## `mock/crates/arvo-format/DESIGN.md.tmpl`

Two statements, both of the retired claim.

The phase paragraph says a nonzero phase decides whether the set carries an
additive identity at all, and that a half-step-biased grid contains neither zero
nor one. The first is corrected to the whole-multiple rule. The second is kept,
narrowed to the geometry it was measured on, because it is true there and it is
the reason the coordinate is carried.

The law paragraph says a nonzero phase removes the additive identity and that the
test asserts it. It states the whole-multiple rule instead, and says what the test
now asserts, which is both directions rather than one.

## `mock/crates/arvo-format/src/format.rs`, the rustdoc

The trait's `PHASE_NUM` comment and the free function's comment both carry the
claim. Corrected in place. The function's comment additionally says a nonzero
phase takes one off the grid with zero, which a probe measured false at a
half-step grid whose quantum is above one, so that clause goes rather than being
narrowed: what it was reaching for is the half-step geometry, and the sentence
above it already says that.

## `mock/crates/arvo-format/src/lib.rs`

The `Biased` point's own doc says a nonzero phase takes the identity off. Same
correction, and the sentence that the law asserting it keeps the coordinate
honest stays true, because the law does.

## What is not touched

`proposal::membership_of_the_representable_set_is_one_affine_predicate` carries
the same clause at a standing a ratified ruling stamped. A design round does not
correct canon, and this one derives from the affine-predicate sentence that row
opens with rather than from the phase sentence it closes on.
