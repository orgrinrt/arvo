The source follows the design as the doc changelist locked it. The registry, readme and template
changes touch no source. What changes is the admission's carrier check, the placement's account of its
obligation, and three additions to the tests.

## Current state

`Sole::ADMITTED` forces `<SlotsOf<S> as SoleCarrier>::ADMITTED`, a provided constant an outside row may
replace with `()`. The placement's module doc and the obligation's doc say an outside row is stopped
wherever its obligation is forced, so the two forms cannot drift apart. No arithmetic test holds a
fixed-point signature at a non-zero exponent. No test observes `Abort` in a release build.

## Changes proposed

### CHANGE: `arvo-numeral`, the admission asserts `carrier_agrees`

`src/admit.rs` imports `carrier_agrees` and asserts `carrier_agrees::<SlotsOf<S>>()` in
`Sole::ADMITTED` in place of forcing the row's own constant, with a message naming the row, the wrong
rung and the rule. The doc of `Sole::ADMITTED` says so.

### CHANGE: `arvo-placement`, the obligation's account

`src/sole.rs` module doc and the doc of `SoleCarrier::ADMITTED`: every row of this crate forces it; an
outside row may replace it, so a crate needing the agreement asserts `carrier_agrees` itself. No code
changes.
