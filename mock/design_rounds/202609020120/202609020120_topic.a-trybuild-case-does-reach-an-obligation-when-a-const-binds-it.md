# Topic: a trybuild case does reach an obligation, when a const binds it

**Date:** 2026-09-02
**Phase:** TOPIC
**Scope:** `mock/crates/arvo-format/DESIGN.md.tmpl`

## The design says the opposite of what the crate ships

One paragraph of this crate's design states that an obligation's refusal cannot be a `trybuild` case,
because `trybuild` runs `cargo check`, an obligation is a const evaluated at monomorphisation, and
`check` skips codegen. Stated that way it is false, and the crate refutes it five times over.

`tests/ui/a_law_over_no_magnitudes_is_refused.rs` binds the predicate to a `const` item rather than
calling it from `main`, and its committed `.stderr` is `E0080`, produced under `cargo check`. Four
more cases in the same directory do the same thing. The suite runs them and they pass.

**What decides it is where the obligation is forced, not which tool runs.** A const is evaluated where
it is used. Forced from a runtime call it is reached at codegen, which `cargo check` skips, so a
`trybuild` case written that way reports a refused program as compiling and a doctest, which builds a
binary, catches it. Forced in a `const` item it is reached at check time, and then a `trybuild` case
sees it and pins the exact diagnostic.

So both shapes ship and each covers what the other cannot. The source already says this: the
`ADMITTED` documentation on `Quantum` and `Slots` and the module documentation of
`src/tests/obligations.rs` all state the where-forced reading. **Only the design page carries the old
one**, which is the tier that is supposed to be the oracle for the other two.

## How it got there

The sentence is mine, written into the design during the trunk merge that brought the trunk's own
obligations across. The trunk's version of it was accurate about its own crate, which forces every
obligation from a runtime call; this branch had already built the const-bound form and the merge put
the trunk's sentence beside this branch's five counterexamples without either noticing the other.

## What this round does not do

**It changes no source.** The crate already behaves as the corrected paragraph describes, and both
shapes of refusal are already shipped and asserted. What is wrong is one paragraph of prose on a
rendered page.
