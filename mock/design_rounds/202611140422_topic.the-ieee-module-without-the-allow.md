# The IEEE 754 module without the allow

**Date:** 2026-11-14
**Scope:** `arvo-format`'s IEEE 754 parity suites: the shared module under `tests/ieee754/` and the three
targets that declare it.

`64bb4a57` on `dev` took the `allow(dead_code)` off the shared IEEE 754 module by giving each suite only
what it uses, the format tables moving into the suites that run them. This branch's underflow suite, a third
target, brought the allow back with its two draws, `held_below` and `underflow`, which only it reads, and
by not reading the whole-range sweep the other two read; the branch was refused landing for it.

What each target leaves unused decides the split. The underflow draws are read only by the underflow suite,
so they move into it, the way the format tables did. The sweep over a format's whole range, `inputs` and
`misses` over it, is read by the binary and the decimal suites and not by the underflow one, so it goes into
a module of its own under `tests/` that those two declare, as `ties_away` is. What is left in the shared
module is read by all three, and the allow and its comment come out. No case is dropped or changed, and the
three suites run as they did.
