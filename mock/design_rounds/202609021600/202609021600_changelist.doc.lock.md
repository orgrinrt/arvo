# DOC changelist: consolidate the trunk and the branch on both published pages

Two files carry the conflicts and two more are generated from them. The
verification is the same one the previous round used, so the two rounds can be
checked against each other: take everything from the first `## ` heading onward
and count registry addresses in it.

```
awk 'NR>2 && /^## /{f=1} f' <file> | grep -coE '(ruling|proposal|question|dimension|obligation)::'
```

It returns zero on both templates. Run against the declaration block instead and
the count is what the trunk had, because neither side touched it.

The second verification is that no conflict marker survives anywhere in the tree,
which is one grep and is worth stating because a marker left in a generated page
renders into the published tree and reads as content.

## CHANGE: `arvo-format/DESIGN.md.tmpl` FROM two conflicting citation drops TO one that keeps both sides' facts
File: `mock/crates/arvo-format/DESIGN.md.tmpl`
Verification: the body count above returns zero. The declaration block still holds ten addresses. `grep -c '^<<<<<<<'` returns zero.

Fifteen conflicts. Eleven take the branch, which is the side with no address in
it and no fact the trunk's version carries.

Three take the trunk. The phase paragraph is the one that matters: the branch
says a `Phase` constructor cannot produce a zero denominator, and it cannot say
that, because `Phase::of` is total and takes the pair as written. The two
paragraphs that explain where the condition actually sits, on `Phase::denotes`
and `Format::ADMITTED`, merged cleanly from the trunk and are already in the
file, so the branch's opening would contradict them. The trunk's opening also
drops a sentence about what the crate used to carry, which is the page's own
history and does not belong on it. The other two are line wrapping.

One is a consolidation rather than a choice. On the open `Slots` trait the
branch's first paragraph carries no address and the trunk's replacement for the
deleted confession is fuller than the branch's trailing clause, so the resolved
paragraph is the branch's opening followed by the trunk's bolded sentence.
