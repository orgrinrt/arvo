# Src changelist: the proof is invariant

**Date:** 2026-11-20
**Round:** `202611200755`, job `arvo-numeral-doors`. Changes `arvo-bits`, `mock/tools/the-positions` and the lints.
**Topic:** `202611200755_topic.the-proof-is-invariant.md`. **Doc changelist:** `202611200806_changelist.doc.lock.md`.

## `mock/crates/arvo-bits/src/`

CHANGE: `tier.rs`: `Within`'s field is `PhantomData<fn(B) -> B>`, invariant in its container; its doc says
the proof is of the width `B` declares, why it is invariant and that its auto traits no longer follow the
container's; the module doc says the guard is of the declared width (topic decision 2).

CHANGE: `lib.rs`: the crate doc says an index or an amount at or past the width a container declares is
refused (decision 2).

## `mock/crates/arvo-bits/tests/`

ADD: four `compile_fail` cases with their expected output, joining `REFUSED` in `compile_fail.rs`:
`a_proof_carried_to_a_narrower_container_is_refused` (`E0308`, decision 2),
`a_container_of_its_own_shifted_past_its_width_is_refused` (`E0080`),
`an_impl_of_the_callers_sequence_by_hand_is_refused` (`E0119`) and
`an_impl_of_the_callers_trait_without_its_supertrait_is_refused` (`E0277`) (decision 5).

CHANGE: `ui/a_proof_built_by_hand_is_refused.stderr`, regenerated for the new field type.

CHANGE: `common/mod.rs` gains `bit_of`, a bit read by division, and `shifted`, a shift built one bit at a
time; `the_bit_access.rs` and `the_bit_sequence.rs` take them in place of the host's shift and mask, and
their module docs say so (decision 6).

CHANGE: `the_bit_tier_in_a_constant.rs` evaluates all eleven operations in one constant through
`[const]` bounds, `every`, and holds each against its value written out (decision 7).

## `mock/tools/the-positions/`

CHANGE: `src/supply.rs`: `USize`, `Unsigned`, `Bits`, `BitWidth`, `BitAccess`, `Capacity` and `Dim` move
from `ARVO_GONE` to `ARVO_SHIPPED`, the docs of both lists and of the module say what ships, and
`ARVO_GONE` names the lint that keeps it (decision 4).

CHANGE: `src/tests/controls.rs`: the gone test asserts `Cap` and `BitPrim` gone and the seven names
supply (decision 4).

## `mock/lints/`

ADD: `a_name_filed_as_gone_is_exported_by_no_crate.rs` and its tests: a name on `ARVO_GONE` that a
crate's `lib.rs` exports on a `pub` line is a finding. The topic placed this as a control in the tool's
tests reading every `lib.rs` by path; the lint `no-source-include-in-test` refuses a test that includes
crate sources, and a list a crate's exports can make wrong is a state the project refuses to be in, so it
is a lint that gates (decision 4, as built).

ADD: `code_only_source.rs`'s `code_only_at`, the view-reading form of `code_only`, which the lint reads
each `lib.rs` through so a name in a string or a comment is not an export.

## `mockspace.toml`
