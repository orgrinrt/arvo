# nightly-bump-pass-3-rebless

Moving the toolchain pin to `nightly-2026-11-18` changes the text of compiler
diagnostics, so every trybuild `.stderr` fixture is blessed again for the new
compiler. Pass 1 (round 202611200111) did that for the fixtures that existed
then. `arvo-capacity` and `arvo-numeral-contracts` landed on `dev` afterwards
with fixtures blessed on the old compiler, so this round blesses those too and
the whole set once more after the merge.

## Scope

No design doc changes. The src changelist lists the pin, every `.stderr`
fixture of the earlier bump, the fixtures added in pass 1, the `arvo-capacity`
ones and the `arvo-numeral-contracts` ones.

## Known text-merge hazards

The two fixtures for a format without an identity or a one merged textually
from both sides and are blessed again from the compiler, not trusted.
