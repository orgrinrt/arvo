# Doc CL: rename arvo-narrow to arvo-refit

**Date:** 2026-04-30
**Round:** 202604301700
**Phase:** DOC

Per topic file decisions A-D, normalise every live doc-template
reference to the new crate name `arvo-refit`. Keep historical
references to `arvo-narrow-contracts` (the L0.5 trait crate that
merged into `arvo-bits-contracts` in round 202604280034) untouched
because that name is genuinely historical.

The current source tree has inconsistent references: some doc
templates already flipped to `arvo-refit` during round 202604300826
(when the rename was originally drafted in-flight, then backed out
in the polish round 202604301539), and some remained on
`arvo-narrow`. This round picks one canonical state across the
templates: `arvo-refit` everywhere, with the rename attribution
moved from "round 202604300826" to "round 202604301700" where the
templates name the round that performed the rename.

The prior round metadata (202604300826 closed) stays accurate as the
round that introduced `Widen<T>` and the cross-domain matrix; the
rename itself happens in this round (202604301700).
