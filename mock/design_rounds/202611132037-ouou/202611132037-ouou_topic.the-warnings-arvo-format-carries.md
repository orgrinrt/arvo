# the-warnings-arvo-format-carries

**Date:** 2026-11-13
**Round:** `202611132037-ouou`, job `arvo-format`, job 2 of track T2 of the arvo triage.
**Tickets:** `arvo_format_rounded_at_is_used_only_by_tests_and_warns_in_th`,
`arvo_format_s_rounded_at_is_dead_code_outside_tests_and_warn` and
`arvo_format_three_clippy_warnings_under_all_targets`.

## What is wrong

`cargo clippy -p arvo-format --all-targets` on the branch at `ea4fbd5a` reports four warnings, two in the
library and two in its tests.

`Rounded::at` in `src/apply.rs` builds a rounded position that sits on a slot already. Its one caller is
`apply/tests/mod.rs`, so every build that is not a test build warns that the function is never used. It
is a constructor of the type and belongs with it, so it stays beside `Rounded` and is compiled for the
tests only.

`cancelling_slot` in `src/format.rs` carries `#[must_use]` on a function returning `Maybe<Slot>`, and
`Maybe` is marked must-use itself, so the attribute says nothing. Clippy calls it `double_must_use`.

Two tests write by hand what the language or the integer already has: the error numerator in
`apply/tests/the_ratio_coordinate.rs` spells out an absolute difference that `u128::abs_diff` is, and the
count in `tests/the_identity/the_magnitude_range.rs` nests an `if` inside an `if let` that one let chain
says.

The fourth warning the third ticket names, an `if` with identical blocks at `apply.rs:169`, is not
reported on this branch any more, so it needs nothing.

## What changes

`Rounded::at` gains `#[cfg(test)]`, the redundant `#[must_use]` goes, and the two tests take the
spelling clippy names. Nothing a caller sees moves, and the design says nothing of any of it, so the doc
changelist carries no template edit.
