# src changelist

Executes the doc changelist: an independent oracle for the applied map swept over both ends of the index,
the hand-picked matrices it subsumes taken out, the `core`-binding arm of the platform-width lint read as
tokens with a use-tree walk, and the shadowing probe made to run every arm through `run.sh`.

## CHANGE: `apply/tests/the_oracle.rs` ADDS an oracle sharing none of `apply`'s arithmetic
File: `mock/crates/arvo-format/src/apply/tests/the_oracle.rs`
Verification: the file declares `struct Wide` (a two-limb integer, `hi: i128`, `lo: i128`) and the free functions `rounded`, `completed` and `answer`, and imports nothing from `crate::apply`: `grep -c 'crate::apply' mock/crates/arvo-format/src/apply/tests/the_oracle.rs` returns 0. `cargo test -p arvo-format --lib apply::tests::the_oracle::` runs `the_two_limbs_agree_with_the_index_wherever_the_index_holds_the_answer`, `past_the_index_the_two_limbs_keep_the_value`, `the_oracle_reads_each_mode_by_its_words` and `the_oracle_completes_by_each_policy_s_words`, all green.

## CHANGE: `apply/tests/the_oracle_sweep.rs` ADDS the sweep of the shipped map and every broken map against the oracle
File: `mock/crates/arvo-format/src/apply/tests/the_oracle_sweep.rs`
Verification: the feed is anchors `i128::MIN`, `i128::MAX` and both range ends, whole offsets `-8..=8`, quarters `0..4`, dithers in eighths; the formats are the eight near-end and at-end `Over` ranges, `Integer<3>`, and the four off-zero references (200-wide and 2^64-wide, each sign); every mode and every policy. `the_feed_reaches_every_band_around_both_ends` pins the feed's reach. `every_declared_signature_answers_as_the_oracle_does` runs `adapt` and `panic_on_overflow` through every `Signature<F, Adapt<M, P>>`; `the_shipped_map_answers_as_the_oracle_does` runs `complete_slot` and `lands_within` directly. `the_sweep_reports_every_broken_map` asserts each of the nine maps in `the_broken_maps.rs` disagrees with the oracle, and whether the first disagreement is inside the index or only past it.
