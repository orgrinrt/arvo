# Topic: rename the imported lint pack to mockspace-extra-lints

**Date:** 2026-07-31
**Phase:** TOPIC
**Scope:** the `[lint-crates]` entry in the root `mockspace.toml`; no source, no templates.

## What and why

The shared lint pack renamed its crate from
`mockspace-hilavitkutin-stack-lints` to `mockspace-extra-lints` when it moved
to the split lint-trait ABI on the pack repo's `dev` branch. The engine's
builtin set simultaneously dropped `no-bare-vec`, `no-box` and `no-float` as
standalone registrations (`no_alloc` subsumes the first two, `no_bare_numeric`
the third); arvo's config carried no override sections for those names, so the
rename is the whole change here: the `[lint-crates]` entry now names
`mockspace-extra-lints` against the pack repo's `dev` branch. arvo was already
launcher-shape (root `mockspace.toml`, `mockspace_branch = "dev"`, no
bootstrap build.rs; the surviving `mock/crates/arvo/build.rs` is the
arvo_fast_math cfg declaration and stays).

## The gate blessing this commit carries

An engine fix (mockspace PR #11) repaired inherited hook environment that had
been making the commit-gate lints run blind under hooks. With the gate now
actually seeing, arvo's pre-existing debt (52 forbidden-imports errors,
arvo-tensor importing `arvo::{Cap, USize}` against the L2 layering rule)
blocks any commit that triggers an unscoped lint run, including this
config-only one. Op blessed a per-instance `--no-verify` for this migration
commit (2026-07-31, in-session). The red predates this change, is untouched by
it, and clearing it belongs to the arvo formalization arc; the next
source-touching commit in the affected crates is, by design, the one that
clears it.
