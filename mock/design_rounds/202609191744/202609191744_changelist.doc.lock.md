## `crates/arvo-format/DESIGN.md.tmpl`, the platform-width points

The manifest-rename paragraph no longer says the rename reaches `::core` "as long as the path the
edition's prelude import names ... resolves in the renamed crate" without saying whose prelude that is.
It says this is what a `no_std` dependent needs, names `arvo-format` as the `no_std` crate the rest of
the paragraph is about, and states the std case as its own sentence: a dependent carrying no
`#![no_std]` needs none of it, since its own prelude comes through the name `std` rather than `core`,
shown by the new arm.

## `crates/arvo-format/DESIGN.md.tmpl`, the laws the applied map owes tests for

"each mode's and each policy's meaning as this crate documents it" becomes "as the implementation reads
it". The crate documents `Clamp` as pinning to a declared bound; the oracle applies it as `Saturate`,
which the next sentence already says is a reading taken from the implementation rather than the
documented one, so the framing sentence is brought into line with what it introduces.
