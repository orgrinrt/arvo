# Src changelist: normalise a negative phase denominator by sign

**Date:** 2026-09-01
**Round:** a negative phase denominator carries a value and a zero one does not
**Scope:** `mock/crates/arvo-format/src/format.rs`, `mock/crates/arvo-format/src/tests/the_predicate.rs`

The doc changelist states what each non-positive denominator becomes. This writes it down.

## CHANGE: `Phase::of` FROM reading every non-positive denominator as one TO normalising a negative one by sign
File: `mock/crates/arvo-format/src/format.rs`
Verification: `Phase::of(3, -7)` answers `(-3, 7)`, `Phase::of(3, 0)` answers `(3, 1)`, and
`Phase::of(3, i64::MIN)` and `Phase::of(i64::MIN, -7)` both answer a denominator of `1`. Asserted in
`a_phase_never_carries_a_denominator_that_cannot_divide`.

The branch splits three ways rather than two. A positive denominator is kept. A zero one, and the two
`i64::MIN` pairs whose exact form needs a magnitude past the type, are read as one. Everything else
moves the sign to the numerator, which is a rewrite of the same value rather than a coercion to a
different one.

The struct's doc comment and the constructor's both said the non-positive case maps to a
whole-numbered phase. Both are rewritten to say what actually happens, with the `i64::MIN` bound
named, because a doc comment describing the previous behaviour is the shape that let this stand.

## CHANGE: the guarding sweep FROM asserting the denominator's sign TO asserting the value
File: `mock/crates/arvo-format/src/tests/the_predicate.rs`
Verification: mutating the normalising branch back to `Self { num, den: 1 }` fails the arm at
`Phase::of(-3, -9)`. Run and recorded before the fix was kept.

The sweep already ran every interesting pair and asserted only `denominator() > 0`, which every one
of them satisfied under the lossy constructor. It gains the value assertion on the pairs that
normalise, the two `i64::MIN` pairs pinned as whole-numbered, the exactly-representable `of(3, -7)`
case that is the whole finding, and a zero-denominator control so the value assertion cannot swallow
the case it does not cover.
