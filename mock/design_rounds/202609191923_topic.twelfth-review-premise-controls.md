# twelfth-review-premise-controls

review146l on PR #146 at 2d80b771 found one blocking finding and six
catalogue items. This round fixes B1, C1, C2 and C5. C3 (the manifest arms'
own `target/`), C4 (machinery named in rendered text already on `dev`, which
needs a mockspace change) and C6 (canon rows, op's) are not touched.

B1. The flipped controls `run.sh` generates show that an item is evaluated and
that its comparison decides whether the arm builds. They do not show that the
comparison could come out the other way on the arm as written: `W == W`
flipped is `W != W`, refused, so the arm passes. The header says a check that
could never fail shows up as unexpected, and `arms.md` labels the self-check
"a vacuous check", and neither holds for that class. The tree carries one
instance: `the_shipped_spelling_alone_is_silent.rs` compares two reads of the
same primitive.

C1. The control for that class is to vary the premise. Every arm's premise is
a fake width, a shadow's or a stand-in's `const BITS: u32 = <n>;`. `run.sh`
gains a premise pass: every arm rebuilt with that literal set to the host's
pointer width, the one value where a read of the fake width and a read of the
real one agree. Each arm declares which items read the fake width and which
read past it; an item reading it has to change outcome, and an item reading
past it has to hold. The premise pass cannot judge an item that reads past the
fake width, since it is expected to hold either way, so a spelling pass drops
the leading `::` from `::core` in every arm holding such an item and expects
exactly those items refused.

The self-check becomes committed arms under `selfcheck/`, each written to be
flagged by a stated set of passes, including the review's three shapes
(`W == W`, `1 == 1 && W == W`, `W != 7` against 8), a resisted `W == W`, the
shipped spelling's old assertion, and a vacuous conjunct beside a real one,
which no pass flags and which pins that limit.

`the_shipped_spelling_alone_is_silent.rs` loses its assertion and is run as a
positive control that builds and checks no value.

C2. The item scan reads string literals with their escapes, so an escaped
quote in a message and an `==` inside a string no longer misread the message
or the comparison. A message the harness cannot match against rustc's panic
text, one with another escape, a brace or a line break, is flagged before any
pass. Self-check arms cover the escaped quote, the `==` in a string and the
refused escape.

C5. The off-by-one citation is in the fix report, not in any committed file;
a grep for it over the tree returns nothing, so there is nothing to change.

No canon row is touched.
