# Topic: the capacity crate after its second review

**Date:** 2026-11-20
**Phase:** TOPIC
**Round:** `202611200102-e4xa`, job `arvo-capacity`, amending rounds `202611200029-bfwv` and `202611200049-ol81`.
**Source topics:** none open; the findings of the second review of `work/arvo-capacity`.

The second review found two places where the source says less than the design promises. The length the
seal holds is reachable from outside through the supertrait, as `C::LEN.host()`, so a host integer and
an adaptation the crate chose are public after all, and a second way to read the count bypasses `count`.
`Dim<N>` is a unit struct, so `Dim::<4>` is a value a consumer can construct, where the design says
there is no capacity to construct. The seal's refusal also names a workspace ticket, which a stranger
reading a compiler message cannot resolve.

## What the canon says

Unchanged: `obligation::a_count_fixed_at_build_that_sizes_arrays_from_generic_code`, a proposal asked
of op. Nothing here touches it; this round makes the source hold what the design already says.

## D1. The length is held in a type nobody outside can read

The seal's length is a newtype, `Len`, whose field is private and whose constructor and reader are the
crate's alone. `C::LEN` stays nameable through the supertrait, but nothing can be done with it outside.

Options it was chosen among: hiding the supertrait's const altogether is not possible while the seal
holds it, since a supertrait's items are reachable wherever the subtrait is; moving the length to a
function on a private trait reached by a private bound is the same leak by another path. The newtype
is the narrowest change that closes it.

## D2. `Dim<N>` is a type with no values

`Dim<const N: usize>` is an empty enum, so it names a capacity and constructing one is refused.

## D3. The seal's refusal names nothing outside the crate

The note says the trait is sealed to `Dim<N>` and that whether it stays sealed is open, without naming
a ticket. The `FIXME` beside the trait keeps the ticket's name, where only a maintainer reads it.

## D4. Tests

A compile-fail pair: reading `C::LEN.host()` from outside is refused, beside `count` doing the same read,
which builds. A second pair: constructing `Dim::<4>` is refused, beside `Dim<4>` named as a type, which
builds. `the_count_reads_in_a_constant` goes, being covered by the edge test and the spread. The mutant
run is redone over the whole crate.
