# Src changelist: the rounding step as a pair

**Date:** 2026-09-19
**Round:** review repairs on `feat/platform-width-types-on-a-wider-slot-range`
**Scope:** executes the rounding half of `202609190948_changelist.doc.lock.md`.

## CHANGE: `round_slot` FROM the slot above as `down.saturating_add(1)` TO a `Rounded` pair

File: `crates/arvo-format/src/apply.rs`, `crates/arvo-format/src/addition.rs`

`pub(crate) struct Rounded { down: i128, up: Bool }` with `at`, `down`, `step`, `lands_within` and a
test-only `index`. `round_slot` returns it. `complete_slot` takes it: in range by `lands_within`; wrap as
`lo + ((down mod span) - (lo mod span) + step) mod span`; saturate and clamp on `down < lo`.
`panic_on_overflow` answers `!lands_within`. Addition's verdict reads the offset as
`(down - low) + step`.

Verification: `grep -n 'pub(crate) struct Rounded' crates/arvo-format/src/apply.rs` returns one.

## CHANGE: the suites FROM pinning the saturated step TO the exact answers at the top

`apply/tests/the_top_of_the_index.rs` is new, over `AtTheTop` and `AtTheBottom` (now `pub(crate)`).
`the_edges.rs`'s top-of-index arm asserts the wrap of one past `i128::MAX`, 0, and refuses -1.
`the_ratio_coordinate.rs`'s carry arm reads the pair at the top. `apply/tests/mod.rs` reads the pair
through two local helpers, since every position it feeds is near zero.

## Why this changelist is deprecated

The doc changelist says the pointer-width checks that can run are one ignored catalogue test. The crates
forbid `std::process` (`forbidden-imports`, scope `*`), and a test that drives cargo at a foreign target
needs it, so that sentence cannot be made true inside the crates. The doc changelist is reopened to say
what is actually done instead.
