# Topic: the floor's contracts are spelled in the machine's own types, so nothing outside can implement them

**Date:** 2026-09-01
**Phase:** TOPIC
**Status:** filed deliberately without doing it. Changing what a trait contract is spelled in is a
change to a design, which takes the code under that design with it, and that is its own round.

Found by the standards-alias round, from the consumer side, while trying to write MATLAB's `fi` as a
crate of its own.

## What was measured

A new crate implementing `Format` and `Quantum` over `arvo-format` was refused at fifteen positions by
`no-bare-numeric` and `arvo-types-only`. Every one is a position the implementor does not choose:

- **Six are const generic parameters**, `const W: u32` and `const F: i32`.
  `obligation::a_primitive_for_every_position_a_bare_number_would_take` carries op's own quote
  excepting exactly that position: no bare integer at an API position other than in const generics,
  for a smoother and more ergonomic surface, and even there only where the alternative is genuinely
  painful. **There is no alternative at all here**, painful or otherwise, because nothing the stack
  owns may sit in a const generic argument. So the lint refuses a position op excepted, and it will
  refuse it in every crate that ever carries a const generic numeric parameter.
- **Nine are associated consts whose type the implemented trait fixes.** `Quantum` declares `BASE` and
  `SLOPE` as `i32` and `MAGNITUDES` as `u32`. `Format` declares `PHASE_NUM` and `PHASE_DEN` as `i64`.
  `Slots` declares `MIN` and `MAX` as `i64`. An implementor writes what the contract says.

**So no crate outside `arvo-format` can implement `Format`.** Nothing had tried before, so nothing had
found out.

## Why the exemption is not the answer, and why it is what hid this

`mockspace.toml`'s `[primitive-introductions]` exempts `arvo-format` because it introduces the numeric
category, and its own comment describes the exemption narrowly: the crate is the one bringing the
substrate to the table, so **whatever it does internally** to define it is legitimate. The comment also
calls the list an auditable architectural claim rather than a permission list.

What is being exempted is wider than that description. The contracts are part of the public surface
rather than something the crate does internally, and they are spelled in the machine's own types, so
the exemption is what makes them writable at all. `ruling::the_format_spine_is_canon` is ratified and
says the concept is closed and the inventory of admitted instances is open; in practice the inventory
is open only to the crate that is exempt.

## What is not the answer

**Adding the implementing crate to `[primitive-introductions]`.** It introduces no substrate, so the
claim would be false, and the config's own anti-bypass note says the list is a claim rather than a
permission.

**A `SHAME.md.tmpl` entry.** Tried. It does not key on either lint and silences nothing.

**Inline suppressions.** Fifteen of them is what `strict-by-design-quality-pressure` names as not the
response, and the gate is correct on nine of the fifteen: an implementor being unable to write a
contract in the stack's own types is a defect in the contract.

## What the round would have to decide

**What a coordinate of the affine predicate is spelled in.** The membership predicate is
`phase + slot * quantum(magnitude)` and the design already typed one of its coordinates: `Slots`
carries `WIDTH: Width` beside `MIN: i64` and `MAX: i64`, so the width coordinate is the stack's own
and the slot coordinate is the machine's. That asymmetry is the shape of the question.

**What happens at a const generic argument**, where nothing the stack owns may sit and where op's
exception already applies. This half may need no design change at all, only a lint that knows about
the exception, and that lint lives in another repository.

**Whether the two halves are one round or two.** The const generic half is about an instrument; the
contract half is about a design and takes code with it.

## What is already enumerated, so the round does not start from nothing

Every bare-primitive public position in the tree is inside `arvo-format`; `arvo-placement` and
`arvo-strategy` are clean and use `Width`, `Bool`, `Objective`, `Occupancy` and `Placement`
throughout. Measured with a positive control on the filter.
