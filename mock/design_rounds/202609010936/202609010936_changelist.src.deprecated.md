# Src changelist: MATLAB's five coordinates, and the two that have nowhere to land

**Date:** 2026-09-01
**Round:** the standards-alias round
**Scope:** `arvo-standards`, which is new, and nothing else.

## CHANGE: `arvo-standards` FROM a documented crate with no items TO the MATLAB alias
File: `mock/crates/arvo-standards/src/lib.rs`
Verification: `cargo mock --lint-only --commit` reports no `no-empty-crate` finding for the crate, and
`grep -c 'pub struct Fi<\|pub struct Ufi<\|pub struct FractionLength<' mock/crates/arvo-standards/src/lib.rs`
returns 3.

The crate scaffolded in the doc phase carries module documentation and no declarations. It gains the
three types the coordinate map needs and the two aliases that name a convention's pair.

## CHANGE: the fraction length FROM an expression in a const argument TO a `Quantum` implementor
File: `mock/crates/arvo-standards/src/lib.rs`
Verification: the crate builds with no `#![feature(...)]` attribute, and
`grep -c 'generic_const_exprs' mock/crates/arvo-standards/src/lib.rs` returns zero.

MATLAB's fraction length is the negation of arvo's quantum exponent, so the direct spelling is
`Constant<{-F}>`, an expression in a const generic argument position. That needs
`generic_const_exprs`, which is forbidden.

**The wall is not real and this is the whole of getting past it.** What the expression computes is a
quantum law, so it becomes one: `FractionLength<F>` implements `Quantum` with `BASE` set to `-F` in
the impl body, where an arbitrary expression is legal, and `Fi` bounds on the `Quantum` contract
rather than on the expression. `SLOPE` is zero and `MAGNITUDES` is one, which is the constant family,
because a fixed-point convention has one step and not a ladder of them.

A negative fraction length falls out with no case of its own: `F` is an `i32` and the negation lands
on a positive exponent.

## CHANGE: the rounding map FROM prose in the design TO four renamed re-exports and two `FIXME`s
File: `mock/crates/arvo-standards/src/lib.rs`
Verification: `grep -c 'FIXME' mock/crates/arvo-standards/src/lib.rs` returns 2, and both name the
registry row that decides them.

Ceiling, Floor, Zero and Convergent are `Ceil`, `Floor`, `TowardZero` and `HalfEven`, re-exported
under MATLAB's names so the mapping is a type-level fact rather than a sentence somebody has to
believe.

Nearest and Round are not mapped. MathWorks documents Nearest as ties toward positive infinity and
Round as ties toward the greater absolute value; arvo names one nearest-not-to-even mode, and
`question::is_the_rounding_vocabulary_complete_at_six` and
`question::which_tie_direction_an_unqualified_nearest_names` are both open on what it is. Mapping
either would close an open question inside a design.

## CHANGE: the width bound FROM unstated TO the slot range's own, carried by the alias
File: `mock/crates/arvo-standards/src/lib.rs`, `mock/crates/arvo-standards/tests/ui/word_length_past_the_ladder.rs`
Verification: `cargo test -p arvo-standards` passes with the `trybuild` case asserting the refusal, and
its recorded stderr names the slot range rather than the alias.

`Fi<W, F>` carries `Signed<W>: Slots` and `Ufi<W, F>` carries `Unsigned<W>: Slots`, so a word length
the ladder does not admit fails to build at the declaration with the diagnostic `arvo-format` already
supplies. **No runtime report and no widening**, per `ruling::never_a_runtime_check_and_one_lowered_path`.

MathWorks documents the word length to 65535 and the ladder stops at 62, so this refuses ordinary
declarations. That is the finding rather than a defect in the alias, and the compile-fail case is
where it is recorded so it cannot be lost.

## CHANGE: the parity arms FROM nothing TO MathWorks' own five worked examples
File: `mock/crates/arvo-standards/src/tests.rs`
Verification: `cargo test -p arvo-standards` runs them, and every asserted stored integer and printed
value in the file is one MathWorks publishes rather than one arvo returned.

The five examples the `fi` reference page prints, with the word length and fraction length it reports
for each:

| MATLAB | word | fraction | printed |
|---|---|---|---|
| `fi(pi)` | 16 | 13 | 3.1416 |
| `fi(pi,0)` | 16 | 14 | 3.1416 |
| `fi(pi,1,8)` | 8 | 5 | 3.1562 |
| `fi(pi,0,8)` | 8 | 6 | 3.1406 |
| `fi(pi,1,8,3)` | 8 | 3 | 3.1250 |

Each arm feeds pi as an exact rational, adapts it through the alias, and asserts the stored integer
and that the stored integer over two to the fraction length is the value MathWorks prints. The
expected stored integers are 25736, 51472, 101, 201 and 25, each computable by hand from the printed
value and the fraction length, so an arm can be checked without running anything.

**They are asserted over every nearest mode arvo ships, and that is not a shortcut.** Pi times a power
of two is never a tie, so no arm reaches a tie rule, and an arm that cannot reach one has measured
something true of both. That is what makes these safe to write while the tie question is open, and it
is stated here so nobody later reads them as having settled it.

The five also stay inside their declared ranges, so no arm reaches an overflow policy either. Both
absences are asserted by a control rather than left to be noticed.

## CHANGE: the two gaps FROM prose TO a catalogued red and a compile-fail case
File: `mock/crates/arvo-standards/src/tests.rs`, `mock/crates/arvo-standards/tests/ui/word_length_past_the_ladder.rs`
Verification: `cargo test -p arvo-standards -- --ignored` runs the catalogued arm and it fails, naming
the row that closes it.

The rounding gap is a test asserting what has to become true: that some shipped mode takes a tie
toward positive infinity, which is MATLAB's Nearest. It is red, marked
`#[ignore = "catalogue: ..."]` with the registry row that decides it, and it turns green when the
vocabulary gains the name rather than when anybody edits it.

The width gap is the `trybuild` case above. A refusal is a build failure and a build failure is
expressible, so it is pinned rather than described.

## What is deliberately not here

**No IEEE 754.** In scope by op's bound and its own round.

**No change to `arvo-format`, `arvo-placement` or `arvo-strategy`.** The alias is written over the
surface they already have, which is the claim this round is testing.

**No seventh rounding mode and no widened ladder.** Both are what the round found, and both sit behind
rows the registry holds open or behind a question about the slot index's carrier.

## How this changelist expects to be checked

`cargo test --workspace` in `mock/`, and `cargo mock --lint-only --strict` green. The parity arms
checked by hand against the table above, since each expected stored integer is the printed value times
two to the fraction length, rounded.
