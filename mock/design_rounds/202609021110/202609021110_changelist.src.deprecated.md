## CHANGE: add an exhaustive search pinning `has_an_exact_form`
File: `mock/crates/arvo-format/src/apply/tests/the_ratio_coordinate.rs`
Verification: `cargo test -p arvo-format the_predicate_agrees_with_an_exhaustive_search` passes, and inverting either branch of `has_an_exact_form` makes it fail.

A new test walks every `(n, d)` pair over a value set and asserts the helper
agrees with a decision made by reduction rather than by the helper's rule.
Reduction means dividing both operands by their greatest common divisor in a
carrier wide enough that nothing overflows, moving the sign onto the numerator,
and asking whether both coordinates of that reduced form still fit. Every exact
form is a positive multiple of the reduced one, so the reduced one fitting is
both necessary and sufficient. It shares no branch with the helper, so the two
can disagree.

The value set is every integer from `-64` to `64` crossed with itself, plus the
extremes the rule turns on: the minimum, three values above it, the maximum, two
below it, and both parities at a magnitude in between. That is around twenty
thousand pairs and runs in milliseconds. Exactness is a question about
divisibility and sign rather than about the width of the carrier, so the dense
band is where the arithmetic lives and the extremes are where the rule's own
branches are.

The test carries its own control: a rule with the parity clause removed is run
over the same walk, and the walk is asserted to find a pair where it disagrees
with the reduction. Without that, a walk that had quietly stopped visiting the
saturating region would pass.
