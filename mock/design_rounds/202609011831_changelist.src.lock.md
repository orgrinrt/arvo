## CHANGE: eight comments FROM naming the machinery that produced them TO naming the property
File: the five files above
Verification: `grep -rniE "this round|the round|round \`?20[0-9]{10}|a reviewer|the reviewer"
mock/crates/arvo-format/src/` returns only lines about the rounding coordinate, which is the crate's
own vocabulary. The eight are:

```
apply/tests.rs:8            "four tests round `202608311902` shipped"
apply.rs:62                 "the one function a reviewer named"
tests/the_coordinates.rs:8  "a law about a type this round introduced"
tests/the_identity.rs:13    "The predicate this round replaced"
tests/the_identity.rs:26    "The predicate this round replaced, kept so the control can be run"
tests/the_inventory.rs:14   "the shape this round measured against"
tests/the_inventory.rs:63   "what the round measured against"
tests/the_inventory.rs:327  "The reviewer's construction, values verbatim"
```

Tests ship, so a comment in one is read by whoever reads the crate, and a design round, a reviewer or
a round's timestamp is machinery that means nothing to them. **Every reason those comments carried
stays**, in the words the reason is actually in: what the four replaced tests did wrong, why the
construction is kept, why the arms are written over a foreign contract.

**Two of the eight are from the round two before this one**, which is why this is one change over a
class rather than a list of five. The same reflex produced them across four rounds and nothing in the
crate caught it.

File: `mock/crates/arvo-format/src/tests/the_predicate.rs`,
`mock/crates/arvo-format/src/tests/the_inventory.rs`
Verification: `grep -c "previous cut" mock/crates/arvo-format/src/tests/` returns three, unchanged.

"An earlier version of this stopped at 32 and the unswept half is where the count overflowed" is a
statement about the code, it carries the reason a sweep runs its whole range, and a reader can act on
it. The design template uses the same construction about itself in three places.

**The test is whether a stranger can do anything with the sentence.** One that tells them not to
shorten a sweep is worth its lines; one that tells them which round produced a file is not.
