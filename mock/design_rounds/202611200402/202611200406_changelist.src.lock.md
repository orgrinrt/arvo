# Src changelist: the bit tier owns its index guard

**Date:** 2026-11-20
**Round:** `202611200402`, job `arvo-numeral-doors`. Overhauls `arvo-bits`.
**Doc changelist:** `202611200402_changelist.doc.lock.md`.
**Topic:** `202611200400_topic.the-bit-tier-owns-its-guard.md`.
**Sketches:** `mock/research/sketches/202611200400_bit-tier-guard-at-the-trait/` (the shape, committed
before the doc changelist locked) and `mock/research/sketches/202611200415_bit-tier-mutants-after-second-review/`
(the red runs over the tests below), superseding `mock/research/sketches/202611200335_bit-tier-mutants-after-review/`.

## `mock/crates/arvo-bits/src/tier.rs`

ADD: `pub struct Within<B, const I: u32>(PhantomData<B>)`, private field, with `pub const NEW: Self`
asserting `I < B::WIDTH.count()`, the index mutant `arvo_mutant_bits_index` admitting the width itself,
and the message naming a container `w` bits wide (topic decisions 2 and 3).

ADD: `pub const trait BitAccessAt: BitWidth + Copy` with `bit_at` and `with_bit_at`, each taking
`Within<Self, I>`; `pub const trait BitSequenceBy: BitWidth + Copy` with `shift_up_by`, `shift_down_by`,
`rotate_up_by` and `rotate_down_by`, each taking `Within<Self, K>` (decision 2).

CHANGE: `BitAccess` has `BitAccessAt` as its supertrait and `BitSequence` has `BitSequenceBy`, in place of
`BitWidth + Copy`; each has one impl, `const impl<B: [const] BitAccessAt> BitAccess for B` and its
sequence twin, making the proof with `Within::<Self, _>::NEW` and calling through (decision 2).

CHANGE: `Bits<N>` implements `BitAccessAt` and `BitSequenceBy` in place of `BitAccess` and
`BitSequence`, each method calling the inherent method of the same operation (decision 2).

CHANGE: the module doc and the trait docs say the tier refuses an index or an amount past the width for
every container, in place of the obligation each implementor owed (decision 2).

## `mock/crates/arvo-bits/src/ops.rs`

DELETE: the private `Within<const N: u32, const I: u32>` and its `ADMITTED` (decision 2).

CHANGE: every method taking an index or an amount forces `crate::tier::Within::<Self, _>::NEW` (decision 2).

ADD: the mutants `arvo_mutant_bits_bit`, `arvo_mutant_bits_and`, `arvo_mutant_bits_or`,
`arvo_mutant_bits_xor`, `arvo_mutant_bits_is_empty`, `arvo_mutant_bits_shift_down` and
`arvo_mutant_bits_rotate_down` in their methods, and a module doc line on the flags (decision 4).

## `mock/crates/arvo-bits/src/lib.rs`

CHANGE: re-exports `BitAccessAt`, `BitSequenceBy` and `Within` beside the four traits; the crate doc says
the refusal is the tier's, once for every container (decision 2).

## `mock/crates/arvo-bits/Cargo.toml`

CHANGE: `check-cfg` declares the seven new mutant flags (decision 4).

## `mock/crates/arvo-bits/tests/`

CHANGE: `compile_fail.rs` takes two cases that must build and thirty-nine refusals, and its module doc
says the guard is the tier's and the index mutant never reaches trybuild (decisions 1, 2 and 3).

ADD: `tests/ui/` cases at the edges, `a_bit_at_one_of_one_bit_is_refused`,
`a_written_bit_at_one_of_one_bit_is_refused`, the six `..._sixty_four_of_sixty_four_bits_is_refused`;
past the width, `a_bit_at_the_largest_index_is_refused`, `a_shift_down_past_the_width_is_refused`
(decision 1).

ADD: `a_container_of_its_own_builds_below_its_width` (must build), `a_container_of_its_own_past_its_width_is_refused`,
`a_container_of_its_own_past_its_width_in_a_constant_is_refused`, `an_impl_of_the_callers_trait_by_hand_is_refused`,
`a_proof_built_by_hand_is_refused` (decision 2).

CHANGE: the `.stderr` of the existing index cases, which now name `Within::NEW` and, for the generic
calls, the tier's one impl.

DELETE: the algebraic assertions in `the_bit_logic.rs` (involution, `xor` with itself, commuting, De
Morgan, the intersection test, associating), `the_bit_access.rs` (reading back, rewriting) and
`the_bit_sequence.rs` (a rotation's count, the round trips, the rotation down by `N - K`), and
`common::few`, which only the associating law used (decision 5).

CHANGE: `the_bit_logic.rs`'s module doc says the algebra follows from the equalities (decision 5).
