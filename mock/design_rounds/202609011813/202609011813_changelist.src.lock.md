## CHANGE: `arvo-placement`'s tests FROM signatures over the shipped points TO one over a format they declare
File: `mock/crates/arvo-placement/src/tests.rs`
Verification: `grep -c "impl Format for" mock/crates/arvo-placement/src/tests.rs` returns one, and
`grep -rc "impl Format for" mock/crates/arvo-strategy` stays at zero, so this is the first member of
the format inventory declared anywhere the bare-primitive pack reads.

The derivation is a function from a declared signature to a placement, and every signature this crate
tested was over one of the four shipped points. **A format written here rather than borrowed is what
says the derivation is over the contract**, and it is written out of an ambient domain, a quantum law
and a slot range nothing ships, so all ten coordinates are supplied rather than the one `Format`
itself demands.

**The gate is what makes it an assertion rather than a demonstration.** `arvo-format` is named under
`[primitive-introductions]`, so the pack skips it whole and the format declared in its own tests is
written where nothing could refuse a host integer at a coordinate. This file is read by the pack, and
the control that says so was run before the declaration was written: a bare `i64` planted at the end
of it was refused by `no-bare-numeric` and by `arvo-types-only`, both at error level, and then
removed. The topic records the output.

**What is asserted is this crate's own law rather than a restatement of the format contract's.** The
derivation reads the foreign format's declared width, both arms produce a placement from it, and the
two objectives coincide at sole occupancy and differ at shared, exactly as they do for a shipped
point. **The control is that the foreign format's width is not one any shipped point in this file
produces**, so the arms are reading the declaration rather than answering from a width they already
had.
