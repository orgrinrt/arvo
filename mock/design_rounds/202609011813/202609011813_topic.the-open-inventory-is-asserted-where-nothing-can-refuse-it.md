# Topic: the open inventory is asserted where nothing can refuse it

**Date:** 2026-09-01
**Phase:** TOPIC
**Scope:** `mock/crates/arvo-placement/DESIGN.md.tmpl`, `mock/crates/arvo-placement/src/tests.rs`

## The finding, and it travels with a ratified ruling

`ruling::the_numeric_door_carries_the_coordinate_set_and_the_two_type_bound_is_not_canon` carries it
in its `note`:

> **One test-gate finding travels with this**, from seat 238 and verified:
> `the_format_inventory_admits_a_member_this_crate_does_not_know_about` is the only test asserting the
> ratified open-inventory clause, and it lives inside the crate-wide exemption, so it asserts that
> clause in the one crate where the rule it is about cannot refuse anything. It is narrow twice,
> because its `Ternary` also borrows the crate's own ambient, quantum and slot range and so writes two
> of the ten coordinates rather than all of them.

**The second half is already closed on this branch.** `WhollyForeign` in `the_inventory.rs` supplies
all ten coordinates out of an ambient, a quantum law and a slot range this crate does not ship. The
first half is not.

## Measured rather than argued: no format is declared anywhere the pack reads

```
grep -rn "impl Format for" mock/crates/arvo-placement mock/crates/arvo-strategy
```

returns nothing. Every `Format` in this repository lives in `arvo-format`, which
`mockspace.toml` names under `[primitive-introductions]`, so the bare-primitive pack skips it whole.
**The ratified clause that a new instance earns admission by supplying the concept's obligations is
asserted nowhere a consumer lives.**

## The control, run before the repair rather than after it

A bare `i64` was planted at the end of `arvo-placement/src/tests.rs` and `cargo mock --lint-only
--commit` was run. It refused, twice, at error level:

```
[no-bare-numeric] arvo-placement/src/tests.rs:439: [error] bare `i64` in src/tests.rs line 439
[arvo-types-only] arvo-placement/src/tests.rs:439: [error] bare `i64` in src/tests.rs line 439
```

and the phase gate refused the edit as well, which is the third line of that output and is the
ceremony working rather than a finding. The plant was removed. **So the file the repair goes in is one
the pack reads, and a coordinate written as a host type there stops the gate.** Without that control
the repair would be a claim about a lint nobody had watched fire.

## What this is not, and it is worth saying because a lint on this branch looks like it

This branch adds `mock/lints/a_contract_coordinate_is_not_a_host_primitive.rs`, which reads the exempt
crate and refuses a host primitive at a const there. That closes the exemption's hole for the
contract's own declarations and it is a different statement from this one.

**The lint is about what `arvo-format` may declare. This is about whether a crate outside it can
declare a format at all**, under the whole pack rather than under the one lint that reaches inside.
The two are one rule in two halves rather than two rules, and neither substitutes for the other: a
member joining the inventory from outside is the ratified clause, and nothing in the tree does it.

## Why here rather than in a new crate for the purpose

`arvo-placement` depends on `arvo-format`, is checked by the pack, and already declares signatures
over the shipped points, so a format of its own is the shape a consumer actually has rather than one
invented to satisfy a test. A crate existing only to hold one declaration would be an artifact of the
exemption rather than a consumer of the contract.

## Changes proposed

Declare a format in `arvo-placement`'s tests out of an ambient, a quantum law and a slot range nothing
ships, derive a placement from it, and say in that crate's design that it does so and why. The
assertion is that the derivation reads a format it has never seen, which is the placement crate's own
law over the format contract's open inventory.
