# Src changelist: warrant the spelling rewrite by the referent rather than the mode

**Date:** 2026-09-01
**Round:** the alias table claims more than it enforces
**Scope:** `mock/tools/rounding-vocabulary/src/lib.rs` and its tests.

## CHANGE: the spellings blurb FROM "the mode is not in doubt" TO the referent preservation that holds
File: `mock/tools/rounding-vocabulary/src/lib.rs`
Verification: one arm driving the real report path over a planted `nearest-half-up`, asserting the
warrant that holds is printed and the one that does not is gone. Plus the tool run against the registry.

The blurb reads "Mechanical. The mode is not in doubt, only how it is written, so each of these can be
rewritten to the name on the right without reading anything." It joins two claims and gives the first as
the reason for the second.

The second holds for all six rows. `ceiling` and `ceil` name one function, `round to nearest even` and
`half_even` name one, `nearest-half-up` and `half_up` name one, so the rewrite moves no region.

The first is a claim about the name on the right and is false for one row of the six. `nearest-half-up`
points at `half_up`, which denotes two functions on a signed domain, ties toward positive infinity and
ties away from zero. Three seats measured it separately: `228` section 2.4 by exhaustive function
equality against IEEE 754-2008, `229` finding 2 at `2^(W-1-F)` disagreeing values over `W` in
`{4, 6, 8, 10, 12}`, and `233` section 8 with the witness `p = -255, f = 1` giving `-127` against `-128`.
`233` names this table's `nearest-half-up` row as the site.

So the blurb keeps the claim that licenses the rewrite and drops the one that does not. The distinction
is not cosmetic here: the tool spends the section two below explaining that the retired word names two
operations differing "on exactly the rows where signedness is live", which is the same mechanism, so as
written it explains the mechanism in one section and denies it in another.

**The table, the grouping and the fifteen rewrites already landed are unchanged, and that is a
conclusion rather than an omission.** `nearest-half-up` really is a spelling of `half_up` and really is
mechanically rewritable, so the row belongs where it is and `a8ccf940` was faithful: the ambiguity sat
in the row before that edit and sits in it after, and no region moved. What was wrong was the reason
given, not the placement and not the edit.

## CHANGE: the `Ratified` standing's doc FROM a bare spelling statement TO one bounding what it claims

`Ratified` rows are counted as clean and the headline calls them "already spelled as the canon spells

sentence that overreached.

## CHANGE: the two readings of `half_up` FROM a hand check TO an arm with its controls
File: `mock/tools/rounding-vocabulary/src/tests.rs`
Verification: the disagreement count matches `229`'s closed form `2^(W-1-F)` at every `W` in
`{4, 6, 8, 10, 12}` and every `F` in `1..W`, and the published witnesses of `229` and `233` reproduce.

The blurb's wording turns on whether a name on the right denotes one operation, which is checkable
rather than a matter of taste, so the check that decided it is committed instead of being run once.

**The case that must fail is stated and was made to fail.** Implementing both readings as the same
expression drops the disagreement count to zero at every point, which the arm rejects. Two controls hold
the other side: the readings agree on an unsigned domain, and they agree at `F = 0` where no tie exists,
so the arm is measuring the signed tie rather than an arithmetic slip. The closed form is `229`'s and
was not derived here, so agreeing with it is a cross-check against a separately committed measurement
rather than a restatement.

The arithmetic is not the tool's, which does no arithmetic at all, and the file says so where it sits.

## CHANGE: the alias table's targets FROM unchecked TO pinned against the six
File: `mock/tools/rounding-vocabulary/src/tests.rs`
Verification: an arm over `ALIASES`, and the same arm rejects a planted row pointing outside the six.

An alias naming a target that is not one of the six would classify every row carrying it as `Alias` and
print an arrow to a name the ruling does not have, silently. Nothing checked it. This is not a defect
the corpus has today; it is one nothing would have caught.
