# Source changelist: one url spelling per git dependency

**Date:** 2026-11-13
**Round:** the roadmap step AR0, arvo's half, on `work/bench-harness-alive`.
**Topics consumed:** `202611130050-dd5m_topic.one-url-spelling-per-git-dependency.md`.
**Doc changelist:** `202611130050-dd5m_changelist.doc.lock.md`.

## CHANGE: notko is named by https in the workspace manifest

File: `mock/Cargo.toml`, the `notko` line of `[workspace.dependencies]`.

`git = "ssh://git@github.com/orgrinrt/notko.git"` becomes `git = "https://github.com/orgrinrt/notko.git"`. The
branch, the version and the features are unchanged.

## CHANGE: the mockspace bench crates are named by https in the bench manifest

File: `mock/benches/Cargo.toml`, the `mockspace-bench-core` and `mockspace-bench-harness` lines.

Both `git = "ssh://git@github.com/hiisi-digital/mockspace.git"` become `git = "https://github.com/hiisi-digital/mockspace"`.
The branch and the features are unchanged.

## CHANGE: the two lockfiles are regenerated

Files: `mock/Cargo.lock`, `mock/benches/Cargo.lock`.

Regenerated so that only the changed sources move: the notko `source` line in the first, the two mockspace
`source` lines in the second. Where cargo picks a newer commit of the branch while it does, the commit is
named in the message of the commit that changes the lock.

## Verified

`grep 'notko.git' mock/Cargo.lock` prints only lines beginning `source = "git+https://`.
