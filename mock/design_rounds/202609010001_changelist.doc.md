# Doc changelist: three false sentences, and the obligation that replaces them

**Date:** 2026-09-01
**Round:** the open-trait admission round, opened on the reviewer's fourth pass over PR #28
**Scope:** one crate design document. The source doc comments move in the src changelist with the
code they describe.

## What this changelist is

`DESIGN.md.tmpl` says `Slots` is implemented at the admitted widths **and nowhere else**. The trait is
open, so that is false, and the same document's contracts table already says the opposite by listing
`Signed` and `Unsigned` as **examples** beside "a consumer's own member sits beside them with no edit
to anything below".

The table is the half that matches the canon. Line 345 is the half that goes.

## The canon this declares

`ruling::the_format_spine_is_canon`, ratified, ratifying
`proposal::the_concept_is_closed_and_the_inventory_is_open`. **Both halves of that proposition are
load-bearing here and only one was read last round.** The inventory is open, so the trait is not
sealed. And a new instance "earns admission by supplying the concept's obligations", with closing the
concept while opening the inventory being "what makes admission a check rather than a negotiation", so
the obligations are checked rather than asked for.

`ruling::never_a_runtime_check_and_one_lowered_path`, ratified, for the check being at compile time.

## Files changed

| File | Change |
|---|---|
| `crates/arvo-format/DESIGN.md.tmpl` | removes the "and nowhere else" claim, states that the trait is open and what this crate implements, states the admission obligation an outside implementor owes, and states that the obligation is checked at compile time rather than asked for in prose |

## Why the obligation is stated as checked rather than as asked

A design that states an obligation and checks nothing is the same construction as the sentence being
removed: a claim about what holds, with nothing making it hold. **The document says what is checked and
where**, so a reader can go and find the check, and a later edit that removes the check makes the
document false in a way somebody can see.

## What is deliberately not here

**No seal on `Slots`.** The inventory is open by ratified canon, and a numeral wanting a slot range
that is neither shipped shape has to be able to supply one.

**No claim that the check is total.** It refuses what its assertions name and nothing else, and the
design says so rather than repeating the mistake one level up.

**No answer to how wide arvo goes.** Open, unchanged.

## Addendum: the claim is qualified, because it was too strong

Written after the source work found the limit, and the doc changelist reopened for it rather than the
qualification going only into a comment.

The design said the obligation is "refused at compile time". **Measured, that is true of a build and
false of a check**: the obligation is a const evaluated at monomorphisation, so `cargo build` refuses
and `cargo check` passes, because check skips codegen.

**An unqualified claim there would be the same shape as the three sentences this round removes**, so it
is qualified rather than shipped: an inadmissible range cannot reach a produced binary, and it can
reach a passing check.

The compile-fail case written for it was removed rather than kept green. `trybuild` checks rather than
builds, so it reported the case as compiling, which is a test asserting nothing. The width case stays,
because a missing impl is a type error and does fire at check.

What is pinned instead is the law, which answers the same question without forcing the const and
therefore works at check time and on a construction that has to keep compiling.
