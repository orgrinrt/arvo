## DESIGN: document the fixed-point divide alongside the multiply

File: `mock/crates/arvo-strategy/DESIGN.md.tmpl`

Add a paragraph after the fixed-point-multiply paragraph describing the fixed-point divide: the numerator is
shifted left by `F` and widened before the integer division (`(a << F) / b`), the logical-width-up-to-64
path uses the native `i128` / `u128` widen, the above-64 path needs 256/128 long division and is a tracked
follow-up, and the divide truncates toward zero (a documented asymmetry with the multiply's
floor-toward-minus-infinity). No new public types; `i_div_fixed` / `u_div_fixed` are methods on the existing
`IArith` / `UArith` traits.
