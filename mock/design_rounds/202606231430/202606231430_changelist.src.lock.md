# Src changelist: fixed-point divide

Round: 202606231430
Phase: IMPL
Scope: arvo-strategy, arvo

Mirrors the fixed-point multiply (round 202606231229). `i_div_fixed::<FRAC>(a, b) = (a << FRAC) / b` with the
numerator widened to avoid overflow. Truncates toward zero. No public API shape change.

## CHANGE: implement `*_div_fixed` in every arith macro
File: `mock/crates/arvo-strategy/src/arith.rs`
- `impl_*_arith_wrapping` (Warm): `(a.wrapping_shl(FRAC)) / b` in the 2N container; div-by-zero returns `a`.
- `impl_*_arith_wrapping_widen` (Hot/Cold 1..64): widen `a` to the native `i128`/`u128`, `<< FRAC`, divide by
  the widened `b`, narrow; div-by-zero returns `a`. This is the Quantity (N=48) path.
- `impl_*_arith_wrapping_widen256` (Hot/Cold 65..128): CATALOGUE. Naive in-container `(a.wrapping_shl(FRAC))
  / b` (wrong when `a << FRAC` overflows the 128-bit container); the 256/128 long division is a follow-up.
  A `#[ignore]`d test pins the intended value.
- `impl_*_arith_saturating` (Precise): `(a.wrapping_shl(FRAC)) / b` in the 2N container, then clamp the
  quotient to the logical bound; div-by-zero clamps to the logical MAX.
Verification: `cargo build -p arvo-strategy` green.
