# Doc changelist: the objective becomes a type, and the width bound becomes a set of impls

**Date:** 2026-09-01
**Round:** the severed-binding round, opened on the reviewer's third pass over PR #28
**Scope:** two crate design documents. No new crate.

## What this changelist is

Both blockers change what the design says. The first because the design states the objective is a
const parameter, which is the construction that severed generic composition. The second because the
design states a bound enforced by a refusal inside a function, and the enforcement moves into the set
of impls that exist.

## The canon this declares

`ruling::never_a_runtime_check_and_one_lowered_path`, ratified, for both: the branch has to erase at
monomorphisation, and a public function that panics on a runtime argument is a runtime check on the
public surface.

`ruling::the_derivation_is_a_placement_and_the_operation_set_is_an_admission_rule`, ratified, for the
ladder staying keyed on the objective through the change.

`ruling::cold_is_for_cold_paths_and_cold_storage`, ratified, unchanged: which arm packs.

## Why the const parameter had to go, stated in the design rather than only here

A const generic argument may not depend on a generic type parameter without a forbidden feature, so a
consumer generic over the strategy could not reach the ladder. **That is a composition property and
the design has to state it**, because the next person reaching for a const generic to get erasure will
otherwise make the same trade without seeing the cost.

The design says the marker is a type, that the associated const on it is what the arms read, and that
those two facts together are what buy erasure and composition at once.

**No answer to how wide arvo goes**, still open, still not this round's.
