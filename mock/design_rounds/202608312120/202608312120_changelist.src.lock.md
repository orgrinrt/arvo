# Src changelist: a marker instead of a const generic, and impls instead of a guard

**Date:** 2026-09-01
**Round:** the severed-binding round
**Scope:** `arvo-placement/src/lib.rs`, `arvo-strategy/src/lib.rs`, `arvo-format/src/slots.rs`, all
three crates' tests, and one dev-dependency.

## CHANGE: the objective FROM a const generic parameter TO a type-level marker
Files: `mock/crates/arvo-placement/src/lib.rs`, `mock/crates/arvo-strategy/src/lib.rs`
Verification: `grep -c 'adt_const_params' mock/crates/arvo-placement/src/lib.rs` returns zero, and
`a_consumer_generic_over_the_strategy_reaches_the_ladder` compiles and runs.

**Reproduced first, and the regression is mine from the previous round.**

```
error: generic parameters may not be used in const operations
    = help: add `#![feature(generic_const_exprs)]` to allow generic const expressions
```

A const generic argument may not depend on a generic type parameter, so a consumer generic over the
strategy could not reach the ladder. The suggested feature is forbidden. **Every test passed because
every test named a concrete preset**, which is setup that helps: the breaking path was never entered.

`ObjectiveKind` is a trait carrying `const OBJECTIVE: Objective`, with `objective::Footprint` and
`objective::Access` as its markers, and `Strategy::Objective` becomes an associated type. The arms
match on `O::OBJECTIVE`, a constant after monomorphisation, so the erasure the const generic bought is
kept while composition comes back.

**It removes `adt_const_params` rather than adding a feature**, which is the argument for this shape
over any other that also composes.

## CHANGE: the width bound FROM an assertion inside a function TO the set of impls that exist
File: `mock/crates/arvo-format/src/slots.rs`
Verification: `grep -c 'pub const fn checked_width' mock/crates/arvo-format/src/slots.rs` returns
zero, and the trybuild case records the refusal.

**Reproduced first**: deleting the upper-bound assertion left the whole suite green, and `Signed<63>`
then inverted its range with a negative count and `slot_in_range(0) == false`, silently, in release.

The distinction that decides the fix: the width-recovery class is gone **by construction** and the
slot-range coherence class was **guarded**. A guard can be deleted. So `Slots` is implemented by macro
at the admitted widths and nowhere else, `Signed<63>` has no impl, and the refusal is a trait-bound
error with `#[diagnostic::on_unimplemented]` carrying the message the assertion used to.

**The set cannot be widened by accident**: an impl past the bound overflows in its own body at the
definition site.

**This removes the non-blocking finding for free.** `checked_width` was `pub` and took a runtime
`u32`, so calling it at runtime in release panicked, which under I15 is a runtime check on the public
surface. It stops existing.

## CHANGE: `the_refusal_above_the_bound_is_recorded_where_it_can_be_reproduced` FROM a tautology TO a compile-fail case
Files: `mock/crates/arvo-format/src/tests.rs`, `mock/crates/arvo-format/tests/`
Verification: no test asserts `MAX_DECLARED_WIDTH == 62`.

It asserted a constant against the literal its own definition sets, which cannot fail, and its doc
argued the refusal could not be asserted from inside a running test. **That argument was false** and
`trybuild` is the mechanism the rules name for exactly this. The compile-fail case holds the
offending instantiation and asserts the diagnostic.

`trybuild` enters as a dev-dependency of `arvo-format` only. It does not reach the shipped crate, any
consumer, or the no-std surface.

## What replaces the deleted assertions

The properties the bound is actually about, over the admitted set rather than about the constant: that
every admitted width has a coherent range, that the count at the widest admitted width does not wrap,
and that the arithmetic naming the bound derives it rather than restating it.

## How this changelist expects to be checked

`cargo mock check` green at strict. `cargo test --workspace` in `mock/` with the generic-consumer test
present and the trybuild case passing, and the same counts under `--release`.
