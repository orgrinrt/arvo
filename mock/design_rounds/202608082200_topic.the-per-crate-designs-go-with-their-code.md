# Topic: the per-crate designs go with their code

**Date:** 2026-08-08. **Round two of the tree nuke.**
**Predecessor:** round `202608082157`, which deleted the crate sources and emptied the workspace.

Round one could not take the per-crate documents with it. `mock/crates/*/README.md.tmpl`,
`DESIGN.md.tmpl`, `BACKLOG.md.tmpl` and `SHAME.md.tmpl` are design tier and are gated to the DOC
phase, while source is gated to IMPL, and the two windows are never open at once. Fifty-two documents
remain describing sixteen crates that no longer exist.

## Why they go rather than staying as a record

`the-canon-design-code-chain.md`: a lower tier that survives a change above it becomes a claim about a
document that no longer exists. "Surviving code says the old design is still true; surviving design
says the old canon is still true. Both then get read, both mislead, and worse, both get **defended**,
because they are concrete and detailed and look authoritative next to an abstract statement."

A per-crate design describing deleted code is exactly that. It is more dangerous than the code was,
because it reads as intent.

The reproduction property is why this costs nothing: nuke the design and little is lost, because an
equivalent design can be written from the canon, and it may be a different design and still be valid.
There is no canon yet, which is the whole point of the current work, and writing one is what these
documents are in the way of.

## Scope

**Goes:** every `*.md.tmpl` under `mock/crates`, and the now-empty crate directories with them.

**Stays:** `mock/DESIGN.md.tmpl`, `mock/PRINCIPLES.md.tmpl`, `mock/WORKFLOW.md.tmpl`. They describe
the workspace rather than a crate's contract. They will need rewriting once a canon exists and designs
are derived from it. Editing them now would be writing design ahead of canon, which is the inversion
this whole exercise corrects.

## Recoverability

Unchanged from round one. Git history holds every byte and `origin/dev` carries the full tree.
