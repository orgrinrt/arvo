## `mock/crates/arvo-bits/src/lib.rs` (create)

## CHANGE: crate `arvo-bits` FROM nonexistent TO shipping `Bits<const N: u32>`
File: `mock/crates/arvo-bits/src/lib.rs`
Verification: `cargo check -p arvo-bits` succeeds; `grep -q 'pub struct Bits<const N: u32>' mock/crates/arvo-bits/src/lib.rs`.

Contents, mechanically:

- `#![no_std]`, `#![forbid(unsafe_op_in_unsafe_fn)]`, crate doc naming the obligation and ruling this
  design sits under, matching `DESIGN.md.tmpl`'s own framing.
- `#[repr(transparent)] pub struct Bits<const N: u32>(u64);` with the derive set `Clone, Copy,
  PartialEq, Eq, PartialOrd, Ord, Hash, Debug`.
- Private `const ADMITTED: ()` on the inherent impl, two `assert!` calls: `N >= 1` and `N <= 64`, each
  with its own message, mirroring `arvo_format::slots::Slots::ADMITTED`'s per-condition style.
- Private `const MASK: Self = if N == 64 { Self(u64::MAX) } else { Self((1u64 << N) - 1) };`.
- `pub const fn masked(raw: u64) -> Self`, forcing `Self::ADMITTED` then `Self(raw & Self::MASK)`.
- `pub const fn raw(self) -> u64`, returning `self.0`.
- `pub const fn cast<const M: u32>(self) -> Bits<M>`, returning `Bits::<M>::masked(self.raw())`.
- `#[cfg(test)] mod tests;` at the bottom, matching `arvo-placement`/`arvo-strategy`'s own convention.

## `mock/crates/arvo-bits/src/tests.rs` (create)

## CHANGE: test module FROM nonexistent TO covering the laws `DESIGN.md.tmpl` names
File: `mock/crates/arvo-bits/src/tests.rs`
Verification: `cargo test -p arvo-bits` green; every law in `DESIGN.md.tmpl`'s "laws this crate owes
tests for" section has a corresponding `#[test]`.

Cases, each named for the law it pins rather than for the function under test:

- Construction at the narrow boundary, `N = 1`: `masked(0)`, `masked(1)`, and `masked(2) ==
  masked(0)`, pinning that masking wraps rather than rejecting.
- Construction at the wide boundary, `N = 64`, exercising the `MASK` special case:
  `masked(u64::MAX).raw() == u64::MAX`.
- Round-trip at a width in the interior, `N = 28` (the obligation's own motivating width): for a raw
  value below `2^28`, `masked(raw).raw() == raw`; for a raw value with bits set above 28,
  `masked(raw).raw() == raw & 0x0FFF_FFFF`.
- An exhaustive sweep at `N = 8`: every `u8` value round-trips exactly through `masked`/`raw`, which is
  the whole value space at that width and is cheap to run in full rather than sampled.
- `cast` widening: `Bits::<28>::masked(x).cast::<32>().raw() == x` for `x < 2^28`, pinning that
  widening never drops a bit.
- `cast` narrowing: `Bits::<32>::masked(y).cast::<28>().raw() == y & 0x0FFF_FFFF`, pinning that
  narrowing masks rather than refusing.
- `cast` identity: `Bits::<28>::masked(x).cast::<28>().raw() == x & 0x0FFF_FFFF` for `x` including
  values above the mask, pinning `M == N` is not treated as a special no-op case that skips masking.
- Derive sanity: equality and inequality across two `Bits::<8>` values, confirming the derived
  `PartialEq` reads the wrapped value rather than being vacuous.

This module states the laws as assertions over concrete widths chosen for the reason named beside each
(boundary, interior, motivating case, exhaustive-where-cheap), not a sample chosen for convenience.
There is exactly one generic code path in this crate (no per-width macro-generated impls, unlike
`arvo_format::slots`'s `admit_widths!`), so the distinct behaviours to cover are the boundary at `N =
1`, the special-cased boundary at `N = 64`, and the ordinary interior case, which is what the widths
above are chosen to hit rather than an arbitrary handful.

## Correction against this changelist's first draft: `MASK` is typed `Self`, not `u64`

Writing the crate against `a-contract-coordinate-is-not-a-host-primitive` in its widened form found
that the lint refuses any const in an exempt crate carrying a host primitive type, private ones
included, by design: it reads every file, test modules and inherent impls alike, on the reasoning
that the door a primitive-introducing crate is given is for defining the crate's own types and not for
spelling an arbitrary internal constant in the host's vocabulary. `MASK: u64` fell inside that refusal.
Fixed by typing `MASK` as `Self` instead, which is also the more honest shape: a mask covering the low
`N` bits is itself a value at width `N`. `masked` reads `Self::MASK.0` rather than `Self::MASK`
directly. Nothing about the public surface, the laws, or the two `trybuild` cases changes.
