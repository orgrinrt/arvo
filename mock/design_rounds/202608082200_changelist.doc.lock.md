# Doc changelist: delete the per-crate designs

**Date:** 2026-08-08. **Round:** the per-crate designs go with their code.
**Source topic:** `202608082207_topic.the-per-crate-designs-go-with-their-code.md`.

## What this round does

Deletes all fifty-two `*.md.tmpl` documents under `mock/crates`, and the empty crate directories left
behind by round `202608082157`, which removed the sources those documents describe.

## The change

Every `mock/crates/<crate>/README.md.tmpl`, `DESIGN.md.tmpl`, `BACKLOG.md.tmpl` and `SHAME.md.tmpl`,
across sixteen crates, is deleted. Nothing replaces them, because there is no canon yet to derive a
design from, and writing one now would invert the order this work exists to restore.

`mock/crates` itself remains as an empty directory. mockspace panics rather than erroring when it is
absent (`can't read crates dir: NotFound`, `src/parse.rs:12`), and git cannot track an empty
directory, so a fresh clone reproduces the panic. That is an upstream defect, noted in round one's
topic, not something this round fixes.

## Not in scope

The root templates `mock/DESIGN.md.tmpl`, `mock/PRINCIPLES.md.tmpl` and `mock/WORKFLOW.md.tmpl`
describe the workspace, not a crate contract. They stay, and their rewrite waits on a canon.

`mock/benches` is untouched. Its artifacts are committed evidence that the canon panel's doability
claims cite.

## Lock criteria

- `find mock/crates -name '*.md.tmpl' | wc -l` returns 0.
- `mock/crates` exists and is empty.
- The three root templates are unmodified.
- Git history and `origin/dev` still carry every deleted byte.
