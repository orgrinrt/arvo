# a-sweep-keeps-each-format-s-walk-out-of-line

**Date:** 2026-11-13
**Round:** `202611132223-c27b`, job `arvo-format`, job 5 of track T2 of the arvo triage.
**Ticket:** `rustc_overflows_its_stack_in_llvm_building_arvo_format_tests`.

## What is wrong

`cargo test --release -p arvo-format --lib` does not build. rustc dies with SIGSEGV after about seven
minutes, its stack overflowed in LLVM's scalar evolution, `createSCEV` recursing through
`createAddRecFromPHI` and `createNodeFromSelectLikePHI`. The default profile builds the same tests in
about a minute. The ticket left two ways out open: raise rustc's stack in the workspace config, or find
the test shape that trips LLVM.

## Where it dies

The build was rerun on one codegen unit with `-C llvm-args=-opt-bisect-limit=-1`, which prints every pass
and the function it runs on. The last function named is `the_signed_oracle::agrees` at one signature,
through its machine passes, and then the IR passes of the next function start: freeze canonicalisation
and loop strength reduction on a loop, where the stack overflows. The same build emitted as IR on one
unit gives the module's order, and the function after `agrees` is
`addition::tests::the_step::the_step_is_the_signed_sum_of_the_values::<Difference>`, 120 thousand lines
of IR.

That function calls `Denotation::run` at 340 formats through two macros, every exponent from -8 to 8 at
five phases, two ambients and two slot ranges. Each `run` is a distinct monomorphic function, small, and
called once, so LLVM inlines every one of them into the caller. The walk's counters, `formats`,
`tuples`, `owed` and the mutant's two, then thread one chain of values through 340 loops in one body,
and scalar evolution follows that chain recursively when strength reduction asks about a loop near its
end. The recursion depth grows with the number of inlined walks, and at 340 it passes rustc's stack.

The same shape is everywhere in the suite: 41 implementations of `PerFormat` or `PerSignature`, each
called from a walk over widths, signatures or formats written out by a macro, `every_width` at 128
formats, the signature dispatch at eighteen, the edge sweeps at hundreds. The largest functions in the
emitted IR are all such walks, the division's edge sweep at 834 thousand lines. Only one of them crosses
the depth today; any of them can, whenever a walk gains formats.

## The shape

Each walk's `run` is marked `#[inline(never)]`. The walk over formats is then a list of calls, each
format's body is its own function, and the counters pass through `&mut self` in memory rather than as
one chain through every loop. Nothing a test asserts changes, since the attribute changes where the code
sits and not what it computes.

Raising `RUST_MIN_STACK` is not taken. It moves the depth at which the same shape fails, keeps the
120-thousand-line functions and their build time, and asks every machine building the tests to carry a
setting the shape made necessary.

A gotcha becomes a lint: `a-sweep-keeps-each-walk-out-of-line` reads `arvo-format`'s test modules and
refuses an `impl` of `PerFormat` or `PerSignature` whose `run` is not `#[inline(never)]`. It reads source
as text the way `every-function-the-format-ships-is-inline` does, and the functions that one keeps to
itself to find a `fn` and its attributes move into `rust_text.rs` so the two share them.

## What tests it

The release build of the lib tests, which died before and must finish, with the lib suite run on it,
and its time against the seven minutes it took to die. The lint's own tests: a walk impl with the mark
passes, one without it and one marked `#[inline]` are findings, and a `run` outside a walk impl is not
read. The mutant is the mark removed from `Denotation::run` alone, which the lint names.
