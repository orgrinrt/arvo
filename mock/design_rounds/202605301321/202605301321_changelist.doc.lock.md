### Change 1: new section before `## Array<T, const N: Cap>`

Insert a `## Capacity and Dim, the GCE-free capacity foundation` section: prose plus a `rust` fence showing the trait and marker. Prose and fences are not checked by the `design-doc-source-mismatch` lint (it checks backticked type names in markdown tables); the types land in this same round's src CL, so a table row is deliberately avoided until they exist.

The section documents:

- The trait surface: `type Array<T>: AsRef<[T]> + AsMut<[T]>`, `const CAP: Cap`, and `fn filled<T: Copy>(v: T) -> Self::Array<T>`.
- The marker: `Dim<const N: usize>` implements it with `type Array<T> = [T; N]` and `const CAP: Cap = cap(N)`.
- Why it escapes `generic_const_exprs`: no const expression sits in type position. `[T; N]` is plain min-const-generics; `cap(N)` appears only in the associated-const value position. This contrasts with the `[T; cap_size(N)]` shape that ICEs when the capacity is threaded through generic code as `cap_size(cap(N))`.
- The single bare `usize` site (`Dim`'s `const N`) as the irreducible array-length-grammar root, the one permitted bare primitive in the capacity-as-type convention, the same root that already forces `cap` and `cap_size` to exist.

## Refinements vs the validated sketch

The proving sketch (`hilavitkutin/mock/research/sketches/202605301145_capacity-as-type/`) carried a `const N: usize` associated const and `as_slice` / `as_mut_slice` functions on the trait. Both are dropped for the shipped shape:

- `const N` is redundant with `CAP` (the length is `cap_size(CAP)`) and would place a bare primitive on the public trait surface. Where generic code needs the length as a loop bound or index, it reads the slice (`as_ref().len()`) or `cap_size(Self::CAP)`, the existing canonical bridge.
- `as_slice` / `as_mut_slice` are redundant with the `AsRef<[T]> + AsMut<[T]>` bound; consumers call `.as_ref()` / `.as_mut()` directly.
- The constructor is renamed `empty(fill)` to `filled(v)`, matching the existing `Array::filled`. The sketch name was contradictory ("empty" taking a fill value).

These are the DOC-phase naming and access-surface decisions op delegated to the implementer. The result keeps the trait surface fully arvo-typed (`Cap`, GAT, no bare primitive) with the one bare `usize` confined to `Dim`'s const-generic root.
