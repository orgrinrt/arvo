## Intent

Ship the capacity-as-type foundation (convention T13). A fixed capacity becomes a TYPE implementing `Capacity`; the backing array is a GAT bound to a literal-length array in the concrete impl, so no const expression sits in type position and `generic_const_exprs` never runs over capacity arithmetic. This is the GCE-free replacement for the `Cap`-const-generic pattern that ICEs when threaded through generic code.

The test is written first (TDD): it asserts the exact generic-build-and-walk shape that overflowed `generic_const_exprs` under the `Cap`-const-generic form now compiles and runs, plus the typed-capacity surface and the 2-D composition that the container migration (task #651) depends on. The test file declares no `#![feature(...)]` gates; that absence is itself the proof the foundation escapes the GCE surface.

This round ships only the foundation types. The `Array` / `Matrix` / `Csr` / `BitMatrix` migrations are task #651; the engine `PlanDims` adoption is task #652. `cap` and `cap_size` are unchanged.

## CHANGE: new module `capacity` declaring trait `Capacity` and struct `Dim`
File: `mock/crates/arvo-tensor/src/capacity.rs` (new)
The trait: `type Array<T>: AsRef<[T]> + AsMut<[T]>`, `const CAP: Cap`, `fn filled<T: Copy>(v: T) -> Self::Array<T>`. The marker: `pub struct Dim<const N: usize>` with `impl<const N: usize> Capacity for Dim<N>` binding `type Array<T> = [T; N]`, `const CAP: Cap = cap(N)`, `fn filled<T: Copy>(v: T) -> [T; N] { [v; N] }`. `Dim`'s `const N: usize` carries a `lint:allow(no-bare-numeric)` citing the array-length-grammar root (the one permitted bare primitive in the convention; tracked #649).
Verification: `grep "pub trait Capacity" mock/crates/arvo-tensor/src/capacity.rs` and `grep "pub struct Dim<const N: usize>" mock/crates/arvo-tensor/src/capacity.rs` each return one match.

## CHANGE: new integration test `tests/capacity.rs`
File: `mock/crates/arvo-tensor/tests/capacity.rs` (new)
Tests: (1) `Dim<N>::CAP == cap(N)` exact and distinct per N; (2) `filled(v)` populates every slot at the exact backing length (`as_ref().len() == cap_size(CAP)`); (3) a fully-generic `fn` over `C: Capacity` that builds via `C::filled`, writes through `.as_mut()`, reads through `.as_ref()`, and walks the storage (the shape that ICE'd under `Cap`-const-generics); (4) 2-D composition `R::Array<C::Array<T>>` built and indexed generically. No `#![feature(...)]` gates.
Verification: `cargo +nightly-2026-05-28 test -p arvo-tensor --test capacity` passes; `! grep "feature(" mock/crates/arvo-tensor/tests/capacity.rs` (no gates).
