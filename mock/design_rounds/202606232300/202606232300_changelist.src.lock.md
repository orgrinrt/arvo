## CHANGE: `even_split_parts` guards the `base + 1` overflow
File: `mock/crates/arvo-strategy/src/arith.rs`
- In both `impl_scalar_euclid_i!` and `impl_scalar_euclid_u!`, replace the eager `base + 1` with a
  remainder-gated form: `let base_plus = if rem == ZERO { base } else { base + 1 };`. When `rem != 0` the
  divisor `n >= 2`, so `base <= a/2` and `base + 1` cannot overflow; when `rem == 0` the value is never
  yielded, so `base` stands in. Removes the debug-panic on `split_evenly(USize(1))` at container MAX.
Verification: `grep "if rem ==" mock/crates/arvo-strategy/src/arith.rs` returns matches; the new width-8 MAX
test passes.

## CHANGE: `div_euclid_whole` saturates the `<< FRAC` shift
File: `mock/crates/arvo-strategy/src/arith.rs`
- In both macros, replace `a.div_euclid(b) << FRAC` with `a.div_euclid(b).saturating_mul((1 as $c) << FRAC)`
  so a sub-unit divisor's out-of-range whole-unit quotient saturates to the bound instead of panicking.
  Deterministic, no panic.
Verification: `grep "saturating_mul" mock/crates/arvo-strategy/src/arith.rs` returns matches; the new
fractional-divisor test passes.
