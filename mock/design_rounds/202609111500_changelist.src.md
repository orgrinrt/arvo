# Source changelist: addition admitted on a declared signature

Executes `202609111200_changelist.doc.lock.md` against `crates/arvo-format/DESIGN.md.tmpl` as it stands at
`aca9a8e9`. The tautological tests go first, in their own commit, before any addition source lands, so the
suite the addition is built on is one whose every arm can fail.

## Comparison to deprecated changelist

`202609111300_changelist.src.deprecated.md` was deprecated by the unlock that reopened the doc changelist,
whose comparison section named the deprecated doc changelist's sections in prose and not one heading each,
and so failed the push gate. Nothing in the source plan was wrong, and every block below is the deprecated
changelist's block, carried. Three things change. Two are `File:` lines: the `panic_on_overflow` block and the
`Reach` block named `lib.rs`, and neither change touched it, because the crate root re-exports both by name
and a changed signature or a new method moves no re-export. The third is the totality block's verification, which cited a line of `apply/tests/mod.rs` that the commit removing the macro made stale, and now names the macro instead. The landed commits are named per section.
