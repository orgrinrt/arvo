# Doc changelist: the documents stop describing a deleted tree

**Date:** 2026-08-31
**Round:** the surfaces round, opened on the reviewer's findings against PR #28
**Scope:** four root and agent templates, and one crate design document. The rendered `docs/` follow by
regeneration and are not edited.

## What this changelist is

Four documents describe a seventeen-crate tree deleted on 2026-08-08. One of them is a layer table
naming `arvo-strategy` as `BitsContainerFor` and `Project<TAG, Sign, BYTES, S>` while the source
shipping beside it names the same crate as a binding from a name to a placement objective, so the
published document and the crate disagree about what the crate is.

A fifth change is consequential rather than stale: `arvo-strategy/DESIGN.md.tmpl` names `StatedIntent`,
which the src changelist deletes, so the design has to stop naming it in the same round.

## The canon this declares

Unchanged from rounds `202608311902` and `202608311957`. Nothing here adds a canon dependency; every
edit replaces a description of a tree that no longer exists with a description of the one that does.

`ruling::the_strategy_intents_are_not_clear_cut` bears on the fifth change, because a per-preset
compile-time item keyed on the preset is nearer the behaviour table that row forbids than prose is.

## Why the banner goes rather than gets updated

`agent/rules/implementation.md.tmpl` already carries a note saying the crate names below name a tree
that no longer exists and should be read for discipline rather than architecture. **A disclaimer over a
description is not a description**, and every agent that loads it still reads seventeen crate names and
a layering rule about them before reaching the note's caveat. Replacing the content is the fix and
removes the need for the banner.

## What is deliberately not here

**The four broken bench manifests.** `fnv1a`, `xxhash3`, `spectral-bisection` and
`structural-decomposition` inherit workspace dependencies that no longer exist and fail at
`cargo metadata`. They are named in this round's topic file with their exact state and left alone:
making them build means inventing bench arms, and deleting them destroys an artifact trail the
workspace manifest says the panel cites. **Keeping them is the result and the finding is that nothing
in the tree says they are broken.**

**The root `README.md`**, which the branch's first commit already brought in step with what ships.

**No new design document and no new crate.** Every edit is to a document that exists.
