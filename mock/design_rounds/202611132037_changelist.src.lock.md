# Src changelist: a fixme names its ticket

**Date:** 2026-11-13
**Round:** a defect round on `work/arvo-lints`, the six `FIXME` markers that name no ticket.
**Doc changelist:** `202611132036_changelist.doc.lock.md`, which edits no design.
**Scope:** `mock/crates/arvo-strategy/src/lib.rs` and `mock/crates/arvo-format/src/symmetry.rs`. The lint and its helper under `mock/lints/` are outside the gated source and land in the same change.

## CHANGE: the four preset markers name their ticket

In `arvo-strategy/src/lib.rs` the four `// FIXME:` markers above the impls for `Hot`, `Cold`, `Precise` and `Warm` become `// FIXME(arvo_s_four_preset_adaptation_defaults_are_carried_rather_th):`. The reason each carries is kept in its own words, rewrapped. No code line changes.

## CHANGE: the two symmetry markers name their ticket

In `arvo-format/src/symmetry.rs` the marker on the parity region becomes `FIXME(arvo_s_even_translation_parity_region_is_named_and_expressed)` and the one above `rounding_is_reflection_equivariant` becomes `FIXME(arvo_s_reflection_predicate_takes_no_reach_and_answers_no_in)`. The reasons are kept. No code line changes.

## CHANGE: the lint

`mock/lints/a_fixme_names_its_ticket.rs` refuses a comment whose own text opens with `FIXME` and has no `(<ticket id>):`, at `HARD_ERROR`. `comment_lines` is added beside `code_only` in `mock/lints/code_only_source.rs` so the lint reads comments from the one parse. The research copies of both are removed.

## Verification

The lint's 18 tests pass in the pack, a bare marker and the same marker without its id among them, and the pack's 972 tests pass with the 19 ignored arms of the half-up ticket unchanged. The research note recorded exactly these six markers as the hits before the edits.
