# Topic

The capacity-container migration (round 202605301415, PR #74) changed `BitMatrix<W, const N: Cap>` to `BitMatrix<W, C: Capacity>`. The struct declaration and the arvo-bitmask `DESIGN.md.tmpl` were migrated, but three rustdoc surfaces that render to docs.rs still describe the old signature:

- `src/lib.rs` module doc: `BitMatrix<W, const N: Cap>` and the example `BitMatrix<Bits<64, Hot, Unsigned>, N>`.
- `src/dirty.rs` `propagate_dirty` doc: `BitMatrix<W, N>`.
- `src/node.rs` `NodeId` doc: `BitMatrix<W, N>`.

The PR's src-changelist verification grepped the struct declaration, not prose claims about the signature, which is the doc-vs-source failure mode `documentation-writing.md` names. This round corrects the three comments to the migrated `BitMatrix<W, C>` / `BitMatrix<W, C: Capacity>` spelling. Comment-only edits, no behaviour change; lands on the same branch before the PR merges.
