## D38. arvo gets a crate for number-system membership

**Decision (op, 2026-07-29).** Not just `Natural`. The whole family: `Real`, `Surreal`, and the rest
worth having, in a new crate, `arvo-num-systems`.

**The reasoning is that they serve as generic bounds across all mathematical work**, which matters
more here than in most codebases because the stack leans explicitly on typestate and generics. With
the sets available as bounds, code can diverge on established mathematical facts rather than on
ad-hoc predicates: when a value is in ℝ do this, when it is not ℝ but ℤ do that. Those are real,
settled distinctions with centuries of meaning behind them, and expressing them as bounds costs
nothing at runtime.

**They ship even if nothing uses them yet.** op's call, and it is the opposite of the anti-speculation
default applied elsewhere in this round for a specific reason: the vocabulary is fixed by mathematics
rather than invented here, so it cannot be got wrong in a way that later needs undoing. A good deal of
existing work will want to adopt these bounds later, and having them exist now is cheaper than
retrofitting the vocabulary once consumers have improvised around its absence.

### What the literature calls this

"Number systems" is the standard mathematical phrase, which is where op's name lands. The computing
term for the same structure is the **numerical tower**, from Scheme and Common Lisp, defined as "a set
of data types that represent numbers and a logic for their hierarchical organisation", ordering
Number ⊃ Complex ⊃ Real ⊃ Rational ⊃ Integer.

Worth noting that the tower as those languages define it has **no `Natural` at its base**. That is a
gap in the borrowed structure, not a reason to avoid the term, and arvo's version starts one rung
lower than Scheme's.

The members worth carrying, with the standard notation:

| Set | Notation | Note |
|---|---|---|
| Natural | ℕ | below the Scheme tower's base |
| Integer | ℤ | |
| Rational | ℚ | |
| Real | ℝ | |
| Complex | ℂ | |
| Quaternion | ℍ | Cayley-Dickson from ℂ |
| Octonion | 𝕆 | Cayley-Dickson from ℍ |
| Surreal | No | Conway. op's word was exactly the English one |
| Hyperreal | *ℝ | Robinson, non-standard analysis |
| p-adic | ℚ_p | |

Algebraic and transcendental cut across ℝ rather than nesting under it, so they are a separate axis
rather than more rungs.

## D39. Membership is defined in terms of algebraic structure

**Decision (op, 2026-07-29).** `arvo-num-systems` depends on `arvo-algebra-contracts`, and the sets are
defined through the structures rather than as opaque markers. ℝ is a complete ordered field, ℤ is an
integral domain, and each membership bound says so.

This is the mathematically honest arrangement and the definitions carry real content: a consumer
bounding on `Real` gets the field operations because that is what being real means, not because a
separate bound was also written.

**It has a sequencing consequence that this round has to respect.** The algebra ladder has to be
defined before the sets can be, so `arvo-algebra-contracts` is upstream work rather than a sibling.
The changelist orders them accordingly.

## The harder half, which is the actual work

**op's framing, recorded because it is what makes the crate non-trivial.** Contracts without proofs
would be marker traits a consumer could implement wrongly. The interesting part is the const
assertions and typestate machinery that **statically prove membership holds**, so an impl exists only
for types that genuinely satisfy it. That is not obvious and is where the design effort goes.

One precision the machinery needs from the start: the predicate is **inhabits**, not **equals**.
`Natural` asserts that every value of the type is a natural number, not that the type represents all
of ℕ. `UFixed<8, 0, S>` holds 0 through 255, a finite subset, and is `Natural` under the inhabits
reading and nothing under the equals reading. Inhabits is also the reading that makes the bound
decidable and composable, and it is the one that gives the diverging-logic idea its teeth.

## What arvo's own types actually inhabit, and it is not ℝ

**Agent finding, from the sources below.** Applying the inhabits test to arvo's existing primitives
produces a sharper answer than expected, and it is decidable from the type parameters alone.

A `UFixed<I, F, S>` is an integer over 2^F, so every value it holds is a fraction with a
power-of-two denominator. Those are the **dyadic rationals**, the ring **ℤ[1/2]**, a proper subset of
ℚ. Floats are the same: "for most floating-point representations, the representable numbers are a
subset of the dyadic rationals", and fixed-point "use powers of two implicitly in the majority of
cases".

| arvo type | Inhabits | Why |
|---|---|---|
| `UFixed<I, 0, S>` | ℕ | integers, non-negative, bounded |
| `IFixed<I, 0, S>` | ℤ | integers, signed, bounded |
| `UFixed<I, F, S>`, F > 0 | ℤ[1/2] | numerator over 2^F |
| `IFixed<I, F, S>`, F > 0 | ℤ[1/2] | as above, signed |
| `FastFloat` / `StrictFloat` | ℤ[1/2] plus specials | infinities and NaN are outside any of these sets |

**So no arvo type is `Real`, and none is `Rational` in full.** `Real` becomes a bound that nothing in
the crate satisfies, which op already accepted in advance ("even if nothing uses them, they are
there"). It is information rather than a gap: it says precisely what the substrate cannot promise, and
a consumer who needs ℝ learns it at the bound rather than after a rounding surprise.

The float row also connects to `202607291710`. NaN and the infinities are exactly the values that
break membership, and D30 already reads their handling as a typestate question rather than a
carve-out. The same marker that lets a non-NaN float implement the ordering contract is what lets it
claim dyadic membership.
