# Topic: two `arvo-format` files past five hundred lines split on their seams

**Date:** 2026-09-24
**Governing canon:** none directly. `file-size.md` (workspace rule) sets the five-hundred-line smell
threshold this topic answers; no `ruling` row in this repo's registry governs module layout, so this is
harness discipline rather than a canon-derived change.
**Where this came from:** findings 9 of the fifth review of pull request #150 (the review at
`review150d.txt` in the reviewing session's scratchpad), naming `mock/crates/arvo-format/src/symmetry.rs`
(505 lines) and `mock/crates/arvo-format/src/addition/tests/the_verdict.rs` (515 lines) as both over the
`file-size` lint's threshold.

## What is over the line

`symmetry.rs` carried two things that do not need each other to be read: what an operation's exact
positions and its translations reach (`Residues`, `Reach` and the private `ordered` fn), and the
equivariance predicates asking whether rounding, completion and adaptation commute with a translation or
a reflection (`Reads`, `When`, `Behaviour`, `behaviour_of`, and the six predicate functions). The first is
a coordinate the second consults; neither reads the other's internals.

`the_verdict.rs`, a test module for `addition::add`, carried four sections that already read as separate
concerns under their own comment headers: the counts the canon records reproduced at every scale, the
verdict checked against brute force over small licensed windows, the verdict walked over the whole
admitted width range, and two negative controls. Nothing in one section calls into another except through
the module's own shared `Table`, `Window`, `DITHERS` and the two type aliases `Sat`/`Wr`, all of which the
parent module already owns.

## What this round is not

Not a design change. No public type, trait, signature or module path outside `symmetry` and
`addition::tests::the_verdict` changes. `Reach` is re-exported from `symmetry` exactly as before
(`pub use reach::Reach;`), so every external `use crate::symmetry::Reach` still resolves. The test module
keeps the name `the_verdict` and every test function keeps its name, so `cargo test the_verdict` still
selects the same set. This is file-size hygiene, gated because it touches `crates/*/src/*.rs`, not because
anything about the crate's shape is being decided.

## The split

`symmetry.rs` (505 lines) becomes `symmetry.rs` (274 lines, the equivariance predicates and `Reads`/
`When`/`Behaviour`) plus `symmetry/reach.rs` (251 lines, `Residues`, `Reach`, `ordered`).

`the_verdict.rs` (515 lines) becomes a directory module: `the_verdict/mod.rs` (43 lines, the two type
aliases and the module doc) plus `the_verdict/counts.rs` (117 lines), `the_verdict/brute_force.rs`
(205 lines), `the_verdict/width_walk.rs` (171 lines) and `the_verdict/negative_controls.rs` (57 lines),
one per section as the file's own headers already named them.

Verification: `cargo test -p arvo-format the_verdict` selects the same 8 tests before and after, all
passing; `cargo build -p arvo-format` and `cargo test -p arvo-format` are clean, no new warnings.
`find mock/crates/arvo-format/src -name "*.rs" | xargs wc -l | sort -n | tail -5` shows nothing over 500
lines after the split.
