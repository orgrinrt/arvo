# Src changelist: every contract coordinate gets a type the stack owns

**Date:** 2026-09-01
**Round:** the format contract is spelled in host primitives
**Scope:** `mock/crates/arvo-format/src`, `mock/crates/arvo-format/tests`, `mock/lints`

Ten associated consts, and every public parameter and return that carries a coordinate, move off the
host's types and onto the crate's own. The const generic surface is untouched.

File: `mock/crates/arvo-format/src/ambient.rs`
Verification: `grep -c 'pub struct Radix' mock/crates/arvo-format/src/ambient.rs` returns one.

`repr(transparent)` over the count, a private field, and `count` as the one declared unwrap door.
`Radix::BINARY` and `Radix::DECIMAL` name the two the crate ships an ambient domain for.

## CHANGE: types `Exponent`, `Magnitude`, `MagnitudeCount` FROM absent TO declared
File: `mock/crates/arvo-format/src/quantum.rs`
Verification: each of `pub struct Exponent`, `pub struct Magnitude`, `pub struct MagnitudeCount`
returns one match in that file.

`Magnitude` and `MagnitudeCount` are separate because an index and an extent are separate, which is
the off-by-one this crate already says it will not carry in a const. `Exponent` serves both the step
law's intercept and its rate, since both sit on the same additive axis and the law adds them.

## CHANGE: type `Phase` FROM absent TO declared, and consts `Format::PHASE_NUM` and `Format::PHASE_DEN` FROM two `i64` TO one `const PHASE: Phase`
File: `mock/crates/arvo-format/src/format.rs`
Verification: `grep -c 'PHASE_NUM\|PHASE_DEN' mock/crates/arvo-format/src/format.rs` returns zero and
`grep -c 'const PHASE: Phase'` returns one.

This is the one change that is not a rename. The ratified parameterisation carries a phase, one
coordinate, and the crate carried a numerator and a denominator as two consts with the denominator's
never-zero condition written as a doc comment nothing enforced. `Phase::of` maps a non-positive
denominator to one, on the same total-function reading `Exact::between` already used for its own, so
there is no runtime check and no way to construct the case the comment asked about.

## CHANGE: type `Fraction` FROM absent TO declared, and `Exact` and `Dither` FROM loose numerators and denominators TO carrying one
File: `mock/crates/arvo-format/src/apply.rs`
Verification: `grep -c 'pub struct Fraction' returns one; `Exact` has fields `slot: Slot` and
`part: Fraction`, and `Dither` wraps a `Fraction`.

`Exact::between` keeps normalising an out-of-range remainder into the slot, so a `Fraction` handed to
it may be any ratio and what `Exact` holds afterwards is in `[0, 1)`. That invariant stays `Exact`'s
rather than `Fraction`'s, because moving it into the constructor would drop the carry the caller is
relying on.

## CHANGE: `adapt` FROM `-> i64` TO `-> Slot`, `panic_on_overflow` FROM `(slot: i64) -> bool` TO `(slot: Slot) -> Bool`, `panic_on_inexact` FROM `-> bool` TO `-> Bool`
File: `mock/crates/arvo-format/src/apply.rs`
Verification: `grep -c 'pub const fn adapt<S: DeclaredSignature>(exact: Exact, dither: Dither) -> Slot'`
returns one.

`round_slot` and `complete_slot` stay private and keep the wide intermediate they compute in. That
value is deliberately wider than a `Slot`, it exists inside two private functions, and giving it a
coordinate type would put on the public surface a quantity nothing outside has any business holding.

## CHANGE: the `points` impls FROM two phase consts TO one, and `Biased`'s third const generic FROM `PHASE` TO `HALF_STEPS`
File: `mock/crates/arvo-format/src/lib.rs`
Verification: `grep -c 'const PHASE_NUM' mock/crates/arvo-format/src/lib.rs` returns zero.

The rename is forced rather than chosen: the associated const is now called `PHASE`, and a const
generic parameter of the same name inside the same impl reads as the wrong one. `HALF_STEPS` is also
what the parameter has always meant, since its denominator was fixed at two. **No const generic
parameter changes type**, which is the line this round does not cross.

## CHANGE: lint `a-contract-coordinate-is-not-a-host-primitive` FROM absent TO declared
File: `mock/lints/a_contract_coordinate_is_not_a_host_primitive.rs`
Verification: `cargo mock --lint-only` names the lint, and its tests plant an offending declaration
and assert it is reported.

The class this round fixes can come back tomorrow, because `arvo-format` is exempt from the
bare-primitive pack and nothing else looks at it. The lint is that hole closed: an associated const
declared in this crate with a host primitive as its type is refused, and it is refused at the commit
gate rather than by somebody noticing.

A lint rather than a test, because it gates and because
`mock/lints/` is where a gating check lives in this repo. It reads the crate's source the way the
pack lints do, so what it refuses is the same shape they refuse everywhere else, applied to the one
crate they skip.

## CHANGE: the outside-implementor test FROM one format TO the whole contract
File: `mock/crates/arvo-format/src/tests.rs`
Verification: the test module declares a member of every one of `Ambient`, `Quantum`, `Slots`,
`Format`, `Overflow` and `Operation`, and each is reachable through the crate's free functions.

The existing `Ternary` supplies a `Format` and reuses everything under it, which never exercised what
an implementor supplying the whole contract has to write. The round's measurement was taken against
exactly that shape, so it becomes a permanent construction rather than a probe somebody deleted.

asserts the denominator is positive for every one.

The property the doc comment used to ask for, asserted over the inputs that would have broken it,
including the ones that reach the coercion rather than only the ones that do not.

## CHANGE: `trybuild` cases FROM one TO four
File: `mock/crates/arvo-format/tests/ui`
Verification: `tests/compile_fail.rs` names the directory and the run is green.

Three added, each pinning a refusal this round creates. A host integer where a `Slot` is wanted. A
`Magnitude` where a `MagnitudeCount` is wanted, which is the index-against-extent separation the two
types exist for and which is invisible while both are `u32`. And a `Phase` built from a construction
that no longer exists, which pins that the two consts are gone rather than deprecated.

## CHANGE: the test bodies FROM host values TO coordinates
Files: `mock/crates/arvo-format/src/tests.rs`, `mock/crates/arvo-format/src/apply/tests.rs`
Verification: `cargo test -p arvo-format` is green and the sweeps still run every admitted width.

Mechanical, and it is most of the diff. Every sweep keeps its full matrix, every control keeps its
assertion, and the negative constructions kept as permanent records keep the values they were
measured with.

## What does not change

**No const generic parameter's type.** Op excepts that position and
`question::the_width_surface_crossing` is open on it.

**No lint severity, no `mockspace.toml` line, and no primitive-introductions entry.** The gate was
right and the contract was wrong.

**Nothing in `width.rs` but its module doc.** `Width` and `Bool` stay the two primitives, and the
coordinates are built through that door rather than beside it.

**No registry row.**
