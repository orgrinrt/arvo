# The rule and the render say what the source does

## What this round does

Three things a reviewer found on this branch, all of them one shape: a document
saying something the source does not do.

**The placement design changed and its rendered page did not.** The commit hook
runs in lint-only mode and says so in its own output, so a template edit lands
with the rendered file untouched and every gate stays green. `docs/PLACEMENT.md`
carries three paragraphs fewer than the template it comes from, and it is the
published page.

**The rendered page carries a banned word.** `paradigm` is on the vocabulary
list, and it entered through the same paragraphs.

**The agent rule for implementation states a trait that does not exist and a
prohibition the source does not keep.** It shows `const OBJECTIVE: Objective;`
where `arvo-strategy` declares `type Objective: ObjectiveKind;`, and the crate's
own rustdoc explains why a const cannot compile there: it becomes a const generic
argument depending on a generic parameter at the call site. And it says the
overflow mode is unsettled and must not be filled in, while all four presets fill
it in, each with a `FIXME` marking the value a carried default rather than a
ratified one.

The last is the one that matters most, because it is not a document a stranger
reads. It is the file every session in this repository loads before it writes
anything, so an agent that trusts it writes a trait that does not compile and
then deletes four `FIXME` markers to obey a prohibition the source already
carries an honest answer to.

## What this round does not do

**It does not settle the overflow mode.**
`ruling::wrap_or_clamp_stays_open_and_both_get_priced` is at `open` and says the
bench decides. The four values stay exactly as they are, markers included; what
changes is that the rule stops telling a reader they are absent.

## Where it came from

A pre-merge review over this branch and four others. Each of the three was
verified against the source before being written down here: the render by
running `cargo mock` and reading `git status`, the trait by opening
`arvo-strategy/src/lib.rs`, and the four presets by grepping their `Adaptation`
lines and finding the `FIXME` above each.
