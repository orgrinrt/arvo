# Doc changelist: the rule and the render say what the source does

Source topic: `202609011520_topic.the-rule-and-the-render-say-what-the-source-does.md`.

## `mock/crates/arvo-placement/DESIGN.md.tmpl`

One word. `paradigm` is on the banned vocabulary list and it entered with the
paragraphs this branch added about the arms. It becomes `approach`, which is what
the sentence meant and carries the same weight.

The word matters more here than in a round artifact, because this template
renders into `docs/PLACEMENT.md`, which is published.

## `docs/PLACEMENT.md`

Regenerated, which is the actual defect this round exists for. The template
gained three paragraphs on this branch and the rendered page did not move,
because the commit hook runs in lint-only mode and says so in its own output, so
every gate stayed green over a published page that disagreed with its source.

Nothing here is hand-edited. `cargo mock` writes it and the diff is checked
against the template rather than trusted.

## `mock/agent/rules/implementation.md.tmpl`

Not gated by the phase, being under `mock/agent/`, and listed here because it is
part of the same finding rather than because the window is needed for it.

Two corrections, both against `arvo-strategy/src/lib.rs`:

The trait shown was `const OBJECTIVE: Objective;`. The declared trait is `type
Objective: ObjectiveKind;`, and the crate's own rustdoc says why a const cannot
be used: it becomes a const generic argument depending on a generic parameter at
the call site, which does not compile without a feature the stack does not take.

The overflow paragraph said the mode is unsettled and must not be filled in. All
four presets fill it in, because a trait with an associated type cannot be
implemented without one, and each carries a `FIXME` above it saying the value is
a carried default rather than a ratified one. The paragraph now says that, and
says to leave the markers alone until the bench answers.

**The ruling is untouched.** `ruling::wrap_or_clamp_stays_open_and_both_get_priced`
stays at `open` and nothing here settles it.
