**Date:** 2026-09-03
**Phase:** IMPL
**Scope:** `arvo-format`
**Source topics:** `202609031451_topic.the-counts-the-consolidation-left-stale.md`

Three fixes, no behaviour change. Two comments that counted something other than
what they said they were counting, and one attribute silencing three warnings the
merge introduced. The suite was green before and is green after, which is the
point: none of this is caught by a test, and all of it is read by the next person
who opens these files.

## Comparison to deprecated changelist

`202609031455_changelist.src.deprecated.md` states exactly the same three changes
and this file carries them forward unchanged. It was deprecated for an ordering
mistake rather than a content one: it was locked before its source was committed,
so the round reached CLOSED with the edits still staged and the phase gate refused
them, which is the gate working. The only additions here are this section, the
tool lockfile bump the run surfaced, and verifications rerun against what actually
landed rather than against the working tree.

## CHANGE: the arm comment on `a_coordinate_is_readable_off_the_impl_without_the_obligation_firing` FROM `the shortest route of the four` TO the design's count of three
File: `mock/crates/arvo-format/src/tests/obligations.rs`
Verification: `grep -c 'shortest of the three routes the design names' mock/crates/arvo-format/src/tests/obligations.rs` returns 1, and `grep -c 'route of the four' mock/crates/arvo-format/src/tests/obligations.rs` returns 0.

The design names three routes and the section lead comment above the arms lists
four items, the fourth of which the lead comment itself says is about a different
obligation. The arm was counting the lead comment rather than the design. The
replacement says which document it is counting, so the next reader knows where to
check rather than which of two numbers to believe.

## CHANGE: `InvertedSlots`, `NeverCancelsOverAnInvertedRange` and `NeverCancelsOverAnAdmissibleRange` FROM three `dead_code` warnings TO `#[allow(dead_code)]` with the reason on each
File: `mock/crates/arvo-format/src/tests/obligations.rs`
Verification: `cargo test -p arvo-format --lib 2>&1 | grep -c 'never constructed'` returns 0, against 3 before the change.

All three are typestate markers reached only in type position, by const
assertions, so the compiler cannot see them being used and deleting them would
delete the evidence the const assertions rest on. The doc comment on each says
that, rather than the attribute sitting there unexplained.

## CHANGE: the module doc of `compile_fail.rs` FROM enumerating seven of its cases TO enumerating all eleven
File: `mock/crates/arvo-format/tests/compile_fail.rs`
Verification: the groups the doc names now sum to the case count: `grep -c 'compile_fail(' mock/crates/arvo-format/tests/compile_fail.rs` returns 11, and the paragraph counts one, three, two, one, three, one.

Four of the eleven cases were unaccounted for, four short on the trunk and one
worse on this branch, which added the eleventh case without touching the
paragraph. The enumeration says what each group of cases is for, which the file
names do not, so it is worth completing rather than deleting.

## CHANGE: the five tool lockfiles FROM `mockspace-lint-rules` at `1ff158c` TO `cf0fb06`
File: `mock/tools/*/Cargo.lock`
Verification: `grep -c 'mockspace.git?branch=dev#cf0fb06d53f8ba89547f1e90b4d20f5d034f3c00' mock/tools/*/Cargo.lock` returns 1 for each of the five.

The engine pin moved to mockspace's `dev` head between the previous round's lock
and this one, so the generated lint crate was alone on the new revision and the
five tools lagged it. That is the direction the lint's own message names, and in
this direction its prescribed remedy converges. The previous round recorded the
other direction, where it does not: a bare `cargo update -p mockspace-lint-rules`
takes the branch head rather than the engine's resolution, so it moves the tools
past the engine and the lint then refuses the other way. `--precise` against the
engine's revision is what settles it either way, and it is what was run here.

## What is not verified by any of the above

That the design still names three routes. Nothing checks the agreement between
that paragraph and these comments, so a later round moving the design's count
leaves these two comments stale again with a green suite. The honest statement is
that the fix restores agreement today and builds no instrument to hold it.
