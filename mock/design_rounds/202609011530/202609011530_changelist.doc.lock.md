Source topic: `202609011530_topic.the-shipped-comments-name-the-process.md`.

## No template changes

The templates are not touched. What this round corrects is comment text in three
`.rs` files, and the phase gate puts that in the source window rather than this
one, so this changelist exists to open the window and says what it does not do.

`mock/crates/arvo-format/DESIGN.md.tmpl` does carry the same defect, in about nine
places, and it renders into the published document, which makes it the worse half.
It is left standing on purpose and the topic says why: it predates the work this
round is cleaning up after, it is the crate's whole register rather than one
change's slip, and correcting it means rewriting paragraphs whose subject is the
design. It wants a round whose subject is that, with the greps run across every
tier-one surface together.

Recording it here rather than only in the topic, because a template defect named
in a doc changelist that then changes no template is the shape a later reader can
check: the count is nine and the file is named.
