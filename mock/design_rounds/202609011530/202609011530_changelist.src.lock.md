# Src changelist: the shipped comments name the process

Doc changelist: `202609011530_changelist.doc.lock.md`.

Comment text only. No signature, no body, no test assertion and no behaviour
changes anywhere in this round, so `cargo test -p arvo-format` reports the same
counts before and after and that is the check.

## CHANGE: comment at `Slots::ADMITTED` FROM naming the design round TO naming the mechanism
File: `mock/crates/arvo-format/src/slots.rs`
Read `at all until the round that gave the other three contracts the same
obligation`. The useful half is that the refusal went untested while being
described as a fact, and that the other three contracts carry the same obligation.
Neither needs the ceremony named. The idiom `the right way round` two lines below
goes with it, because the word is what the grep finds and a rewrite costs nothing.
Verification: `grep -ciwE 'round' mock/crates/arvo-format/src/slots.rs` returns
zero.

## CHANGE: two comments in `tests/identity.rs` FROM citing a research path TO stating what the instrument established
File: `mock/crates/arvo-format/src/tests/identity.rs`
The module doc on `zero_is_a_member` and the section note above the extreme-phase
arms both cite
`mock/research/sketches/phase-over-the-magnitude-range/` by path. The directory is
internal and a reader of the published package cannot open it, and nothing else in
this crate cites one.

What each is carrying survives without the address. The first is saying that a
predicate checked against an enumeration written independently of it is a
different and stronger check than this helper, which is true and worth saying and
does not need to say where that check lives. The second is saying the two extreme
pairs were measured rather than reasoned about, which the four arms below it then
assert.
Verification: `grep -c "mock/research" mock/crates/arvo-format/src/tests/` returns
zero.

## CHANGE: five comments in `tests/identity.rs` FROM naming a round TO naming the region an arm reaches
File: `mock/crates/arvo-format/src/tests/identity.rs`
The module doc, the extreme-phase note, the half-step control and the
out-of-range arm each explain themselves by saying which round did or missed
something. Each becomes a statement about the coordinates: an arm whose phase is
always fractional cannot enter the region where a whole phase keeps the identity,
and an arm that only ever asserts true cannot see a whole phase whose slot is out
of range. That is what the reader needs and it stays true when nobody remembers
there were rounds.

## CHANGE: four comments in `tests/obligations.rs` FROM naming a round and a ratification TO naming the contract
File: `mock/crates/arvo-format/src/tests/obligations.rs`
The module doc opens on a proposal being ratified through the format spine, and
three arms explain themselves by which round added or missed the case. The
proposition's content is what binds and it is stated directly: a new instance
earns admission by supplying the concept's obligations, which is what makes
admission a check rather than a negotiation.
Verification: `grep -ciwE 'round|ratified' mock/crates/arvo-format/src/tests/obligations.rs`
returns zero.
