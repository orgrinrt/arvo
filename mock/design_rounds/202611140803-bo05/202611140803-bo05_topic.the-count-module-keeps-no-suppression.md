## Current state

The two count binaries, the const path and the plain path, include one shared module, and the module
silences dead code because the const path leaves one alias unread: `TwoBitsAbort`, which only the plain
path's debug abort reads. No suppression is kept.

## Changes proposed

The alias moves into the plain path's binary, the one that reads it, and the shared module drops the
attribute. Each binary then uses all of what it includes.
