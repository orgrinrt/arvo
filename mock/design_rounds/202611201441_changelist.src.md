# Src changelist: the proof is invariant

**Date:** 2026-11-20
**Round:** `202611200755`, job `arvo-numeral-doors`. Changes `arvo-bits`, `mock/tools/the-positions` and the lints.
**Topic:** `202611200755_topic.the-proof-is-invariant.md`. **Doc changelist:** `202611200806_changelist.doc.lock.md`, relocked. **Replaces:** `202611200811_changelist.src.deprecated.md`.

## `mock/crates/arvo-bits/src/`

CHANGE: `tier.rs`: `Within`'s field is `PhantomData<fn(B) -> B>`, invariant in its container; its doc says
the proof is of the width `B` declares, why it is invariant and that its auto traits no longer follow the
container's; the module doc says the guard is of the declared width (topic decision 2).

CHANGE: `lib.rs`: the crate doc says an index or an amount at or past the width a container declares is
refused (decision 2).

## `mock/crates/arvo-bits/tests/`

ADD: four `compile_fail` cases with their expected output, joining `REFUSED` in `compile_fail.rs`:
`a_proof_carried_to_a_narrower_container_is_refused` (`E0308`, decision 2),
`a_container_of_its_own_shifted_past_its_width_is_refused` (`E0080`),
`an_impl_of_the_callers_sequence_by_hand_is_refused` (`E0119`) and
`an_impl_of_the_callers_trait_without_its_supertrait_is_refused` (`E0277`) (decision 5). The review's pass 1
adds `an_impl_of_the_callers_sequence_without_its_supertrait_is_refused` (`E0277`), the seal's last branch,
and `the_container_the_proof_is_held_against_is_not_send` (`E0277`), the control for `the_proof.rs`.

CHANGE: `ui/a_proof_built_by_hand_is_refused.stderr`, regenerated for the new field type.

CHANGE: `ui/an_impl_of_the_fields_of_a_packed_word_by_hand_is_refused.rs` keeps the impl of `Fields` and drops
the layout naming it, whose refusal rustc put before or after the impl's from one build to the next, so
the case failed about one run in two; its expected output is the one refusal.

CHANGE: `common/mod.rs` gains `bit_of`, a bit read by division, and `shifted`, a shift built one bit at a
time; `the_bit_access.rs` and `the_bit_sequence.rs` take them in place of the host's shift and mask, and
their module docs say so (decision 6). `rotated_up` and `written` read each bit through `bit_of` too,
so no oracle reads a bit the way `src/ops.rs` does.

CHANGE: `the_bit_tier_in_a_constant.rs` evaluates all eleven operations in one constant through
`[const]` bounds, `every`, and holds each against its value written out (decision 7): at `Bits<8>`
with index one and amount three, at `Bits<1>` with index and amount zero, and at `Bits<64>` with index
sixty-three and amount four, where the rotations take the branch for a container as wide as its carrier.

ADD: `the_proof.rs`: `Within` is `Send` and `Sync` for a container that is neither, held by constants that
do not build otherwise.

## `mock/tools/the-positions/`

CHANGE: `src/supply.rs`: `USize`, `Unsigned`, `Bits`, `BitWidth`, `BitAccess`, `Capacity` and `Dim` move
from `ARVO_GONE` to `ARVO_SHIPPED`; `ARVO_SHIPPED` is what a crate exports at its root or through a public
module, so `arvo_format::slots::Unsigned` and `arvo_strategy::presets::Hot` are on it, and both lists name
the lint that holds them (decision 4).

CHANGE: `src/tests/controls.rs`: the gone test asserts `Cap` and `BitPrim` gone. The loop asserting the
seven names supply and `the_control_the_names_arvo_does_export_are_supply` compared the hand list with
itself, and the lint holds both lists against the tree now, so both are deleted (decision 4).

## `mock/lints/`

ADD: `a_supply_list_agrees_with_what_the_crates_export.rs` and its tests: a name on `ARVO_GONE` that a
crate exports, a name on `ARVO_SHIPPED` that no crate exports, and a supply file holding neither list are
findings. Both sides are read from the parse: a list is the strings of its own `const` item, and a crate
exports its `lib.rs`'s `pub` items and `pub use` names, vertical braces, aliases and `self` included, and
the same of every module it reaches through a `pub mod`, inline or by file. The review's pass 1 found the
first form reading past the list into `NOTKO` and seeing only lines opening with `pub`, and checking one
direction; the fixtures now take the real file's shape. The topic placed this as a control in the tool's
tests reading every `lib.rs` by path; the lint `no-source-include-in-test` refuses a test that includes
crate sources, and a list a crate's exports can make wrong is a state the project refuses to be in, so it
is a lint that gates (decision 4, as built).

## `mockspace.toml`

ADD: `[lints.a-supply-list-agrees-with-what-the-crates-export]` at error on commit, build and push.

Decision 3 is a question ticket. Findings 8, 9 and 10 are tickets.

## Comparison to deprecated changelist

`202611200811_changelist.src.deprecated.md` was the source claim as the round first locked it, before
the review's pass 1 (`mock/research/202611200325_review-arvo-bits-tier/PASS_4.md`). It was deprecated
because pass 1 named a refusal the design did not yet list, the impl of `BitSequence` on a type with no
`BitSequenceBy`, and a design sentence can only change in the doc window; the doc changelist was
reopened for that one sentence and relocked.

Against it, this changelist adds two `compile_fail` cases (the seal's last branch and the control for
`the_proof.rs`), the reduced packed-word case, `the_proof.rs`, `bit_of` in the oracles, the 1-bit and
64-bit sweeps in the constant test, and `ARVO_SHIPPED` read as what a crate exports through a public
module. The lint is renamed from `a-name-filed-as-gone-is-exported-by-no-crate` to
`a-supply-list-agrees-with-what-the-crates-export`, reads both lists and the exports from the parse
rather than by lines, and checks both directions, so `code_only_at`, which only the first form read
through, is gone from `code_only_source.rs`. The two controls that compared the hand list with itself are
deleted. The `DESIGN.md.tmpl` change it would have carried is in the doc changelist instead.
