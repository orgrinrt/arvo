### arvo-bitmask source changes

Identical: blanket `impl<W> const MaskOps for Mask<W>` with `[const] BitAccess + BitLogic + BitSequence + Bounded + Identity` bounds. `empty` routes through `Identity::ZERO`. `full` routes through `Bounded::MAX` (matching the audit Finding 11 fix). Cargo.toml gains `arvo-mask-contracts.workspace = true`.

### arvo (facade) source changes

Identical: `bitfield!` macro emits `impl const ConstPartialEq` (with `ConstPartialEq::const_eq` body), `impl const ConstEq` (empty marker over the supertrait), and `impl const ConstDefault` (with `ConstDefault::const_default` returning `Self(<Bits as Identity>::ZERO)`). The macro continues emitting `PartialEq` / `Eq` / `Hash` / `Debug` impls alongside the const variants. Mask construction at three emission sites routes through `<C as BitPrim>::mask_low(USize(N as usize))` at the dispatched container `C`, replacing the prior `(1u64 << N) - 1`. The `BitPrim::mask_low` saturating-at-WIDTH semantic absorbs the prior full-width branch. Facade re-exports `NUSize` from arvo-storage and `Just` / `Maybe` / `Outcome` from notko.

### arvo-bits-contracts source changes
