## Deliverable B: LOGICAL_WIDTH internal arithmetic cleanup

### Add helper functions in `mock/crates/arvo/src/markers.rs`

Add two const fns next to the `BitPresentation` trait declaration:

```rust
pub const fn logical_width_unsigned(i: IBits, f: FBits) -> USize {
    USize(i.raw() as usize + f.raw() as usize)
}

pub const fn logical_width_signed(i: IBits, f: FBits) -> USize {
    USize(1 + i.raw() as usize + f.raw() as usize)
}
```

Each helper carries one `lint:allow(no-bare-numeric)` /
`lint:allow(arvo-types-only)` annotation on the `as usize` cast lines
with `tracked: #312`. Round 3 lifts the cast out of the helper bodies
once typed Width arithmetic ships.

### Update `mock/crates/arvo/src/ufixed.rs:204`

`crate::markers::logical_width_unsigned(I, F)`.

### Update `mock/crates/arvo/src/ifixed.rs:198`
