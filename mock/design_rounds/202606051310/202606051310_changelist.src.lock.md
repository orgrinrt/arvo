generalized algorithms round 202606051246 left covered only at `Bits<64>`:
`upward_rank`, `downward_rank`, `longest_path`, `spanning_tree`. The fixture is
the same 129-node bowtie at `Bits<256, Hot, Unsigned>` / `Dim<129>` the existing
wide-word tests use (64 sources fan into the middle node 64, which fans out to
64 sinks 65..128), with unit weights of the 8-bit `UFixed` type the prior rank

`longest_path` returns overall weight 3 with the middle and sinks carrying a
predecessor and the sources not; `spanning_tree` flags the middle as the sole
fan-in bridge and places the head source, the middle, and a wide-bucket sink on
a trunk. Each assertion reads indices at or beyond 64 (and beyond 128 for the
wide-bucket path), so a row-word narrowed to 64 fails it.

No source change to the crate, so no `## CHANGE:` blocks (the round adds tests,
not contract-bearing symbols).
