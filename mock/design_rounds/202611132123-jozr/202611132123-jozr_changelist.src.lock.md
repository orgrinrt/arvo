## Current state

`tests/a_consumer_crate.rs` reads the crate's directory with `env!("CARGO_MANIFEST_DIR")` and its
scratch directory with `env!("CARGO_TARGET_TMPDIR")`. Both are fixed when the test binary is built,
so a binary reused from a shared build directory tests the checkout that built it.

## Changes proposed

### `arvo-numeral`

`tests/a_consumer_crate.rs`: the crate's directory is read from `CARGO_MANIFEST_DIR` in the run's
environment, and the scratch directory is `tmp` under the build directory the test binary sits in,
three levels above the binary. A second test, `the_paths_are_the_ones_this_run_was_given`, asserts that
the crate's directory read is the run's working directory, that the consumer's manifest is in it and
that the scratch directory exists.

No mutant is taken: the change is to how a test finds its fixture and no operation of the value is
touched.
