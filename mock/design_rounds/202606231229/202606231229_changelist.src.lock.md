## CHANGE: Precise saturates at the logical bound, not the container bound

File: `mock/crates/arvo-strategy/src/arith.rs`
Thread the `$container` type param into `impl_u_arith_saturating!` / `impl_i_arith_saturating!` (mirroring
the widen macros), add a logical-bound clamp helper computed from the macro's `$bits` (= N), and route every
Precise op (add/sub/mul/div + `u_mul_fixed` / `i_mul_fixed`) through the clamp. The fixed-point arm changes
from `saturating_mul(a, b) >> FRAC` to `clamp_logical(wrapping_mul(a, b) >> FRAC)`. The div-by-zero path
clamps to the logical max, not the container max.
Verification: `cargo test -p arvo --test fixed_point_mul i_mul_fixed_precise_should_saturate_to_logical_bound`
passes after its `#[ignore]` is removed; add add/sub/div Precise logical-saturation regression tests.
