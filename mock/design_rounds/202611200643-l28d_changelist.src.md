## `mock/crates/arvo-bits/tests/the_packed_word.rs`

`a_lane_agrees_with_cast_and_with_bit_zero` goes. `whole_at::<N>` checks, for each pattern and `1`, `2` and the top bit, that `from_low` then `low` of `Bits<N>` gives the pattern's low `N` bits and nothing above. `a_bool_lane_reads_bit_zero_and_writes_nothing_above_it` checks the same for `Bool` against bit zero.

A consumer value `Leaky`, `Lane` four bits wide, keeping and handing back all sixty-four bits, is the field `Nibble` of the layout `Nibbles` over `Bits<64>` beside a sixty-bit `Rest`. `a_value_leaking_bits_above_its_width_reaches_no_other_field` writes it set everywhere into a clear word and reads it out of a word set everywhere, and asserts only the field's four bits move either way. Taking out the mask in `get`, or the one in `with`, turns this test red and no other, checked by hand and undone.

No source file changes.
