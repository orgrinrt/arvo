# Topic: the format contract is spelled in host primitives, so nobody outside can implement it

**Date:** 2026-09-01
**Phase:** TOPIC
**Scope:** `mock/crates/arvo-format`

`proposal::the_concept_is_closed_and_the_inventory_is_open` is ratified through
`ruling::the_format_spine_is_canon`, and it says a new instance earns admission by supplying the
concept's obligations rather than by amending the canon, and that closing the concept while opening
the inventory is what makes admission a check rather than a negotiation.

The contract as shipped makes that unreachable. Every coordinate an implementor must supply is
declared with a host primitive as its type, the bare-primitive lints run at error level in every
crate that is not `arvo-format`, and `arvo-format` is the only crate exempt. So an outside crate
that implements `Format` is refused at the gate, and the only way it lands is by suppressing a lint.
Admission is a negotiation with the lint config, which is the thing the ratified sentence says it is
not.

## Measured rather than argued

Three arms, each written into `mock/crates/arvo-placement/src/lib.rs`, which is a real crate in this
workspace and is not exempt, and each run through `cargo mock --lint-only --commit`. The arms were
removed afterwards; the round lands them as a permanent test instead, so nobody has to redo this by
hand.

**The whole contract, implemented from nothing.** Nine associated consts, refused at nine positions
by `no-bare-numeric` and again at the same nine by `arvo-types-only`, so eighteen errors. The tenth
coordinate, `const WIDTH: Width`, drew nothing, because its type is the stack's own.

**The cheapest possible outside format**, reusing every shipped `Ambient`, `Quantum` and `Slots` and
supplying only what `Format` itself demands. Two positions, `PHASE_NUM` and `PHASE_DEN`, four errors.
**That is the floor**, and it is what makes this a defect rather than an inconvenience: there is no
arrangement of the shipped parts that gets an outside format past the gate.

**Const generic parameters alone**, no associated const anywhere. Also refused. Op excepted those by
name, in his own words carried on
`obligation::a_primitive_for_every_position_a_bare_number_would_take`:

> We want arvo there. No bare usize other than in const generics for smoother and more ergonomic api,
> and even there, only when truly painful otherwise.

So that third arm is a defect in the lint rather than in arvo, and this round does not touch the
const generic surface. `question::the_width_surface_crossing` is open on exactly that surface with
the panel as its decider, so the round would be filling a question that is not its own even if the
lint agreed with op.

## The sentence that licensed it is false, and the counterexample was nine lines away

`mock/design_rounds/202608311902/202608311902_changelist.src.lock.md:103` says:

> A const generic parameter and an associated const must have a primitive type; the language gives no
> alternative.

The first half holds without a feature. The second half does not, and the same trait it was written
about carries the refutation: `mock/crates/arvo-format/src/slots.rs:63` declares `const WIDTH: Width`,
and `rounding.rs:26` and `overflow.rs:28` declare `const MODE: Mode` and `const POLICY: Policy`. Three
associated consts in this crate already carry a type that is not a host primitive. An associated const
takes any type at all; only a const generic parameter is restricted.

So the coordinates are spelled this way because a sentence nobody checked said they had to be, and
the crate disproved it in three places while the sentence stood.

## Ten positions, and one of them was never counted

`adapt.rs:95` carries `const ARITY: u32`, which no earlier reading of this surface named. The full
set an implementor must supply:

| Coordinate | Declared | What it is |
|---|---|---|
| `Ambient::RADIX` | `ambient.rs:18` | the base a domain counts in |
| `Ambient::SIGNED` | `ambient.rs:25` | whether the domain reaches below zero |
| `Quantum::BASE` | `quantum.rs:27` | the exponent at magnitude zero |
| `Quantum::SLOPE` | `quantum.rs:30` | the change in exponent per magnitude |
| `Quantum::MAGNITUDES` | `quantum.rs:34` | how many magnitudes the law ranges over |
| `Slots::MIN` | `slots.rs:54` | the lowest admitted slot index |
| `Slots::MAX` | `slots.rs:57` | the highest admitted slot index |
| `Format::PHASE_NUM` | `format.rs:41` | the phase numerator |
| `Format::PHASE_DEN` | `format.rs:46` | the phase denominator |
| `Operation::ARITY` | `adapt.rs:95` | how many operands an operation takes |

And the same crate's free functions and constructors carry the same spelling in their parameters and
returns: `contains(slot: i64, magnitude: u32) -> bool`, `exponent_at(magnitude: u32) -> i32`,
`radix() -> u32`, `slot_count() -> i64`, `adapt(..) -> i64`, `Exact::between(slot: i64, num: i64, den:
i64)`, `Dither::at(num: i64, den: i64)`, `ADMITTED_WIDTHS: &[u32]`. Those do not block an outside
implementor, because calling one writes no type name, but they are the same class of position and
`ruling::the_operating_constraints_are_intents_and_rules` is in force over all of them:

> public API positions using the stack's own primitives rather than bare integers, floats, bool or
> usize

One class, one round. Fixing the ten and leaving the rest would be fixing the instance the report
named.

## What each coordinate is, which is the whole repair

Nothing here needs a mechanism. An associated const takes a type, so the work is naming what each
coordinate actually is and giving it one. The names come out of the crate's own prose, which already
calls them coordinates and already insists a slot is an index and not a value.

`Radix`, the base a positional notation counts in. `Exponent`, a signed power of that radix, which is
what both `BASE` and `SLOPE` are, one as an intercept and one as a rate on the same additive axis.
`Magnitude`, an index into a quantum law, and `MagnitudeCount`, how many it ranges over, kept apart
because the crate frets about exactly this off-by-one at `slots.rs:31` and then carries both as
`u32`. `Slot` and `SlotCount`, on the same reading. `Arity`. `Fraction`, a ratio with a positive
denominator, which is the remainder inside `Exact` and the whole of what a `Dither` is.

`Phase` is the one that is not a rename. The canon's parameterisation carries **a phase**, singular,
and the crate carries a numerator and a denominator as two independent consts with "Never zero"
written in a doc comment where nothing enforces it. One `Phase` with a constructor that cannot
produce a zero denominator is both closer to the ratified sentence and one fewer thing an implementor
can get wrong, so the two consts become one.

Each type sits in the file that declares the trait it is a coordinate of, rather than in a new module.
`Radix` with `Ambient`, `Exponent` and the magnitudes with `Quantum`, `Slot` and `SlotCount` with
`Slots`, `Phase` with `Format`, `Arity` with `Operation`, `Fraction` with the applied map. One file is
one topic and this keeps it that way, and it keeps every file under the size gate.

`width.rs` does not grow. `Width` and `Bool` stay the two stack primitives, and the door stays as
narrow as its own doc comment promises, because the coordinates are built through it rather than
beside it.

Each new type gets what `Width` has: `repr(transparent)`, a private field, one declared unwrap door,
and no second way to reach the value. A type carrying a property whose fields are public has not
carried it.

## What this round does not do

**It does not touch a const generic parameter.** Op excepted them, and the open width-crossing
question belongs to the panel.

**It does not raise, lower or exempt any lint.** The repair is to the contract, and the gate is
right about it.

**It does not widen the primitive-introductions door.** `arvo-format` stays the one exempt crate and
the exemption keeps covering exactly what it was opened for, which is that something has to turn a
machine integer into a stack value and that something cannot be written in types it has not defined.
What the round removes is the crate's use of that door for positions an outside crate has to write
too.
