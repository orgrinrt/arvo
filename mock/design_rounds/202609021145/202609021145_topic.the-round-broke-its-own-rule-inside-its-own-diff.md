# The round about shipped test comments shipped a research path in one

Round `202609021041` established that the arms guarding a surface are read on
that surface: a comment in a shipped test goes in the package and is browsable
beside the rendered documents, so it is tier 1 under `documentation-writing.md`
and may not name the internal machinery. That round then swept this crate for
provenance and left one path standing, in a doc comment in the file the round
was about.

`has_an_exact_form` cites `mock/research/sketches/202609021019_the-fraction-decision/`
as what its derivation agrees with. `mock/research/` is on the forbidden list by
name. Measured rather than assumed: the class has one instance in the whole of
`mock/crates/*/src/`, it is this one, and the base of the branch carrying it has
zero. So the branch regresses a class that was clean, inside the diff of the
round whose subject is that class.

The fact under the citation survives without it. An exhaustive search agreed
with the derivation at every width from three bits to eight, and that is what a
reader needs; where the search was run is internal. It is not lost either: two
round topic files name the sketch, and those are internal by location and stay
internal.

The citation was also carrying more weight when it was written than it carries
now. The suite has since grown an arm that walks the predicate against a
reduction sharing no branch with it, so the claim the comment was reaching for
is pinned by something that runs rather than by something a reader has to go and
find.

## The saturating region is eleven pairs wide, and a wider walk already exists

A second thing, found in the same read and unrelated to the first.

The four properties are asserted over `every_ratio()`, which is 225 pairs, of
which eleven enter the saturating region. That region is one of the two the
constructor has, and eleven is thin enough that a rule failing on a shape the
matrix happens not to carry would pass.

`every_pair_worth_reducing()` sits in the same file and walks around twenty
thousand pairs, reaching roughly a hundred saturating ones. It was built for the
predicate arm and nothing stops the four properties running over it too. The
matrix control stays exactly as it is: it is about `every_ratio()` carrying both
parities, which is what makes the smaller walk meaningful, and a second walk
does not retire it.
