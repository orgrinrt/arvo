# Src changelist: the value at every shape, and the conversion under the target's reduction

**Date:** 2026-11-14
**Round:** `202611140014`, job `arvo-values-fin`.
**Doc changelist:** `202611140020_changelist.doc.lock.md`.
**Scope:** `mock/crates/arvo-numeral/tests/`. No file under any crate's `src/` changes.

This changelist is tests only. The value type's source stands as the design describes it, and what
changes is how much of each stated law a test runs over. A law the design states over every shape was
held at sampled shapes; it is now held at every width from 1 to 64 on both ranges, at the three
radixes the tests' formats take, with the exponents and the adaptations crossed as the design's
section on what is proved says.

## CHANGE: the shared arithmetic of the tests

`tests/common/mod.rs` declares the modules below and takes the format crate's two-integer arithmetic
by path as `big`. `tests/common/oracle.rs` holds the expected quotient, product and conversion in host
integers and in `big`, with no case skipped for leaving 128 bits. `tests/the_oracle.rs` holds the two
against each other.

`tests/common/shapes.rs` holds the count a sweep keeps and asserts (`Shapes`), the width bands, the
adaptations, the three radix families, and the members and pairs a shape is run at.
`tests/common/points.rs` and `tests/common/hosts.rs` hold the integer points and the host integers
the door tests take.

## CHANGE: the quotient and the product at every shape

`tests/every_shape/quotient.rs` and `tests/every_shape/product.rs` are the bodies, included by one
test file a radix: `the_quotient_at_every_shape_{binary,decimal,ternary}.rs` and
`the_product_at_every_shape_{binary,decimal,ternary}.rs`. A band of sixteen widths is one test and
asserts 1600 signatures. One file a radix, since the three in one binary do not build in the memory
this container has.

`tests/the_quotient.rs` keeps the exhaustive widths 1 to 4 and the named quotients, and
`tests/fixed_point_product.rs` the named products, both on the shared arithmetic.

## CHANGE: the conversion on four sweeps

`tests/common/crossings.rs` holds one conversion between two signatures against the expected one, at
the source's members and at the source slots around zero and around each end of the target's range,
and the planted arm that holds a wrapping value against the saturating expectation.

`tests/common/widths.rs` is the width matrix: every source width onto every target width, four pairs
of ranges, both policies. `the_conversion_at_every_width_{binary,decimal,ternary}.rs` take it at
exponent zero, and the `_rounded` three from exponent minus one onto zero under `HalfEven`. Each band
asserts 8192 signatures and that the planted arm caught something.

`tests/common/exponents.rs` is the exponent pairs of a width (five by five, both ranges a side, ten
target signatures), the source signatures (ten by ten at each width and range), and the radix pairs.
`the_conversion_at_every_exponent_{binary,decimal,ternary}.rs` and their `_wide` halves take the
first, `the_conversion_under_every_source_signature.rs` the second,
`the_conversion_between_radixes.rs` the six ordered pairs.

`tests/the_conversion.rs` keeps the thirteen named pairs no sweep holds and gains a test that the
deepest exponent of the sweeps is the last the format admits.

## CHANGE: the host door and the debug check at every width

`tests/the_host_door.rs` runs the door at every width on both ranges.
`tests/the_debug_check_at_every_width.rs` runs the door's debug check at every width, both ranges,
with the 8-bit and the 64-bit host integers of each sign.

## No change

No source file of `arvo-numeral`, `arvo-format`, `arvo-placement`, `arvo-strategy` or `arvo-bits`. No
feature is added to any manifest and no mutant feature is added. The band tests, the crossing, the
lane, the count and the compile-fail tests stand as they were.
