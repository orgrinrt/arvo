# References in the letkajenkka spelling

Op, 24 November: "arvo: swap `[lint-crates]` from muisti's removed `ask` to `mockspace-extra-search`, so `cargo mock tools` works in arvo. First check, on a clean worktree of arvo dev, whether that swap alone commits. If the registry check refuses old-spelling references, extend the letkajenkka reference standard and `migrate references-to-letkajenkka` in mockspace so a reference can name a file's extension where two files differ only by it (ticket letkajenkka_migration_cannot_tell_files_apart_by_extension). Do not rename research records."

The swap alone did not commit: the registry check refused 1457 references still in the spelling before the standard. `cargo mock migrate references-to-letkajenkka` rewrites every one of them and one in a template, 1458 in all, on an engine that names an extension as a shape where two files differ by nothing else (letkajenkka `SPEC.md` 9.1): 1319 in the plain spelling and 139 as `stem<ext>`, such as `t183_probes::unblock_value<out>::6`.

One of the rewritten references is in a design template: `{{ crates::arvo-numeral }}` in `mock/crates/arvo-format/DESIGN.md.tmpl` becomes `{{ crates::arvo_numeral }}`, the same crate in the standard's character set. The registry rewrites need no round; this one does, and it changes no claim of the design.
