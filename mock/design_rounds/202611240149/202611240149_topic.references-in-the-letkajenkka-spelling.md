# References in the letkajenkka spelling

arvo takes `mock search` from the lint pack's repository, as `mockspace-extra-search` in `[lint-crates]`, in place of the `ask` tool its old repository no longer has, so that `cargo mock tools` and `cargo mock search` answer here.

That swap alone does not commit: the registry check refuses 1457 references still in the spelling before the letkajenkka standard. `cargo mock migrate references-to-letkajenkka` rewrites every one of them and one in a design template, 1458 in all: 1319 in the plain spelling and 139 naming a file's extension as a shape, such as `t183_probes::unblock_value<out>::6`, where two files of one directory share a name up to its first dot (letkajenkka `SPEC.md` 9.1). No research record is renamed.

The registry is this repository's canon (`canon_paths` is `mock/registry/*.toml`), so fourteen canon files have their references respelled. Each reference reaches the file, and the line or heading, it reached before, which the migration checks for every one it writes; no row's claim changes.

The template is `mock/crates/arvo-format/DESIGN.md.tmpl`: `{{ crates::arvo-numeral }}` becomes `{{ crates::arvo_numeral }}`, the same crate in the standard's character set. The engine renders a crate reference by the crate's name after the project prefix, so the generated `docs/FORMAT.md` links it as `[numeral](NUMERAL.md)`, the name its document is filed under; the `[arvo-numeral]` it showed came from an engine older than the standard.
