# Round 7 source changelist (arvo side)

This CL covers arvo's source changes for Round 7. Two new `impl const Bounded` blanket impls land on UFixed and IFixed via the predicate-bundling pattern Round 1 established for Identity and the Round 5 const-trait family extended for ConstPartialEq / ConstEq / ConstBitEq / ConstOrd / ConstDefault. Two existing const test files extend with MIN/MAX assertions that Round 6 had to skip (Round 6 deviation 3, recorded post-CLOSED).

The pattern is mechanical. The inner `Bits<W, S, Sign>` already impls const Bounded (arvo-storage/src/bits.rs:101). The blanket forward projects MIN/MAX through `<Bits<W, S, Sign> as Bounded>::MIN` / `MAX` and wraps in `Self`. Predicate bound shape is `S: BitsContainerFor<{ufixed_bits(I, F)}, Unsigned>` plus `Bits<{ufixed_bits(I, F)}, S>: [const] Bounded` (signed mirror for IFixed).
