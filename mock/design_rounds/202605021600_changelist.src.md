# Src changelist 202605021600 — const-trait bridges + mask traits

**Date:** 2026-05-02
**Phase:** SRC-PLAN

## Apply order

### Step 1: Bounded + Identity in arvo-strategy

`arvo-strategy/src/arith.rs`: add `Bounded` (MIN/MAX) and `Identity` (ZERO/ONE) const traits. Macro impls on u8..u128 (using `<$ty>::MIN` / `<$ty>::MAX` / `0` / `1`) and i8..i128. Re-export from crate root.

UPrimConst / IPrimConst: keep as before (already cover ZERO/ONE/MAX). Later steps reference UPrimConst directly; Bounded and Identity are the new generic surfaces consumers can take.

### Step 2: BitPrim / IBitPrim const-equality bridge

`arvo-bits-contracts/src/lib.rs`: add `fn is_zero(self) -> bool;` to BitPrim and IBitPrim trait declarations. Macro impls add `fn is_zero(self) -> bool { self == 0 }` body — concrete primitive `==` is const-stable.

### Step 3: Lift Bits BitAccess/BitSequence/BitLogic blanket impls to impl const

`arvo-bits-contracts/src/bits_impl.rs`:
- `BitAccess` impl: `impl<...> const BitAccess for Bits<N, S>` with `[const]` bound on `<S as UContainerFor<N>>::T: BitPrim`. Body's `BitPrim::get_bit` etc are now const-callable.
- `BitSequence` impl: `impl<...> const BitSequence for Bits<N, S>`. Body's `is_zero` body changes from `self.to_raw() == ZERO` to `<<S as UContainerFor<N>>::T as BitPrim>::is_zero(self.to_raw())`.
- `BitLogic` impl on `Bits<N, Hot>`: `impl const BitLogic`. The `core::ops::BitOr<Output = T>` etc bounds gain `[const]` prefix. With feature(const_ops), bare primitives satisfy const core::ops surface.

### Step 4: Bits inherent ZERO via UBitContainer bridge

`arvo-storage/src/bits.rs`: add inherent constant block:

```rust
impl<const N: u16, S: Strategy, Sign: Signedness> Bits<N, S, Sign>
where
    S: BitsContainerFor<N, Sign>,
    <S as BitsContainerFor<N, Sign>>::T: UPrimConst,
{
    pub const ZERO: Self = Self::from_raw(<<S as BitsContainerFor<N, Sign>>::T as UPrimConst>::ZERO);
}
```

The two predicates (`S: BitsContainerFor` + `T: UPrimConst`) appear together but BitsContainerFor takes free `const N: u16` parameter; the cycle hits only when CONSUMER code uses anonymous const exprs. At Bits-level the parameter is free.

If the cycle still hits, fall back to a sealed bridge `BitsContainerWithBounds<const N: u16, Sign>: BitsContainerFor<N, Sign>` with `Self::T: UPrimConst` baked into the trait declaration.

### Step 5: UFixed / IFixed inherent ZERO / ONE / MINUS_ONE

`arvo/src/ufixed.rs` + `ifixed.rs`: inherent constants via UBitContainer / IBitContainer bridge. Single-predicate pattern resolves the generic_const_exprs cycle.

```rust
impl<const I: IBits, const F: FBits, S: Strategy> UFixed<I, F, S>
where
    S: UBitContainer<{ ufixed_bits(I, F) }>,
{
    pub const ZERO: Self = ...;
    pub const ONE: Self = ...;
}
```

Need to navigate from UBitContainer::Prim back to UFixed::from_raw's expected `<S as UContainerFor<N>>::T`. Use `UBitContainer::from_prim` const fn (UBitContainer is now const trait per round 202605021400) to convert.

If this fails, alternative: just add a `pub const ZERO_RAW: <Self as UContainerFor<N>>::T;` direct const associate to a new `UContainerWithIdentity<const N: u16>: UContainerFor<N>` trait.

### Step 6: FastFloat / StrictFloat inherent ZERO / ONE

`arvo/src/float.rs`: inherent const constants. F: Ieee provides ZERO/ONE/etc via the Ieee trait (or via UPrimConst if Ieee bridges through). Simpler: add inherent const ZERO / ONE on FastFloat / StrictFloat using `F::ZERO` / `F::ONE` if Ieee carries them; otherwise add to Ieee trait.

### Step 7: Filled trait at arvo-mask-contracts

`arvo-mask-contracts/src/lib.rs` (or new `filled.rs`): define `pub const trait Filled: Sized { const EMPTY: Self; const FULL: Self; }`. Re-export.

Blanket impls:
- `impl<T: BitPrim> const Filled for T` — primitives (u8..u128 etc) where EMPTY = ZERO, FULL = MAX.
- (Or impl per macro on bare primitives.)

`Bits<N, S, Sign>: const Filled` — blanket with appropriate bridge predicate.

### Step 8: Mask64 / Mask256 use Filled trait, remove hardcoded constants

`arvo-bitmask/src/ops.rs`: remove the hand-rolled `pub const EMPTY: Mask64 = ...` and `pub const FULL: Mask64 = ...` inherent constants. Add:

```rust
impl<W> const Filled for Mask<W>
where
    W: BitSequence + BitAccess + Copy + Default + [const] Filled,
{
    const EMPTY: Self = Self::from_word(<W as Filled>::EMPTY);
    const FULL: Self = Self::from_word(<W as Filled>::FULL);
}

impl const Filled for Mask256 {
    const EMPTY: Self = Self([<QWord<Hot> as Filled>::EMPTY; 4]);
    const FULL: Self = Self([<QWord<Hot> as Filled>::FULL; 4]);
}
```

### Step 9: impl const BitAnd / BitOr / BitXor / Not on Mask64 / Mask256

`arvo-bitmask/src/ops.rs`: add `impl const BitAnd / BitOr / BitXor / Not for Mask<QWord<Hot>>` and the parallel `Mask256` impls. Bodies call `BitLogic` methods (now const) on the underlying word(s).

Convert inherent methods (union / intersection / difference / complement) from `fn` to `const fn`.

### Step 10: Smoke test extension

`arvo-storage/tests/usize_const_arith.rs` plus per-domain tests: validate `<UFixed<8, 0, Hot> as>::ZERO`, `<Mask64 as Filled>::EMPTY`, `<Bits<8, Hot> as>::ZERO` all const-evaluate.
