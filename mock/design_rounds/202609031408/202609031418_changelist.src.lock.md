# Src changelist: consolidate the two source halves the trunk merge left at parent bytes

The merge commit put `src/width.rs`, `src/tests/obligations.rs` and
`tests/compile_fail.rs` in at the branch parent's bytes, which mockspace excuses
because nobody authored them. Two of the three are not finished there. This is
where somebody authors them.

`tests/compile_fail.rs` needs nothing: the branch carries `dev`'s two cases and
the `trybuild` case for a cancelling phase reaching the slot range on top, so it
is already a superset.

## CHANGE: the module doc on `Width` states both reasons a count is not written down

File: `mock/crates/arvo-format/src/width.rs:24`

Both sides say the type count is unsettled and say it differently, and neither
clause is in the other. `dev` says two separate derivations reached different
counts. The branch says a number written here would be wearing the door's
authority without having earned it. The first is why nobody can write the number;
the second is what writing it anyway would do. One sentence carries both:

```
How many types that is, is not stated here and is not settled anywhere: two
separate derivations reached different counts, so a number written down here
would be one of them wearing the door's authority without having earned it.
```

Verification: `grep -n 'separate derivations reached different counts'` and `grep
-n 'without having earned it'` over `mock/crates/arvo-format/src/width.rs` both
return one match, and the two line numbers are one apart, so the clauses are in
one sentence rather than two.

## CHANGE: `a_coordinate_is_readable_off_the_impl_without_the_obligation_firing` is added, over `NoDenominator`

File: `mock/crates/arvo-format/src/tests/obligations.rs:354`

`dev` alone carries this arm, and it is the shortest of the routes that reach a
value without meeting the obligation: a reader takes `PHASE` off the impl and
there is nothing in between to force anything. It belongs, and it is rewritten
over `NoDenominator` rather than over `dev`'s `PhaseNamesNoPosition`, which is a
character-for-character second declaration of it that the branch had already
removed.

It carries its own control, which is `dev`'s and transfers unchanged: the same
read on `Integer<8>` answers the other way, so the arm reports that the obligation
was not consulted rather than that the phase happens to be false.

Verification: `cargo test -p arvo-format --lib obligations` runs 17 arms and the
new one is among them.

## CHANGE: the override arm asserts that its two declarations differ only in the obligation

File: `mock/crates/arvo-format/src/tests/obligations.rs:385`

`dev` alone carries this third assertion. The branch dropped it with a reason
that was true of `dev`'s shape and is not true of the branch's: under `dev` the
two fixtures were verbatim copies, so asserting they agreed on `PHASE` only
checked they had not drifted. With the copy gone, `DisarmedObligation` and
`NoDenominator` are two different declarations and the assertion has a job. It is
what says the arm is about the override: without it a reader cannot tell whether
`DisarmedObligation` simply declares a phase that denotes, which would make
`has_additive_identity::<DisarmedObligation>()` a fact about the phase.

The lead comment's sentence about the copy's assertion having no job goes with it,
since it now describes neither shape.

Negative control, run before the arm was believed: setting `DisarmedObligation`'s
`PHASE` to `Phase::of(1, 2)`, which denotes, fails this assertion and only this
one, with `left: Phase { num: 1, den: 2 }` against `right: Phase { num: 1, den: 0
}`. The two assertions above it pass unchanged, so the line carries the claim
rather than decorating it.

## CHANGE: the section lead comment counts four routes rather than three

File: `mock/crates/arvo-format/src/tests/obligations.rs:273`

The comment enumerates what the arms below are about, so it moves with them:
two routes that reach a value without meeting the obligation at all, the
membership predicate and a read off the impl, rather than one.

## What this changelist does not do

It states nothing new about the design. Every sentence and every arm here was
written by one side or the other and locked by the round that wrote it; what this
round decides is only which of them survive together.

It does not touch `tests/compile_fail.rs`, `DESIGN.md.tmpl` or `docs/FORMAT.md`.
The first needs nothing and the other two were settled in the doc changelist.
