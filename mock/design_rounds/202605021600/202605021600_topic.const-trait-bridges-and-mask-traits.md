# Topic: const-trait bridges + generic mask traits — PR #42 finishing work

**Date:** 2026-05-02
**Phase:** TOPIC
**Scope:** arvo-strategy + arvo-bits-contracts + arvo-mask-contracts + arvo-bitmask + arvo
**Tracking:** closes #305 + #306, plus user-flagged design smells from PR #42 round 202605021400

The previous round shipped most of the const-trait surface but left four design smells that are unacceptable for the unified PR. This round resolves all four.

## What was wrong

1. **Mask EMPTY/FULL hardcoded the underlying primitive.** `pub const FULL: Mask64 = Mask::from_word(QWord::<Hot>::from_raw(u64::MAX));` directly references `u64::MAX`. The signature `Mask<QWord<Hot>>` does not promise its container is `u64`. The constant is a leaky abstraction: if `QWord<Hot>` ever lowers to a different primitive, the constant breaks silently. The all-bits-set value must come from the container's own typed const surface, not be re-stated by the consumer.

2. **EMPTY/FULL/ZERO/ONE on concrete struct impls is the wrong level of abstraction.** Hand-rolling these per-type constants forces every mask type to ship its own `pub const EMPTY` line. The right shape is a const trait surface (`Bounded` for MIN/MAX, `Identity` for ZERO/ONE, or a mask-specific `MaskBounds` trait) with a blanket impl. Concrete types impl the trait once; consumers see uniform surface.

3. **The "synthetic blocker" framing was a cop-out.** UFixed / IFixed / Bits inherent ZERO/ONE/MINUS_ONE were filed as #306 "gated on a predicate-bundling bridge". The bridge IS the substrate's job. The existing UBitContainer trait already bundles `UContainerFor<N>` + `T: BitPrim` into one predicate. Extending UBitContainer (or adding a parallel Bounded-bridge) to bundle the ZERO/ONE/MAX const associates resolves the cycle. Round 202605021600 ships the bridge.

4. **The "rustc-level blocker" on BitAccess/BitSequence/BitLogic was a real surface limit, but workable.** Const PartialEq on bare primitives is not stable. The fix is a substrate-level workaround: add `is_zero(self) -> bool` (and other equality predicates) directly to BitPrim/IBitPrim, with concrete-impl bodies that use the primitive `==` operator (which IS const-stable on bare primitives at codegen). BitSequence::is_zero on Bits then calls BitPrim::is_zero instead of comparing through generic-context PartialEq. This is the bridge pattern the reviewer named: "introduce our own Eq, Ord etc. traits" via a substrate-level surface that const-impls on the bare primitive.

## What this round ships

### A. Bounded + Identity const traits at arvo-strategy

```rust
pub const trait Bounded: Sized {
    const MIN: Self;
    const MAX: Self;
}

pub const trait Identity: Sized {
    const ZERO: Self;
    const ONE: Self;
}
```

Implemented for u8 / u16 / u32 / u64 / u128 / i8 / i16 / i32 / i64 / i128 via macro impls.

UPrimConst / IPrimConst become pub trait aliases: `pub const trait UPrimConst: Bounded + Identity {}` (with a blanket impl for any `T: Bounded + Identity` covering the unsigned case; signed analogue carries `NEG_ONE` separately).

### B. Filled const trait at arvo-mask-contracts

```rust
pub const trait Filled: Sized {
    const EMPTY: Self;
    const FULL: Self;
}
```

The mask-specific bottom/top semantic. Empty = no bits set; full = all bits set.

### C. Const equality via BitPrim::is_zero

BitPrim and IBitPrim gain `fn is_zero(self) -> bool`. Macro-impl bodies use `self == 0` on the concrete primitive (const-stable). Replaces the generic PartialEq comparison in BitSequence::is_zero on Bits.

### D. Bits<N, S> blanket impls to impl const

BitAccess / BitSequence / BitLogic blanket impls on Bits<N, S> promote from `impl` to `impl const`. The is_zero body routes through BitPrim::is_zero (step C). The bitwise ops route through `[const] core::ops::BitOr / BitAnd / BitXor / Not` bounds with feature(const_ops).

### E. Bits inherent ZERO via UBitContainer bridge

```rust
impl<const N: u16, S: Strategy, Sign: Signedness> Bits<N, S, Sign>
where
    S: UBitContainer<N>,
{
    pub const ZERO: Self = Self::from_raw(<<S as UBitContainer<N>>::Prim as Identity>::ZERO);
}
```

Single predicate; UBitContainer bundles the container projection + Prim-bound. No more cycle.

### F. UFixed / IFixed / FastFloat / StrictFloat inherent ZERO / ONE / MINUS_ONE

UFixed inherent constants flow through UBitContainer bridge. IFixed parallel via IBitContainer. Float types via Ieee::ZERO / ONE.

### G. Generic Mask EMPTY / FULL via Filled blanket

```rust
impl<W> const Filled for Mask<W>
where
    W: BitSequence + BitAccess + Copy + Default + [const] Filled,
{
    const EMPTY: Self = Self::from_word(<W as Filled>::EMPTY);
    const FULL: Self = Self::from_word(<W as Filled>::FULL);
}

impl const Filled for Mask256 {
    const EMPTY: Self = Self([<QWord<Hot> as Filled>::EMPTY; 4]);
    const FULL: Self = Self([<QWord<Hot> as Filled>::FULL; 4]);
}
```

QWord<Hot> = Bits<64, Hot, Unsigned>; `Filled` blanket on Bits routes through `<S as UBitContainer<N>>::Prim` Identity::ZERO and Bounded::MAX.

### H. Mask64 / Mask256 inherent EMPTY/FULL constants are removed

The hand-rolled `pub const EMPTY: Mask64 = ...` lines come out. Consumers reach EMPTY / FULL through the `Filled` trait on Mask64 / Mask256 directly: `<Mask64 as Filled>::EMPTY`. Re-exports add convenience aliases if needed.

### I. impl const BitAnd / BitOr / BitXor / Not on Mask64 / Mask256

Now possible since BitLogic on Bits<N, Hot> is impl const. Bodies call BitLogic methods at const time.

## Sketch validation

The probe at `/tmp/const_probe/` already validated `pub const trait` + `[const]` supertrait bounds + `impl const` bodies on rustc 1.96.0-nightly with feature(const_trait_impl) + feature(const_ops). Re-validation per-step during apply.

## Decision

This round is a hard requirement for PR #42 to merge. Under no circumstance does PR #42 ship with any of the four design smells named above. Closing the round opens the merge.

## Out of scope

- Extending UBitContainer to additionally bundle Filled (a future enhancement; current shape with Bounded/Identity blanket through to BitPrim is sufficient).
- Const `core::cmp::PartialOrd` / `Ord` on USize and Cap — usize::partial_cmp is not stable as const; resolution belongs in a separate cmp-substrate round.
- Cross-strategy mask resolution.
