**Phase:** DOC

## Per-crate doc edits

### arvo-strategy DESIGN

Update the round-202605021400 "Primitive const bridges" section. Document `Bounded` (MIN/MAX) and `Identity` (ZERO/ONE) as the canonical const-trait surfaces. UPrimConst / IPrimConst become combinations / aliases.

### arvo-bits-contracts DESIGN

Document `BitPrim::is_zero` / `IBitPrim::is_zero` as the const-equality bridge. Note the design rationale: bare-primitive `==` is const-stable on concrete types but not via generic `PartialEq` trait dispatch; `is_zero` impls per-primitive use the const-stable concrete operator.

Document the lift of `BitAccess` / `BitSequence` / `BitLogic` blanket impls on `Bits<N, S>` from `impl` to `impl const`.

Document the `Bits<N, S, Sign>` inherent `ZERO` constant via the UBitContainer bridge.

### arvo-mask-contracts DESIGN

Add new section: `Filled` const trait. Carries `const EMPTY: Self` and `const FULL: Self`. Document the substrate semantic: empty = no bits set, full = all bits set. Implementable for any mask-like type.

### arvo-bitmask DESIGN

Document the `Filled` blanket impl on `Mask<W>` where `W: Filled`, and the parallel concrete impl on `Mask256`. Mask64 / Mask256 inherent EMPTY / FULL constants are removed in favour of the trait surface. Document `impl const BitAnd / BitOr / BitXor / Not` on Mask64 / Mask256.

### arvo (facade) DESIGN

Document the UFixed / IFixed inherent `ZERO` / `ONE` / `MINUS_ONE` constants via UBitContainer / IBitContainer bridge. Document FastFloat / StrictFloat inherent ZERO / ONE.

### Cross-references

PRINCIPLES updated to record: substrate-level bridges resolve rustc-level surface gaps; consumer code does not work around limitations of the standard library's const-trait surface, the substrate provides the const surface.
