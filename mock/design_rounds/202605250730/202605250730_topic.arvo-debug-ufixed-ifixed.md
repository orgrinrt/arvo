# Topic: arvo Debug on UFixed + IFixed

**Date:** 2026-05-25
**Phase:** TOPIC
**Scope:** arvo `UFixed` and `IFixed` numeric types.
**Task:** #428 (`arvo: ship Debug on UFixed/IFixed/Bits/USize/Bool/FastFloat/StrictFloat numerics`).

## Current state

Of the named numeric types in #428, all but two already have Debug:
- `Bits` at `arvo-storage/src/bits.rs`: `#[derive(... Debug ...)]` already shipped.
- `USize`, `Cap`, `Bool` at `arvo-storage/src/platform.rs`: `#[derive(... Debug)]` already shipped.
- `FastFloat`, `StrictFloat` at `arvo/src/float.rs`: `#[derive(... Debug)]` already shipped.

The two outstanding:
- `UFixed<const I: IBits, const F: FBits, S: Strategy>` at `arvo/src/ufixed.rs`.
- `IFixed<const I: IBits, const F: FBits, S: Strategy>` at `arvo/src/ifixed.rs`.

Both use manual `impl Copy / Clone / PartialEq / Eq` blocks because of the const-generic + `BitsContainerFor` bound shape; `#[derive]` does not work cleanly across the complex where-clauses. Debug needs the same manual treatment.

## Changes proposed

### Source edits

1. `arvo/src/ufixed.rs`: add `impl<const I: IBits, const F: FBits, S: Strategy> core::fmt::Debug for UFixed<I, F, S> where S: BitsContainerFor<{ ufixed_bits(I, F) }, Unsigned>` delegating to the inner `Bits` value's Debug impl with a wrapper that names the type: `f.debug_tuple("UFixed").field(&self.0).finish()`.

2. `arvo/src/ifixed.rs`: same shape with `Signed` on the `BitsContainerFor` bound and `f.debug_tuple("IFixed")`.

### Tests

One smoke test per type confirming Debug renders without panicking and the type tag appears in the formatted output. Goes in each file's existing test module if present, else a small `#[cfg(test)] mod debug_test {}` addition.

### Out of scope

Other numeric types in the workspace (kuvio, hilavitkutin numeric wrappers) that may also lack Debug. The #428 task scopes specifically to arvo's named numeric types.

## Lock criteria

- `cargo build` clean on arvo.
- `cargo test` clean on arvo.
- Both Debug impls exist; manual smoke tests assert Debug output contains `UFixed` and `IFixed` respectively.
- `cargo mock --lint-only --commit` clean.
