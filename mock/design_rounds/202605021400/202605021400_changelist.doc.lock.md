# Doc changelist 202605021400 — const-trait machinery lift

**Date:** 2026-05-02
**Phase:** DOC

**Tracking task:** #304

This DOC CL describes the doc-template edits that flow alongside the source-side const-trait machinery lift. The source-side detail lives in the SRC CL, written after this DOC CL locks.

## Per-crate doc edits

### arvo-strategy

`mock/crates/arvo-strategy/DESIGN.md.tmpl`: add a "Primitive const bridges" subsection under the existing arithmetic dispatch section. Document the new `UPrimConst` / `IPrimConst` const traits paralleling the existing `USaturating` / `ISaturating`. Each carries `ZERO` / `ONE` / `MAX` (and `MIN` / `NEG_ONE` for the signed variant) as const associated items. Note their role: the typed-primitive const surface that lets generic-context bodies construct or compare against zero / one without falling back to non-const `Default`.

Document the const-trait lift of `UArith<N>` / `IArith<N>` / `USaturating` / `ISaturating`. Surface contract unchanged for callers; the `const` qualifier opens the trait for use in const-context call sites.

### arvo-bits-contracts

`mock/crates/arvo-bits-contracts/DESIGN.md.tmpl`: add a "Const-trait surface (round 202605021400)" subsection. Document the lift of `BitPrim` / `IBitPrim` / `UBitContainer` / `IBitContainer` to `pub const trait`. Note that `Bits<N, S>` blanket impls of `HasBitWidth` / `BitAccess` / `BitSequence` / `BitLogic` are now `impl const` (closing an existing gap where the trait was const but the impl was not).

### arvo (facade)

`mock/crates/arvo/DESIGN.md.tmpl`: extend the round-202605021200 const-arith subsection to record what shipped in 202605021400.

`UFixed<I, F, S>` and `IFixed<I, F, S>` now carry:
- `pub const ZERO: Self` / `pub const ONE: Self` (and `pub const MINUS_ONE: Self` for IFixed).
- `impl const Add / Sub / Mul / Div for Self` (all four ops gain `const`).

`FastFloat<F>` and `StrictFloat<F>` now carry:
- `pub const ZERO: Self` / `pub const ONE: Self`.
- `impl const Add / Sub / Mul / Div / Neg for Self` via the const-bound macro.

`Bits<N, S, Sign>` now carries:
- `pub const ZERO: Self` (constructed via `Bits::from_raw(<container as UPrimConst>::ZERO)`).

### arvo-bitmask

`mock/crates/arvo-bitmask/DESIGN.md.tmpl`: extend the round-202605021200 const-trait subsection. `Mask64` and `Mask256` now ship inherent constants `EMPTY` / `FULL` plus `impl const BitAnd / BitOr / BitXor / Not`. `BitMatrix64` / `BitMatrix256` const-context constructors marked accordingly.

`Mask::from_word` becomes `pub const fn`; existing inherent constructors trace through the const path.
