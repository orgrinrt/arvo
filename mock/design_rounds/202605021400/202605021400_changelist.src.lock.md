# Src changelist 202605021400 - const-trait machinery lift

**Date:** 2026-05-02
**Phase:** SRC-PLAN
**Source doc CL:** `202605021400_changelist.doc.lock.md` (locked)
**Tracking task:** #304

This SRC CL applies the source-side const-trait machinery lift that closes round 202605021200's deferred Layer B. Nine commits, dep-direction-ordered. Each commit must `cargo +nightly check --manifest-path mock/Cargo.toml` clean before moving to the next.

## Apply order

### Step 1: arvo-strategy primitive const bridges

`mock/crates/arvo-strategy/src/arith.rs`: add `pub const trait UPrimConst: Sized` carrying `ZERO` / `ONE` / `MAX` const associated items. Add `pub const trait IPrimConst: Sized` carrying `ZERO` / `ONE` / `NEG_ONE` / `MIN` / `MAX`. Macro impls on `u8` / `u16` / `u32` / `u64` / `u128` and `i8` / `i16` / `i32` / `i64` / `i128`.

These const-callable typed-primitive constants unblock Layer B's UFixed / IFixed inherent ZERO/ONE constants and replace the non-const `Default::default()` zero-check in arith.rs.

### Step 2: arvo-strategy UArith / IArith / saturating const lift

`mock/crates/arvo-strategy/src/arith.rs`:

- `pub trait UArith<const N: u16>: UContainerFor<N> + HasAxes` → `pub const trait UArith<const N: u16>: [const] UContainerFor<N> + HasAxes`. Same for `IArith`.
- `pub trait USaturating: Sized` → `pub const trait USaturating: Sized`. Same for `ISaturating`. Macro impls gain `impl const`.
- The four `impl_*_arith_*!` macros gain `const` on the impl line. Bodies stay; only the trait header changes.
- Replace `<<Self as UContainerFor<$bits>>::T as Default>::default()` with `<<Self as UContainerFor<$bits>>::T as UPrimConst>::ZERO`. (For `IArith` impls use `IPrimConst::ZERO`.)
- Add `where <Self as UContainerFor<$bits>>::T: [const] UPrimConst` (or `IPrimConst`) to each macro impl's where clause if not already chained through the trait declaration.

`HasAxes` does NOT need to be const because UArith does not call any HasAxes method bodies — it is a phantom marker for axis projection.

### Step 3: arvo-bits-contracts BitPrim / IBitPrim / UBitContainer / IBitContainer const lift

`mock/crates/arvo-bits-contracts/src/lib.rs`:

- `pub trait BitPrim` → `pub const trait BitPrim`. Macro impls gain `const`. Method bodies (count_ones / wrapping_sub / bitwise ops) are already const-stable on bare primitives.
- Same for `IBitPrim`.
- `pub trait UBitContainer<const BITS: u16>` → `pub const trait UBitContainer<const BITS: u16>: [const] UContainerFor<BITS>`. Trivial method bodies (to_prim / from_prim are identity).
- Same for `IBitContainer`.

`feature(const_ops)` already at the crate root from round 202605021200.

### Step 4: arvo-bits-contracts Bits blanket impls const

`mock/crates/arvo-bits-contracts/src/bits_impl.rs`:

- `impl<const N: u16, S: Strategy> HasBitWidth for Bits<N, S>` → `impl const HasBitWidth for Bits<N, S>` (HasBitWidth is already pub const trait; the impl was missing const).
- Same for BitAccess, BitSequence, BitLogic blanket impls. Bodies call BitPrim methods which are now const after step 3.
- Add `[const]` to the `<S as UContainerFor<N>>::T: BitPrim` bound where it appears.

### Step 5: arvo facade UFixed const ops + ZERO/ONE

`mock/crates/arvo/src/ufixed.rs`:

- Lines 153/167/181/195: `impl<...> Add for UFixed<...>` → `impl<...> const Add for UFixed<...>`. Same for Sub, Mul, Div. Bodies stay.
- Add inherent constants:

```rust
impl<const I: IBits, const F: FBits, S: Strategy> UFixed<I, F, S>
where
    S: UContainerFor<{ ufixed_bits(I, F) }>,
    <S as UContainerFor<{ ufixed_bits(I, F) }>>::T: UPrimConst,
{
    pub const ZERO: UFixed<I, F, S> = UFixed::from_raw(<<S as UContainerFor<{ ufixed_bits(I, F) }>>::T as UPrimConst>::ZERO);
    pub const ONE: UFixed<I, F, S> = UFixed::from_raw(<<S as UContainerFor<{ ufixed_bits(I, F) }>>::T as UPrimConst>::ONE);
}
```

### Step 6: arvo facade IFixed const ops + ZERO/ONE/MINUS_ONE

`mock/crates/arvo/src/ifixed.rs`: parallel to step 5. Lines 142/156/170/184. Inherent constants ZERO / ONE / MINUS_ONE. The MINUS_ONE uses `IPrimConst::NEG_ONE`.

### Step 7: arvo facade FastFloat / StrictFloat const ops + ZERO/ONE

`mock/crates/arvo/src/float.rs`:

- Rewrite the `float_binop_impl!` macro to: `impl<F: Ieee + [const] core::ops::$op<Output = F>> const core::ops::$op for $wrapper<F>`. Body uses `<F as core::ops::$op>::$method(self.0, other.0)`. With `feature(const_ops)`, f32 and f64 satisfy `const Add<Output = f32>` etc.
- Same for `float_neg_impl!` macro.
- Add `pub const ZERO: Self = Self(F::ZERO)` and `pub const ONE: Self = Self(F::ONE)` inherent constants. (Verify `Ieee::ZERO` and `Ieee::ONE` are const associated; if not, route through `UPrimConst` or add to the Ieee surface.)

### Step 8: arvo-bitmask Mask64 / Mask256 const ops + EMPTY/FULL

`mock/crates/arvo-bitmask/src/lib.rs`: add `#![feature(const_trait_impl)]` and `#![feature(const_ops)]` to crate root if not present.
