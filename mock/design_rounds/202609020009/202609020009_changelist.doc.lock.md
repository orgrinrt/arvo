## CHANGE: `docs/` is regenerated rather than resolved
File: `docs/FORMAT.md`, `docs/STRATEGY.md`, and any sibling the merge marks.
Verification: every conflicted path carrying `AUTO-GENERATED` in its first three lines before the
regeneration, and `grep -rl '^<<<<<<<' docs/*.md` returning nothing after it.

Both sides of every one of these conflicts is a stale copy, because the only line that differs is the
`Generated at:` stamp each branch wrote when it last ran the tool. Picking a side installs whichever
dead timestamp happened to be on the left, so neither side is taken and `cargo mock` writes the value
that is true now.

This is the fourth branch tonight to pay this tax and the conflict set was identical on all four. That
the stamp buys nothing and costs a conflict on every pair of branches is filed against the tool rather
than worked around here.
