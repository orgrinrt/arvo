# sixth-review-shadowing-and-cross-end-fixes

review146f found that review146e's fixes closed the four named instances
rather than the classes they were instances of, plus process narration left
in shipped test source and rendered docs. This round closes the classes.

## The core-shadowing guard

A textual lint cannot close Rust name resolution, so the aim is an honest,
enumerated guard rather than a total one. The lint's second arm now names
four forms explicitly: `mod core` (plain or `r#core`), `use ... as core`
(plain or `r#core`, including inside a braced group closing at `,` or `}`),
`extern crate ... as core` (plain or `r#core`), and `use ...::core;` binding
`core` as a path's bare, alias-free last segment. Every claim in
`DESIGN.md.tmpl`, the lint's own module doc, and the rendered docs is
rewritten to say exactly these four forms rather than "every way" or "every
shadow", and to name what stays unguarded: a `Cargo.toml` manifest rename of
a dependency to the key `core`, which a source-text lint never sees, and any
form outside the enumeration. The two lint messages that shared one string
now read distinctly, one per keyword, and the `mod core` message's broken
trailing clause is gone. The committed probe gets three new sibling files: a
`use ... as core` arm, a raw-identifier `extern crate self as r#core` arm,
and a negative control that fails to compile, showing the harness can
actually fail rather than only ever exiting 0.

## The cross-end matrix

`the_cross_end_saturation.rs` fed only whole-slot (on-grid) carried
positions, so `round_slot`'s off-grid branches (a quarter, a half and three
quarters past an end) never reached the matrix. The matrix now feeds
remainders 0, 1/4, 1/2 and 3/4 at depths 1 through 5, over every mode and
both policies. A second mutant, S4, narrows the near-bottom Saturate/Clamp
guard on whether the rounding stepped up rather than on where the fed
range's own bottom sits; it is invisible to an on-grid matrix (an on-grid
position never sets `rounded.up`) and is caught once the matrix goes
off-grid. Applying S4 to `apply.rs` and running the suite turned the
positive control red; `apply.rs` was then restored exactly and touched.
Two hand-reduced Wrap residues, computed independently by hand and checked
against the shipped code, cover a case at each end.

## Process narration

Every mention of a review pass, a finding id (M1, M2, F1, 146d and the
like), a scratch file or a round, in source, test names or `DESIGN.md.tmpl`,
is rewritten to say what the thing is instead: what a broken map narrows,
what a matrix covers, what a blind spot is a blind spot in.
