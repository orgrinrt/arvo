# Src changelist: every function the format ships is inline

**Date:** 2026-11-13
**Round:** `202611132043-aun1`, job `arvo-format`.
**Doc changelist:** `202611132043-aun1_changelist.doc.lock.md`.
**Scope:** `mock/lints/rust_text.rs` (new), `mock/lints/the_platform_width_points_read_the_pointer_width.rs`
and its `core_bindings.rs`, `mock/lints/every_function_the_format_ships_is_inline.rs` (new) and its
`tests.rs`, and every source file under `mock/crates/arvo-format/src/` outside the test modules.

## CHANGE: the blanking moves to a module both lints read

`without_comments` and `starts_a_literal` move out of the platform-width lint into
`mock/lints/rust_text.rs`, unchanged, and the platform-width lint and its `core_bindings` read them from
there. The module declares no lint, as the two testkits beside it do not.

## CHANGE: the lint `every-function-the-format-ships-is-inline`

A crate lint at `HARD_ERROR`, reading `arvo-format` only. Every `fn` with a body in a file outside a
`tests` directory or a `tests.rs`, whose attributes do not hold `cfg(test)`, carries `#[inline]` or
`#[inline(always)]`. A function with neither, or with `#[inline(never)]`, is a finding at the line its
item starts on. A function without a body, a required trait method, is not one. Its tests carry the
control over the shipped spelling and each case that has to fire.

## CHANGE: the crate is marked

`#[inline]` on every function the lint names in `arvo-format`, placed as the last attribute above the
item. No body moves.

## Verification

The lint's own tests, `cargo mock --lint-only` green over the marked crate and red on one mark taken
off, `cargo clippy -p arvo-format --all-targets -- -D warnings`, `cargo test -p arvo-format` with the four
parity suites as the brief names them.
