# Doc changelist: fixed-point multiply widening + fixed-point ONE

Round: 202606231001
Phase: DOC
Scope: arvo-strategy, arvo

## Current state

The arvo-strategy `IArith` / `UArith` traits expose `i_mul` / `u_mul` (raw container product). The arvo
`IFixed` / `UFixed` `Mul` impls route through them, so `*` is a raw product with no fixed-point rescale, and
`Identity::ONE` is the container one (raw `1`). For `F > 0` this is not a fixed-point multiply.

## Changes proposed

- `arvo-strategy` DESIGN: document the new `IArith::i_mul_fixed` / `UArith::u_mul_fixed` strategy methods (a
  `FRAC`-scaled fixed-point multiply: widen for Min-container strategies, shift right by `FRAC`; the
  DoubleLogical container already holds the product).
- `arvo` DESIGN: document that `IFixed` / `UFixed` `Mul` is the fixed-point multiply for `F > 0` (`F = 0`
  unchanged integer multiply) and that `Identity::ONE` is the fixed-point one (`1.0` = raw `1 << F`).

## Files

- `mock/crates/arvo/DESIGN.md.tmpl`: note fixed-point `*` semantics + fixed-point `ONE` (if a Mul/Identity
