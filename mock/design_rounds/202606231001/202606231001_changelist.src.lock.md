## Changes

## CHANGE: trait method `IArith::i_mul_fixed` / `UArith::u_mul_fixed` ADDED
File: `mock/crates/arvo-strategy/src/arith.rs`
`fn i_mul_fixed<const FRAC: u16>(a, b) -> T` (and unsigned). Fixed-point multiply: FRAC-scaled operands ->
2*FRAC-scaled product -> shift right by FRAC. `FRAC == 0` == integer multiply.

## CHANGE: non-widening body in the 4 existing arith macros
File: `mock/crates/arvo-strategy/src/arith.rs`
`impl_u_arith_wrapping` / `impl_u_arith_saturating` / `impl_i_arith_wrapping` / `impl_i_arith_saturating`
gain `*_mul_fixed = Self::*_mul(a,b) >> FRAC`. Correct for DoubleLogical strategies (Warm/Precise) and
Hot/Cold 65-128 (deferred WideBits widen; correct for FRAC=0).

## CHANGE: 2 new widening arith macros for Hot/Cold 1-64
File: `mock/crates/arvo-strategy/src/arith.rs`
`impl_u_arith_wrapping_widen` / `impl_i_arith_wrapping_widen` (`$strategy, $container, $($bits)+`): same
add/sub/mul/div + `*_mul_fixed` that widens to i128/u128, multiplies, `>> FRAC`, narrows to `$container`.
The 16 Hot/Cold 1-64 invocations move to these.

## CHANGE: `IFixed`/`UFixed` `Mul` rewired to fixed-point multiply
Files: `mock/crates/arvo/src/ifixed.rs`, `mock/crates/arvo/src/ufixed.rs`
`mul` calls `i_mul_fixed::<{ F.raw() as u16 }>` / `u_mul_fixed`. FRAC=0 unchanged integer multiply.

## CHANGE: `IFixed`/`UFixed` `Identity::ONE` -> fixed-point one (raw `1 << F`)
Files: `mock/crates/arvo/src/ifixed.rs`, `mock/crates/arvo/src/ufixed.rs`

## Tests
F>0 fixed-point multiply across strategies; an overflow case proving the Hot/Cold widening; `x*ONE==x`;
`ONE*ONE==ONE`. Existing F=0 arith tests stay green.
