## What the round is for

A value has four ring operations and no quotient, no way onto another format, and one way in for a
number the program computes: `adapted`, which runs the format's exact oracle in four limbs at run
time. The audit's first finding is that door. Its ad hoc spike has it at eight to nine nanoseconds
against about one for the host's own clamp, and hilavitkutin's old source unwrapped its integers in
every hot loop, so the door in and out is what a consumer pays for most often.

This round puts `div` and `convert` on `Num`, each the format's own by equality, and gives the value a
door in and out for a host integer that never leaves a machine register.

## The quotient

`div(self, by: Divisor<S::Format>) -> Self`, with `fits_div` beside it. The divisor is the format's
own type, re-exported, so that it cannot be zero is the format's guarantee and is not stated twice.

A divisor is a constant today, `Divisor::constant::<B>()`. The format's other constructor takes a
run-time slot only over a format in which no slot names the zero, and every format the value tier
admits has the zero in range, so a value cannot yet be divided by a value. That is the format's open
ticket, `arvo_a_runtime_divisor_over_a_whole_phase_range_without_the`, and the answer is a membership
type for the non-zero slots there. The value tier takes what that gives when it lands and invents no
non-zero value of its own in between, since a second proof of the same fact in another crate is the
thing the stack is built to avoid.

The format ships no remainder as an operation, so there is no remainder pair here. A remainder defined
in this crate would be a behaviour the value states on its own. It is ticketed against the format.

## The conversion

`convert::<T>(self) -> Num<T, C>` for any `T: Sole`, with `fits_convert::<T>()`. The member is placed
on `T`'s grid by `T`'s rounding and completed by `T`'s policy: the format's `convert` from `S`'s
format onto `T`. Where the two formats are one, it gives what `under` gives, which the suite checks,
and `under` stays the door for that case because it is a move.

## Both go through the format's wide step for now

Each calls the format's own function on slots, as the fractional product does, under the same marker
and ticket, `arvo_numeral_s_fixed_point_product_goes_through_the_128_bit`. The rounding of a ratio has
one home, the format's applied map, and writing five modes of it again per carrier width here would be
a second implementation of the adaptation with nothing but this crate's tests holding the two
together. The per-width adaptation is the format track's, and the shape this crate will call is in the
channel document `briefs/arvo-door-shape-t3.md`: a ratio of two machine integers adapted to a width,
a mode and a policy, equal to `adapt` on the same position. When it lands, each of the three call
sites becomes that call and nothing of this design changes.

So the audit's warning is taken as it applies: the oracle is on the path of the quotient and the
conversion, marked, and is kept off the path of the door, which needs no rounding.

## The door at a host width

A host integer names a slot index. For an integer point that is the integer itself, and for a
fixed-point one it is the stored integer, the count of quanta. Three functions:

`from_index::<H>(host) -> Self` is the member at that index, completed by the declared policy where
the index is outside the range. It equals `adapted(Exact::on_grid(Slot::at(host)))` for every host
value, and under `Abort` a debug build aborts where that would.

`holds_index::<H>(host) -> Bool` is whether the index is a member, the verdict `from_index` asks.

`index::<H>(self) -> H` is the member's slot index as an `H`, refused at build where the range is not
inside `H`'s, so it never truncates.

`H` is any of the host's integers of 8 to 64 bits and the two pointer-width ones, behind a sealed
trait, `HostInteger`. The carrier is not named: `Uint<13>` gives its index as a `u16`, a `u32` or an
`i64` alike, whichever the consumer asks for and the range fits.

The arithmetic is at 64 bits and no wider. The host integer is extended to 64 bits by its own sign.
Wrapping keeps the low bits of the declared width and reads them by the range's sign. Saturation
compares against the two ends, with the two cross-sign cases answered before any comparison: a
negative host into an unsigned range is the bottom, and an unsigned host above the signed 64-bit
maximum into a signed range is the top. Every quantity but the host value is a constant of the
instantiation.

The pointer-width aliases keep `from_host` and `host`. They are the same door at the one width where
every host value is a member, and they are left as they are.

## What is proved

The quotient through the value type against the format's `div`: at widths 1 to 4 for every member
divisor but zero, at widths 5 to 8 for a named set of divisors that holds both ends of the range, one,
minus one and an odd one, both families, both policies, the five modes, every dividend. `Fixed<6, -3>`
and `UFixed<6, -3>` the same way. `fits_div` against `panic_on_overflow` of `quotient_position`.

The conversion against the format's `convert`: every member of each source, across integer widths in
both directions and across signs, from an integer onto a fixed-point grid and back, and between two
fixed-point grids of different exponents where the rounding acts, under both policies and the five
modes of the target. A conversion between two signatures over one format equals `under`.

The door: at widths 1 to 8, both families and both policies, every `i8` and `u8`, every `i16` and
`u16` within 1024 of zero, and the ends of every host integer, against `adapted`. At wider widths the
ends of the range and their neighbours and the ends of each host integer. `index` returns what
`from_index` was given for every member, in every host integer the range fits.

One mutant each, with its red run committed: `mutant-div`, `mutant-convert` and `mutant-index`. The
last makes the saturating door send a negative host to the top of an unsigned range, which is what a
comparison done after a cast gives.

Compile-fail pairs: `index::<u8>()` on a signed 8-bit integer beside `index::<i8>()`, and
`index::<u8>()` on a 9-bit unsigned integer beside `index::<u16>()`. The debug check at each new site
under `Abort` and under `Quiet`, with the release twin.
