## CHANGE: inner raw contracts `ScalarEuclidRaw<N>` / `UScalarEuclidRaw<N>`
File: `mock/crates/arvo-strategy/src/arith.rs`
- Add `pub const trait ScalarEuclidRaw<const N: u16>: [const] BitsContainerFor<N, Signed>` and the unsigned
  `UScalarEuclidRaw<const N>: [const] BitsContainerFor<N, Unsigned>`. Methods (over the projected container
  `T`):
  - `div_euclid_scalar(a: T, n: usize) -> T`: `if n == 0 { a } else { a.div_euclid(n as $c) }`.
  - `rem_euclid_scalar(a: T, n: usize) -> T`: `if n == 0 { ZERO } else { a.rem_euclid(n as $c) }`.
  - `even_split_parts(a: T, n: usize) -> (T, T, usize)`: `(base, base+1, rem as usize)` where
    `base = a.div_euclid(n as $c)`, `rem = a.rem_euclid(n as $c)`; `n == 0` -> `(a, a, 0)`. The combined
    primitive the even split consumes, keeping the `+1` ULP and the `rem -> usize` cast on the concrete side.
  - `div_euclid_whole<const FRAC>(a: T, b: T) -> T`: `if b == ZERO { a } else { a.div_euclid(b) << FRAC }`
    (whole-unit quotient as a fixed value).
  - `rem_euclid_whole<const FRAC>(a: T, b: T) -> T`: `if b == ZERO { ZERO } else { a.rem_euclid(b) }`.
- Macro-impl per strategy x native container, widths 1..=128 (`impl_scalar_euclid_i!` / `_u!`), invoked for
  Hot/Warm/Cold/Precise over i8/i16/i32/i64/i128 (and unsigned counterparts). Bodies strategy-independent (no
  clamp: euclidean division by a count >= 1 shrinks magnitude). `n: usize` carries `lint:allow(no-bare-numeric)`
  (count carrier, mirrors the const-carrier allows on `IArith`).
- Re-export both traits from `mock/crates/arvo-strategy/src/lib.rs`.
Verification: `grep "trait ScalarEuclidRaw" mock/crates/arvo-strategy/src/arith.rs` returns one match;
`cargo build -p arvo-strategy` clean.

## CHANGE: outer traits `ScalarEuclid` / `EuclidDiv` / `EvenSplittable` + `EvenShares`
File: `mock/crates/arvo/src/traits.rs`
- `ScalarEuclid`: `div_euclid_scalar(self, n: USize) -> Self`, `rem_euclid_scalar(self, n: USize) -> Self`.
  Blanket `impl ... for IFixed<I,F,S> where S: ScalarEuclidRaw<{ifixed_bits(I,F)}>` (and UFixed/UScalarEuclidRaw),
  delegating through `to_raw`/`from_raw` and `n.<usize>`.
- `EuclidDiv`: `div_euclid(self, rhs: Self) -> Self`, `rem_euclid(self, rhs: Self) -> Self`. Blanket over the
  fixed types, delegating to `div_euclid_whole::<{frac(F)}>` / `rem_euclid_whole`.
- `EvenSplittable`: `split_evenly(self, n: USize) -> EvenShares<Self>`. Blanket over the fixed types;
  calls `even_split_parts(self.to_raw(), n.<usize>)` -> `(base, base_plus, r)`, wraps via `from_raw`, builds
  `EvenShares { base, base_plus, r, n, i: 0 }`.
- `EvenShares<T: Copy>`: `Iterator<Item = T>`; `next` yields `base_plus` for the first `r`, then `base`, for
  `n` items total.
- Re-export `ScalarEuclid`, `EuclidDiv`, `EvenSplittable`, `EvenShares` from `mock/crates/arvo/src/lib.rs`.
Verification: `grep "pub trait EvenSplittable\|pub const trait EvenSplittable" mock/crates/arvo/src/traits.rs`
returns one match; `cargo test -p arvo` covers the new tests.

## CHANGE: tests (conservation, determinism, remainder rule, negative, whole-unit)
File: `mock/crates/arvo/src/traits.rs` (`#[cfg(test)]`)
