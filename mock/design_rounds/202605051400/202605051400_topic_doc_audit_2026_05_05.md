# Doc audit consolidation round (arvo)

This round consolidates the workspace-wide documentation audit findings for arvo into a single doc-only round. Two audits ran on 2026-05-05: a per-crate sub-agent audit covering `mock/crates/*/{README,DESIGN,BACKLOG,DEEPDIVE_*}.md.tmpl` across all 16 crates, and a self-audit of the entrypoint surfaces (`mock/{DESIGN,PRINCIPLES,WORKFLOW}.md.tmpl`, `README.md`, rendered `docs/*`). The findings cluster into four categories:

1. **Doc-vs-source drift.** The `#316` heterogeneous-N-ary-container round renamed the runtime container from `MultiContainer` to `WideBits` and changed `const N: Width` back to `const N: u16`, but the rename did not propagate into 9 `DESIGN.md.tmpl` files that still narrate the old shape. Six files still cite `const N: Width`. The `arvo` README plus body still advertises the deleted `Uint8`/`Int8`-family std-parallel aliases. The `Width` newtype shape disagrees across three places, none of which match source. Internal contradictions concentrated in `arvo/DESIGN.md.tmpl` (Warm cap stated as 32 / 64 / 65535 in the same file).
2. **Tier 1 leakage.** 60+ round-id mentions across all DESIGN tmpls render verbatim into `docs/*.md`. 14 of 15 DESIGN files have a `## Sources` block listing `mock/design_rounds/` and `mock/research/` paths. Two `substrate` hits (workspace-banned vocabulary). Mockspace + cargo mock + .tmpl + design_rounds vocabulary in `mock/WORKFLOW.md.tmpl` and parts of `mock/DESIGN.md.tmpl`.
3. **Polka-dots historical references in rendered output.** `docs/ARVO_BITMASK_OVERVIEW.md`, `docs/ARVO_COMB_OVERVIEW.md`, `docs/ARVO_GRAPH_OVERVIEW.md`, `docs/ARVO_SPARSE_OVERVIEW.md` carry `polka-dots T3 decision #67` / `T5 L1022-1041` historical cross-references that came from the original imported design notes. The references render to Tier 1.
4. **Spelling drift.** Five US-spelling -ize forms in arvo-spectral / arvo-comb / arvo-sparse against the British baseline.

This round is doc-only. The src CL referenced in section "## Following src CL (mentioned, not written)" is left for a separate round after the doc CL applies and is locked.

## Decisions

### Decision 1: Scope shape

**Single doc CL covering all four categories**, executed against this topic. Splitting into multiple CLs (per category, per crate) was considered and rejected: the findings overlap (e.g., a single line in `arvo/DESIGN.md.tmpl` may carry both a doc-vs-source drift and a round-id leakage); reviewing them together at one lock checkpoint is cheaper than four locks. The doc CL itself is large but mechanical.

### Decision 2: `## Sources` block treatment

Every `## Sources` block at the bottom of a DESIGN.md.tmpl that lists `mock/design_rounds/<id>_changelist.doc.md` paths gets **converted to Tier-2-only history**. Two valid moves: (a) strip the block entirely from the rendered Tier 1 output by adding a comment marker the renderer recognises and skips, or (b) move the block to a sibling `mock/research/<crate>-history.md` Tier 2 file and leave a one-line "Round-by-round history is recorded in `mock/research/`" pointer at the end of the DESIGN.md.tmpl, where the pointer itself is sufficiently generic to satisfy Tier 1.

This round picks **(b)**: move the `## Sources` blocks to per-crate Tier 2 history files. Rationale: the audit-trail value is preserved verbatim, the rendered Tier 1 output gets a clean termination, and no rendering-pipeline change is required.

### Decision 3: Round-id references in DESIGN body prose

Each occurrence of `round YYYYMMDDHHMM` in DESIGN body prose gets **rewritten to the design rationale itself, without the round id**. The audit history already records the round provenance; the rendered Tier 1 doc does not need it. Where the prose currently reads "Per round 202604271346, every trait whose methods are sensibly callable in const context is `pub const trait`," it becomes "Every trait whose methods are sensibly callable in const context is `pub const trait`."

Where the round id is load-bearing for explaining a sequencing constraint that a contributor needs to understand (rare; sample-checked: none in the audit's flagged set), the round id stays and the prose moves to a Tier 2 sibling.

### Decision 4: Doc-vs-source drift fixes

The `MultiContainer → WideBits` and `const N: Width → const N: u16` drifts plus the deleted-`Uint8`/`Int8`-aliases drift are propagated through the affected DESIGN tmpls per the per-crate audit's enumeration. Where the audit cites a specific file:line, the doc CL records the same path and the corrective edit. The internal contradictions in `arvo/DESIGN.md.tmpl` (Warm cap 32 / 64 / 65535) are resolved by re-reading source: the `Width` newtype admits `0..=256` per `arvo-strategy/src/lib.rs`, the Warm container projection caps at 128 bits per `arvo-strategy/src/project.rs`. Wording: "Warm projects to native primitives up to 128 bits; widths 129..=256 require Hot or Precise" replaces the contradictory passages.

### Decision 5: Polka-dots references in rendered output

Every `polka-dots T<N> L<lines>` and `polka-dots T<N> decision #<n>` reference renders into Tier 1 from a per-crate `mock/crates/*/DESIGN.md.tmpl` or `BACKLOG.md.tmpl`. The polka-dots repo is maintainer-private; references leak. The fix: replace each with the design rationale itself ("decision #67: RCM always" becomes "RCM is always run, regardless of bandwidth heuristic, because the cost dominates only above 10⁵ records and most pipelines fit within that") with the supporting source citation moved to a Tier 2 history note.

The audit research file enumerates the specific occurrences; the doc CL includes them per crate.

### Decision 6: Spelling drift

Five US-spelling -ize forms (audit research file enumerates) get converted to British -ise forms to match the workspace baseline. Mechanical edit.

### Decision 7: Auto-gen header workspace finding

The `Generated by: mockspace (mock) ... To regenerate: cargo mock` auto-gen header at the top of every rendered `docs/*.md` is produced by the mockspace renderer and is not editable from arvo's templates. The em-dash on the header's first line is also generator-emitted. **This is recorded as a workspace-wide finding to surface to mockspace upstream**, not addressed in this round. The arvo doc round leaves the header as-is.

### Decision 8: WORKFLOW.md.tmpl rendering fate

`mock/WORKFLOW.md.tmpl` is contributor-shaped. Verify what `cargo mock` produces: if it renders to `docs/WORKFLOW.md` (Tier 1), this round rewrites the body to consumer focus (how to use the crate, how to bump versions). If it renders only to `mock/WORKFLOW.md` (Tier 2), the file stays as-is; the doc CL records the verification result and acts accordingly.

## Following src CL (mentioned, not written)

The doc CL produced by this round is doc-only. A subsequent src CL is required for:

1. **Rustdoc on `pub` items in `crates/**/src/**.rs`.** The per-crate audit flagged narrative drift (the prose around method behaviour) but did not exhaustively enumerate per-pub-item rustdoc state. The src CL audits every `pub` item across the affected crates and updates rustdoc to match the current source shape.
2. **Inline `//` and `//!` module docs.** Workspace-wide writing-style applies; arvo source side may have isolated em-dashes that the workspace gate didn't catch (the gate covers `crates/**/*.rs` per writing-style.md scope). The src CL runs a final em-dash sweep on every `.rs` file.
3. **`Cargo.toml` description and keywords**, per crate. Verify each crate's published metadata aligns with the crate's identity post-doc-update.

The src CL is opened after this round's doc CL is locked. It references this topic file by id.
