# Src changelist 202605021200 - const-trait arithmetic on every arvo numeric

**Date:** 2026-05-02
**Phase:** SRC-PLAN
**Source doc CL:** `202605021200_changelist.doc.lock.md` (locked)
**Source sketch:** `mock/research/sketches/usize-const-arith-202605021200/sketch.rs` (compiles clean on nightly with `feature(const_trait_impl)` + `feature(const_ops)`; FINDINGS.md captures validated facts)
**Tracking tasks:** umbrella #300, layers #301 (A) + #302 (B) + #303 (C).

This CL applies the source-side changes that match the locked DOC CL. Three layers ship together: (A) USize + Cap full const-arith surface, (B) convert existing arvo numeric ops impls to `impl const`, (C) sweep arvo source for `.0` field-access on arvo numerics.

The apply order follows dep direction: L0 first (arvo-storage), then L0.5 contracts (arvo-bits-contracts, arvo-numeric-contracts, arvo-mask-contracts), then L1 (arvo-bits), then L2 (arvo-bitmask, arvo-tensor, arvo-hash), then L2 algorithms (arvo-graph, arvo-sparse, arvo-comb, arvo-spectral), then the facade (arvo). Layer C sweep follows last, after the const surface from A+B is in place.

## Layer C (#303): sweep arvo source for .0 field-access on arvo numerics

The sweep migrates each site to use the const-arith surface from layers A+B. Each migration is mechanical. Sites are enumerated below by file.

### `mock/crates/arvo-bitmask/src/dirty.rs`

- Line 36: `matrix.successors(NodeId(USize(i.0)))` → `matrix.successors(NodeId(i))` (round-trip USize wrapping is redundant; `i` is already a USize).
- Line 62: same.

### `mock/crates/arvo-bitmask/src/ops.rs`

- Line 101: `USize(63 - lz.0)` → `USize(63) - lz`.
- Lines 224, 235, 247: `let word_idx = USize(pos.0 >> 6);` → `let word_idx = pos >> USize(6);`.
- Lines 225, 236, 248: `let bit_idx = USize(pos.0 & 63);` → `let bit_idx = pos & USize(63);`.
- Line 261: `USize(n0.0 + n1.0 + n2.0 + n3.0)` → `n0 + n1 + n2 + n3`.
- Lines 273, 276, 279: `return USize(64 + <QWord<Hot> as BitSequence>::trailing_zeros(a[1]).0);` → `return USize(64) + <QWord<Hot> as BitSequence>::trailing_zeros(a[1]);` (and similarly for 128, 192).
- Lines 291, 295, 299, 303: `return USize(N + 63 - lz.0);` → `return USize(N + 63) - lz;` (constants 192, 128, 64, 0). Note: `USize(N + 63)` keeps the literal arithmetic at construction time; `- lz` is the const-trait Sub.
- Line 340: `return Some(USize(self.word_idx.0 * 64 + bit.0));` → `return Some(self.word_idx * USize(64) + bit);`.
- Line 342: `self.word_idx = USize(self.word_idx.0 + 1);` → `self.word_idx = self.word_idx + USize::ONE;`.

### `mock/crates/arvo-bits-contracts/src/bits_impl.rs`

- Line 64: `USize(N as usize - self.count_ones().0)` → `USize::from_const(N) - self.count_ones()` (or equivalent; verify `from_const` exists; if not, `USize(N as usize) - self.count_ones()`. the `N as usize` cast is the boundary case for the const-generic parameter).

### `mock/crates/arvo-comb/src/dp.rs`

- Line 133: `if reachable.get(USize(0), root_end).0 {` → `if reachable.get(USize::ZERO, root_end).as_bool() {` (the `.0` here is on a Bool, not USize; use `as_bool()` which arvo-storage already exposes via `AsBool` trait, or the `?` operator if applicable).
- Line 164: `*out_idx = USize(out_idx.0 + 1);` → `*out_idx = *out_idx + USize::ONE;`.
- Line 166: `fill_splits::<N>(split, reachable, USize(k.0 + 1), hi, out, out_idx);` → `fill_splits::<N>(split, reachable, k + USize::ONE, hi, out, out_idx);`.

### `mock/crates/arvo-comb/src/greedy.rs`

- Lines 67, 73, 79: `i = USize(i.0 + 1);` → `i = i + USize::ONE;`.
- Lines 85, 102: `count = USize(count.0 + 1);` → `count = count + USize::ONE;`.

### `mock/crates/arvo-comb/src/binpack.rs`

- Lines 112, 113: `used.set(USize(opened.0), w);` and similar → `used.set(opened, w);` (the inner `USize(opened.0)` round-trip is redundant; `opened` is already a USize).
- Line 114: `opened = USize(opened.0 + 1);` → `opened = opened + USize::ONE;`.

### `mock/crates/arvo-graph/src/waist.rs`

- Line 71: `width[d] = USize(width[d].0 + 1);` → `width[d] = width[d] + USize::ONE;`.
- Line 85: `occupied[occ_n.0] = USize(d);`. here `occ_n.0` is array indexing; use `occupied[*occ_n] = USize(d);` (Deref).
- Line 86: `occ_n = USize(occ_n.0 + 1);` → `occ_n = occ_n + USize::ONE;`.

### `mock/crates/arvo-graph/src/spanning.rs`

- Line 98: `if dag.predecessors(NodeId::new(USize(j))).count().0 == 0 {`. `j` here is likely a bare counter; verify and migrate. The `.count().0 == 0` should become `.count() == USize::ZERO` once USize has const PartialEq.

### `mock/crates/arvo-graph/src/components.rs`

- Line 38: `next_id = USize(next_id.0 + 1);` → `next_id = next_id + USize::ONE;`.

### `mock/crates/arvo-sparse/src/rcm.rs`

- Line 49: `order[head.0] = NodeId::new(USize(start));`. array index: `order[*head] = NodeId::new(USize(start));`.
- Line 50: `head = USize(head.0 + 1);` → `head = head + USize::ONE;`.
- Line 53: `let mut read = USize(head.0 - 1);` → `let mut read = head - USize::ONE;`.
- Line 57: `read = USize(read.0 + 1);` → `read = read + USize::ONE;`.
- Line 108: `head = USize(head.0 + 1);` → `head = head + USize::ONE;`.
- Line 155: `Maybe::Is((_, bd)) if d.0 < bd.0 => best = Maybe::Is((USize(i), d)),`. comparison `d < bd` once USize has const PartialOrd.

### `mock/crates/arvo-spectral/src/partition.rs`

- Line 130: `stack_len = USize(stack_len.0 - 1);` → `stack_len = stack_len - USize::ONE;`.
- Lines 168, 193, 197, 206: `stack_len = USize(stack_len.0 + 1);` / `partition_count = USize(partition_count.0 + 1);` → `+ USize::ONE` form.

### `mock/crates/arvo-sparse/src/block.rs`

- Line 42: `next_id = USize(next_id.0 + 1);` → `next_id = next_id + USize::ONE;`.

### `mock/crates/arvo/src/markers.rs`

- Line 89: `UFixed::<{ IBits::ONE }, { FBits::ZERO }, Hot>::from_raw(self.0 as u8)`. the `self.0 as u8` is a boundary-cast inside a `from_raw` constructor. Audit; this is constructing from a Bool's inner `bool`, the `.0` access is on Bool which is the bottom-level wrapper. Document and keep, OR use `arvo::raw(self) as u8` if available.

### `mock/crates/arvo/src/traits.rs`

Lines 178-420 (Sqrt, Recip, Abs impls on FastFloat / StrictFloat): the `.0` access here is bottom-level wrapper-to-`f32`/`f64` for calling into raw float intrinsics. Per FINDINGS.md, document as boundary case (FFI-shaped). Optionally migrate to `arvo::raw(self)` if it works in const context.
