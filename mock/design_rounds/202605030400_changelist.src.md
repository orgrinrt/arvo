## Deliverable B: LOGICAL_WIDTH internal arithmetic cleanup

### Add helper functions in `mock/crates/arvo/src/markers.rs`

Add two const fns next to the `BitPresentation` trait declaration:

```rust
use arvo_storage::{FBits, IBits, USize};

#[inline(always)]
pub const fn logical_width_unsigned(i: IBits, f: FBits) -> USize {
    USize(i.raw() as usize + f.raw() as usize)
}

#[inline(always)]
pub const fn logical_width_signed(i: IBits, f: FBits) -> USize {
    USize(1 + i.raw() as usize + f.raw() as usize)
}
```

The helper fns centralise the typed-meta-bit to typed-USize lift. The
trait surface stays at `USize` (unchanged). The `i.raw()` / `f.raw()`
projections are typed const-fn accessors that flow through the same
boundary the existing impl bodies use; the helper extracts them so the
LOGICAL_WIDTH impl bodies read as one call rather than three operations.

Each helper carries one `lint:allow(no-bare-numeric)` /
`lint:allow(arvo-types-only)` annotation on the `as usize` cast lines
with `tracked: #312` (Round 2 boundary cleanup). Round 3 lifts the cast
out of the helper bodies once typed Width arithmetic ships.
