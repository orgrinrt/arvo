**Date:** 2026-09-01

## CL 1: `mock/crates/arvo-strategy/DESIGN.md.tmpl`

**CHANGE:** Correct the overflow-value claim and the arm-selection claim.

The "Which overflow mode each preset names is not written here" sentence is
false against the shipped `presets` module and gets rewritten to say what is
actually shipped: a carried, non-canonical default per preset, with
`question::does_warm_wrap_or_clamp` named as the one cell a registry question
already disputes.

The "## What an arm is, since this crate is what selects them" section
overstates the crate's role. Rewritten to state precisely that this crate
supplies the const predicate value (`Strategy::Objective`) and that the
selection itself, the match on that value, happens in `arvo-placement`'s
`derive_sole` / `derive_shared`, named by function. The "No arm ships in
this round" reasoning is kept and sharpened: it is not a gap, it is the
refusal of an unjustified generalisation the same two rulings forbid.

## CL 2: `mock/crates/arvo-placement/DESIGN.md.tmpl`

**CHANGE:** Add the two ratified rows this crate's own arms are an instance
of, to its canon citation list, and name them where the arms are described.

`ruling::arms_over_regions_are_the_fundamental_heart` and
`ruling::the_work_is_predicated_arms_composed` go into the "Canon this
design declares" list at the top, and the section naming `derive_sole` /
`derive_shared` as "two arms" gets one sentence tying that vocabulary to the
ratified row by slug, so a reader checking whether the ruling is honoured
finds the evidence in the crate that carries it rather than only a
citation in a sibling crate that ships none.
