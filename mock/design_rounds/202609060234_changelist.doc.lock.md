# Doc changelist: the second door onto the width obligation

## `crates/arvo-bits/DESIGN.md.tmpl` (no change)

Stated here so the absence is a decision rather than an omission.

The document already says what `cast` is and what `ADMITTED` refuses, and both
statements are correct as written. What this round found is not a design that
says the wrong thing, it is a suite that could not have noticed if the code
stopped saying it: the refusal on the cast path is reached by delegation and
nothing held the delegation, and the cast law was checked over every pair of
widths at one value.

Neither of those is a fact about the design. A design says what a construction
means, and how thoroughly the suite observes it is the suite's business, so
the document neither weakens to match what was checked nor strengthens to
describe what is now checked.

## The generated pages (no regeneration)

Nothing authored here renders, so `docs/` is untouched. This is the ordinary
case for a round whose whole changelist is source, and it is written down only
because the previous round in this crate did have generated pages lagging its
templates, which is the failure that makes an unstated "nothing to do" hard to
tell from an unnoticed one.
