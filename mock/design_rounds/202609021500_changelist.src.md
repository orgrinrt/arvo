# SRC changelist: no source change

The round edits two design templates and the two pages they render into. No
`*.rs` file is touched, no type moves, no signature changes, and no claim is
made about source state that was not already there.

## CHANGE: none

Verification: `git diff --name-only origin/dev...HEAD -- '*.rs'` returns nothing.
Three dots, not two. Two dots compares the two tips, so anything landing on the
trunk after this branch was cut comes back as a difference and the check reports
thirty-four files it has nothing to do with. Three dots compares against the
merge base, which is what "did this branch touch any source" actually asks. The
same command without the pathspec returns the seven files this round does touch,
which is what says the instrument works rather than that it is silent.

Every backticked identifier that survives in the two templates names an item
that was already named there before the round. Nothing in the prose that was
removed was the only mention of a source item: the removed text held registry
slugs, which name rows rather than code, and sentences about how the project
settles things.

The generated files under `.claude/` and `.github/` moved with the templates, as
they do on every regeneration. They are gitignored here, so they are not in the
diff and are not claims this changelist can carry.

`docs/STRATEGY.md` is rewritten on every regeneration even when nothing it
renders has changed, so its banner timestamp moves on a run that touches
nothing. It is left at its committed state rather than carried in this round,
because the churn is not this round's and the file is not this round's subject.
The three other pages checked alongside it hold their timestamps across the same
run, so this is one file rather than the generator as a whole.
