# DOC changelist: name the operand that pins, not the magnitude

## CHANGE: mock/crates/arvo-format/DESIGN.md.tmpl

The `Magnitude saturation` row says the region pins the magnitude to the largest
the coordinate carries. It does not, and `of(3, i64::MIN)` shows it: the answer
`-3/i64::MAX` has a magnitude of `3/(2^63-1)`, which is not at any maximum.

Replace the row's description with what the region does: the operand needing
`2^63` takes the largest the coordinate carries, which moves the answer by a
relative `1 / i64::MAX`.

The four properties below the table are correct and are not touched.
