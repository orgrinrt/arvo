# Src CL: rename arvo-narrow source files + workspace + lints

**Date:** 2026-04-30
**Round:** 202604301700
**Phase:** SRC-PLAN

The DOC phase moved the doc templates (`README.md.tmpl`,
`DESIGN.md.tmpl`, `BACKLOG.md.tmpl`) from `mock/crates/arvo-narrow/`
to `mock/crates/arvo-refit/`. The crate's source files
(`Cargo.toml`, `build.rs`, `src/lib.rs`) and the workspace + lint
configurations stay in `arvo-narrow` until this SRC phase closes
the rename.

This CL handles the source-side completion:

1. Move `mock/crates/arvo-narrow/{Cargo.toml,build.rs,src/lib.rs}`
   to `mock/crates/arvo-refit/{Cargo.toml,build.rs,src/lib.rs}`.
   The doc-template move during DOC phase already created the
   destination dir; now the source files join.
2. Edit the moved `Cargo.toml`: `name = "arvo-narrow"` becomes
   `name = "arvo-refit"`.
3. Edit the moved `src/lib.rs`: replace the module-level doc
   comment block with one naming `arvo-refit` (round 202604301700)
   and updating the historical note about
   `arvo-narrow-contracts` (round 202604280034) for accuracy.
4. Update workspace `mock/Cargo.toml`: workspace member entry
   `"crates/arvo-narrow"` becomes `"crates/arvo-refit"`; the
   `[workspace.dependencies]` entry `arvo-narrow = { path =
   "crates/arvo-narrow" }` becomes `arvo-refit = { path =
   "crates/arvo-refit" }`.
5. Update `mock/mockspace.toml`: every `arvo_narrow::*` substring
   in `forbidden = "..."` strings flips to `arvo_refit::*`. The
   `[lints.forbidden-imports]` entry whose `scope = "arvo-narrow"`
   becomes `scope = "arvo-refit"`. The `reason = "..."` text on
   that entry updates to reflect the post-merge re-export shape.
   The comment line above it updates accordingly. Per
   `.claude/rules/mockspace-toml-edits.md` and the
   `lint-severity-reminder.sh` hook, crate-name renames in
   `scope` / `forbidden` / `reason` fields are explicitly
   permitted; no gate-severity changes happen.
6. Update `mock/crates/arvo-bits-contracts/src/lib.rs`: three
   doc-comment references to `arvo-narrow` flip to `arvo-refit`.
   The historical reference to `arvo-narrow-contracts` (the L0.5
   crate that merged into this one in round 202604280034) stays
   unchanged.

## Comparison to deprecated changelist

`202604301700_changelist.src.deprecated.md` was the prior src CL
for this round. It was deprecated when `cargo mock unlock` rolled
the round back from SRC to DOC after mockspace's
`changelist-doc-gate` lint flagged the dir rename's doc-template
moves as DOC-phase edits during SRC phase.

The deprecated CL planned a single atomic `git mv` of the whole
crate dir during SRC phase. That plan failed because mockspace
treats `*.md.tmpl` files as doc artefacts and forbids their
movement during SRC phase, while it treats `*.rs` and
`Cargo.toml` files as source artefacts and forbids their
movement during DOC phase.

This new CL solves the impasse by splitting the dir rename
across the two phases: doc templates moved in DOC, source files
move now in SRC. The destination dir `mock/crates/arvo-refit/`
spans both halves of the rename across two commits; the final
state matches the originally-intended atomic rename.
