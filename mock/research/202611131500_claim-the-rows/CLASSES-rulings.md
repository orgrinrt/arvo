# The readers' classes for the rulings

Two readers took the sixty-one rulings that were not ratified, one lot each,
and wrote a block per row. A block names the row, gives its class, the file and
lines the class rests on, the passage quoted from there, and a note. Class `a`
is a row the written history shows to be his, `b` is a row he does not back or
that stands against a ratified row or the record, and `c` is neither. Where a
row is his in one part and not in another the class names both and the note
says which sentence is which.

The blocks are the readers' own and are kept as they wrote them. A path
beginning `op-responses/` is a capture in the workspace's store of his
responses, which is outside this repository. `NOTES.md` beside this file says
what was done with each class.
