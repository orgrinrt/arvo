Mechanism notes.

The probe-2 const-eval refusal is left in the probe header rather than erased, per the discipline that
a probe which only ever passed is not evidence it was checking anything (file 33's own practice,
`33:33-37`): the first draft's bound was not wrong, its model size was, and the refusal reproduces the
exact wall `26_consolidation_two.md` section 1.3 measures (quadrupling per bit, refused past eight).

`probe_0` intentionally reuses file 32's committed crate rather than a copy, so the closure is about
the artifact file 32 actually measured, not about a reconstruction. Nothing in `32_probes/` was
modified.

Probe 5's `same_type(PhantomData<T>, PhantomData<T>)` is the cheapest type-equality demand available
without unstable machinery; a mismatch is an ordinary E0308 at the call site, which for probe 5b is
the deliverable.
