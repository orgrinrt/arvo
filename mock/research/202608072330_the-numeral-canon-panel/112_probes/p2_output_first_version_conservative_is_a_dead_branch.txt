DEFECT IN THIS RUN, FOUND BY ITS AUTHOR, KEPT RATHER THAN OVERWRITTEN
-----------------------------------------------------------------------------
The `conservative` column above is VACUOUS and its numbers must not be cited.

`q1_exactness` increments `conservative` when the rule refuses to discharge
AND the measured arm agrees with the general arm.  The measured arm is
`eval_cheap_where_discharged`, which FALLS BACK TO THE GENERAL ARM at any node
that does not discharge.  So whenever the rule refuses, the two are the same
function by construction and `agrees` is True with certainty.  The counter is
therefore reporting the number of non-discharging extents and nothing else,
and it cannot ever report a zero for a reason having to do with conservatism.

This is the same class as `110` F3's third bullet, which `111` section 2.2
found and mutation-tested: a count produced by a command that could not have
returned anything else.  Mine is worse in one respect, since I wrote the
condition-can-fire warning into this probe's own header and then failed it.

The `unsound` column is NOT affected: it fires only when the rule discharges
and the arms disagree, both of which are live, and MUTATION 2 at the bottom of
this run confirms it moves (0 -> 120) when the propagation rule is broken.

Repaired in `p2b`, which measures conservatism against the FULLY cheap arm.
A second defect found at the same time: Q4's "grid bound" passed `P.step` as
the leaf grade's step, which is the finest grid rather than a declared coarser
one, so the grid bound could never discharge under `mul`.  Also repaired in
`p2b`.
