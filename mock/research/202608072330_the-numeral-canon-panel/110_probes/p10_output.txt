reading:
  the honest form of the original finding is not that a law set is an
  unsettable coordinate, which is analytic and needs no sweep. it is
  that a law verdict reads a NAMED SET of axes and not the others, and
  that the set is measurable with a test that can return either answer.
  over this sweep every real axis is read and the spurious one is not,
  which is `90` R1's dimension list given a measured floor rather than
  an enumeration.
