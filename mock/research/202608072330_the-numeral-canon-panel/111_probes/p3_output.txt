reading:
  F4 is right that the count is a function of the signature, and the
  function is constant above the literal. A design that can write a
  literal is already at the finest identity its realisation map
  supports, so it does not have to declare a closed operation set to
  have stable identity. It has to have a constructor, which it cannot
  avoid having.
