# Control fixture for arm D

A fixed file arm D's control intersects against, so the control does not depend
on any real panel file staying as it is.

One word matters and it is `supersession`, in this sentence and in none of the
planted quotes, so a planted `says` using it must be reported as drawn from the
source.

The control also needs a word this file does **not** carry, to check the other
direction. That word is deliberately not written here, and the first draft of
this file did write it, in a sentence explaining that it was absent. The control
then failed for exactly the right reason: a file cannot both lack a word and
name it. The probe holds that token and this file must never grow it.
