== section 4: is a tapered set reachable at all ==

   Section 3 refuted the claim that every reachable set is one ladder, so the
   reach question has to be asked directly rather than through the ladder shape.
   A target is a set; the question is whether any coordinate tuple denotes it.

   control, a float target, exponents [0, 1, 2]:
     members [-12, -8, -6, -4, -3, -2, -1, 0, 1, 2, 3, 4, 6, 8, 12]
     reached by Some((2, 1, 3, -3, 3))

   target A, a taper, exponents [0, 1, 3]:
     members [-24, -16, -8, -6, -4, -3, -2, -1, 0, 1, 2, 3, 4, 6, 8, 16, 24]
     reached by None

   target B, a taper, exponents [0, 2, 3]:
     members [-24, -16, -12, -8, -4, -3, -2, -1, 0, 1, 2, 3, 4, 8, 12, 16, 24]
     reached by None

   control holds: the float target is reached.

   FINDING: neither tapered target is denoted by any coordinate tuple in the
   search space. The exponent sequence a format denotes is an arithmetic
   progression, because the law is affine in the magnitude, so a shell ladder
   whose exponents are not equally spaced has no coordinates. That is the exact
   sense in which a tapered numeral is outside this parameterisation, and it is
   narrower than the gap-shape claim section 3 refuted.
