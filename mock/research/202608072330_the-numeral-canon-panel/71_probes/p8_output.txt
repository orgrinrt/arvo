  What this adds to the crossing question. p1 showed the value relation and the pattern
  relation are different MAPS. This shows they can be different KINDS: the value relation
  is a total function and the pattern relation is a relation with no canonical function
  inside it, so a crossing into a redundant encoding is only a function once a section is
  named, and naming one is a choice the two systems do not make between them. That is the
  same shape as the choice p2 found for a lossy crossing, at a different coordinate:
  the crossing needs something neither endpoint supplies.

  And it bounds a canon sentence. 'A crossing preserves values' is true here and says
  nothing about whether the crossing is well defined, because the pattern relation is
  where the ambiguity lives and the value relation cannot see it.
