P1/P2. The two-by-two: operation set against window sign

  |V|   window         ops             hom    mono   BOTH+NONCONST
  2     straddles 0    add+mul           3      10               0
  2     straddles 0    add only          4      10               0
  2     straddles 0    mul only          6      10               0
  2     non-negative   add+mul           4      10               1   <== NON-EMPTY
        witness: {0->0, 1->1, 2->1, 3->1, 4->1, 5->1, 6->1, 7->1, 8->1}
  2     non-negative   add only          5      10               1   <== NON-EMPTY
  2     non-negative   mul only         18      10               1   <== NON-EMPTY

  3     straddles 0    add+mul           6     105               0
  3     straddles 0    add only          8     105               0
  3     straddles 0    mul only         73     105               0
  3     non-negative   add+mul          10     105               3   <== NON-EMPTY
  3     non-negative   add only         12     105               3   <== NON-EMPTY
  3     non-negative   mul only        391     105               3   <== NON-EMPTY

  read as a two-by-two at |V| = 2 and |V| = 3:

                        add+mul   add only   mul only
    |V|=2 straddles 0          0          0          0
    |V|=2 non-negative          1          1          1
    |V|=3 straddles 0          0          0          0
    |V|=3 non-negative          3          3          3

  Every non-negative row is non-empty and every straddling row is empty,
  at every operation set. So the OPERATION SET is not the load-bearing
  half and the DOMAIN is.

P3. Adding closure under negation back to a non-negative window

  |V|=2 non-negative             window 0..4 (5 points): both+nonconst 1
  |V|=2 closed under negation    window -4..4 (9 points): both+nonconst 0
  |V|=3 non-negative             window 0..6 (7 points): both+nonconst 3
  |V|=3 closed under negation    window -6..6 (13 points): both+nonconst 0

  So closure under negation is what empties it, which is exactly what my
  proof's first step uses: an additive homomorphism onto a finite set has
  kernel nZ only if the image is a GROUP, and the image is a group only
  if every element has an inverse in the domain.

P4. Do `119` 4.2's two stated domain conditions separate the rows

  |V|=2 straddles 0   : complete residue system True, interval 0..2 present True
  |V|=2 non-negative  : complete residue system True, interval 0..2 present True
  |V|=3 straddles 0   : complete residue system True, interval 0..3 present True
  |V|=3 non-negative  : complete residue system True, interval 0..3 present True

  Both conditions hold on both rows, so neither distinguishes the cell
