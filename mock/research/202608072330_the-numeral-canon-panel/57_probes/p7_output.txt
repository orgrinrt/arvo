=== 3. the witness, by hand, at Q = [-8, 7] ===

  sat(7) = 7 and sat(8) = 7, so 7 ~ 8 (same high-tail class).
  Multiply both by -1:
    sat(7 * -1)  = sat(-7) = -7
    sat(8 * -1)  = sat(-8) = -8
  -7 != -8, so the class pair (high tail, -1) has two images and `~` is not a
  multiplicative congruence. Under the symmetric range [-7, 7] the same pair gives
    sat(7 * -1) = -7 and sat(8 * -1) = -7
  which are equal, and the class pair has one image.

  asymmetric range splits the class:  true
  symmetric range does not:           true
