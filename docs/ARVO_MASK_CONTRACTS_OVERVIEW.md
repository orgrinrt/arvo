# arvo-mask-contracts. Design

The mask operations contract. One trait declaration: `MaskOps`.
Concrete impls live in `arvo-bitmask`. Consumers writing
mask-generic code bind to this surface to keep their transitive
dependency footprint small. `#![no_std]`, no alloc.

Depends on `notko`, `arvo-storage`, `arvo-bits-contracts`.

## MaskOps

```rust
pub const trait MaskOps: Sized + Copy {
    fn empty() -> Self;
    fn full() -> Self;
    fn set(self, idx: USize) -> Self;
    fn clear(self, idx: USize) -> Self;
    fn test(self, idx: USize) -> Bool;
    fn count(self) -> USize;
    fn union(self, other: Self) -> Self;
    fn intersection(self, other: Self) -> Self;
    fn difference(self, other: Self) -> Self;
    fn complement(self) -> Self;
}
```

The trait is uniform across mask-width: width information lives on
the implementor's underlying word type, not as a trait parameter.
Round 202605040602 (#315) dropped the prior `const W: Width`
parameter (it was dead in every method body) and the
`mask_for_width(n: USize) -> Self` method (zero callers; consumers
already used `BitPrim::mask_low(n)` from arvo-bits-contracts at
the bare-primitive layer where `Narrow<T>` impls actually compose).

Default-method bodies compose `BitAccess` and `BitLogic` from
`arvo-bits-contracts`. Concrete impls in `arvo-bitmask` supply the
storage and may override defaults with hardware-specific
implementations.

## Naming

`arvo-bitmask::Mask<W>` is the concrete chassis struct (type-generic
over a Bits-shape word). `arvo-mask-contracts::MaskOps` is the
abstract operation contract over `Self`. Different shapes,
different roles, different crates. The distinct names eliminate the
prior single-`Mask` clash that mixed struct and trait under one
name.

Round 202605040602 (#315) replaced the prior per-W concrete impls
with a single blanket. The chassis already routes through the
underlying word's `BitAccess` / `BitLogic` / `BitSequence` traits
in its inherent surface; the blanket lifts that routing into the
const-trait surface uniformly. Per-W concrete overrides are
